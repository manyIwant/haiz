# 给维嘉老师 ·《没人布置的作业》

一本交给实习老师的课外作业。翻开是作文格；题目是“找一颗星，指给老师看”；关灯以后，
这一页变成星图，格子里那个不起眼的墨点就是织女一（Vega）；最后一页照例有一栏“教师批阅”，
红笔这一回递到了老师手里。她画的那一笔，会留在可以保存的“最后一页”上。

没有信封，没有印章，没有声音，开场没有星空。整份礼物只有四种材质：
牛皮纸封面、作文格稿纸、蓝晒纸、老师的红笔。

---

## 送出之前，作者只需要做三件事

全部在 **`content.config.js`** 里，用任何文本编辑器打开即可，不需要构建。

1. **核对署名。** `senderName` 现在是旧版印章上的“恩贝”。想用全名就改；想匿名就留空 `""`。
2. **写下真实回忆（`TODO_真实回忆`）。** 找到 `memories: []`，写一两件真实的小事。
   这是整份礼物里唯一没人能替你写的部分。留空也成立，但写了才真正是“给她的”。
3. **确认两处默认说法符合事实：** 正文里的“高中”和“这个学期”。如果不符，直接改字。

其余所有句子也都在这个文件里，想改哪句改哪句。逐句的写作意图见 [`礼物文案.md`](礼物文案.md)。

## 怎么打开

| 方式 | 做法 | 说明 |
|---|---|---|
| 直接双击 | 打开 `index.html` | `file://` 下可完整运行（含保存纪念页）。已在 Chromium 中实测。 |
| 本地预览 | 在本目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/` | 与线上行为一致 |
| 部署 | 把整个 `vega/` 目录放到任意静态托管 | 没有后端，没有构建步骤 |
| 打包发给别人 | `zip -r vega-gift.zip . -x "tools/*" "docs/*"` | 解压后双击 `index.html` |

**关于这个仓库：** `vega/` 放在 HAIZ 站点仓库里。它一旦合并到 `main`，就会随 GitHub Pages 发布到
`haiz.space/vega/`，任何拿到链接的人都能打开。页面已加 `noindex`，不会被搜索引擎收录，但它不是“加密的”。
如果不希望公开，就不要合并，改用上面的打包方式或单独的私有托管。

## 它会不会收集什么

不会。不登录、不请求定位、不上传、不引用任何外部域名的资源。老师在批阅栏里的笔迹只存在她自己
浏览器的 `localStorage` 里（键名 `vega.homework.v1`），为的是下次打开时还在；清除浏览器数据即可抹去。

## 交互与退路

- **翻开：** 点“翻开”、在封面上向上滑、滚轮、或键盘 ↓ 均可。
- **灯：** 可以按那个画出来的开关；不按、只是往下滑，灯也会在该关的地方关、该开的地方开。
- **批阅：** “拿起红笔”后才会接管触摸，之前这一栏不挡滚动。不想画可以盖“阅”字章，也可以不批直接收下。
- **重访：** 批阅过之后，封面底部会多一行“直接翻到最后一页”。
- **只看文字：** 封底有“只看文字”，是可选中、可复制、可朗读的纯文本全文。
- **减少动态效果：** 系统开启后，翻页、渐显、等待全部取消，内容不变。
- **没有 JavaScript：** 显示一段说明文字。

## 改了文案之后字体不对？

页面实际用到的字、加上常用 3500 字，都已备好同一种手写体；更生僻的字会退回系统楷体。
想完全一致：

```bash
pip install fonttools brotli
# 下载 LXGWWenKai-Regular.ttf 与 NotoSerifSC[wght].ttf 到 ./font-src/（地址见 tools/build-fonts.py 开头）
python3 tools/build-fonts.py ./font-src
```
