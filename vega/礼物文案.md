## 二、每一句在干什么

| 句子 | 它承担的事 | 为什么留 |
|---|---|---|
| 这份作业没有人布置，是我自己要写的。您不用批改。 | 交代这是什么、谁给谁 | 学生口吻；“不用批改”是给结尾埋的 |
| 念出来，刚好像您的名字。 | 全篇唯一的“为什么是她” | 只陈述巧合，不升华 |
| 用汉字给英文注音是不对的，我知道。就这一次。 | 把“Vega＝维嘉”落到一个教室里的坏习惯上 | 只有学生对老师才会这么说；全篇唯一的玩笑 |
| 它不是那种花钱“买下来”的星……只是把它找出来，指给您看。 | 说明这件礼物的行为 | 沿用旧版最好的一句；拒绝“命名一颗星”的商品逻辑 |
| 看不清的话，麻烦您关一下灯。 | 触发关灯 | 教室里通常是老师请学生关灯，这里反过来 |
| 这一颗。 | 指 | 三个字，够了 |
| 看见的，就是这个学期。 | 把二十五光年落回她在这里的日子 | 用“学期”而不是“时光”“岁月” |
| 当时并不觉得什么，是一点一点留下来的。 | 银版 → 普通日子如何被记住 | 为正文第一段铺路 |
| 我很喜欢这句话，却说不清为什么。 | 留一处不解释 | 全篇其他地方都很明白，这里故意不说满 |
| 可普通的日子也会被记住，只要有人在里面认真地出现过。 | 具体感谢的前提 | 后面紧接真实回忆；没有回忆时它独自承担 |
| 它很小，写得也匆忙，但里面没有一处是随便放的。 | 学生的自谦与郑重 | 沿用旧版 |
| 谢谢您来过。 | 感谢 | 前面铺垫够了，才轻得起 |
| 祝您以后站上的每一个讲台，都有人认真地听。 | 唯一一句祝福 | 只祝一件事，不替她许诺未来 |
| 以前，红笔总在老师手里。这一回，是我把它递给您。 | 交出红笔 | 整件作品的转折 |
| 老师再见。 | 结束 | 每一节课都这样结束；这是最后一次 |

## 三、删掉的和没用的

- 删掉了旧版“大约需要五分钟”“请在一个安静的时候打开它”之类对读者的要求。
- 删掉了“一分多钟”的曝光时间：资料包里核实过的只有年份与人物，具体秒数没有核实，就不写。
- 没有写“您是光”“照亮”“星河”“永远”“改变了我”。全文“光”字只指物理上的光。
- 结尾考虑过三种：留白（“老师再见。”）、回望（“以后再听见 Vega，我会想到您。”）、
  轻松（“这份作业，可以不用还给我。”）。只用了第一种。
- 没有声音，没有“愿您”排比。
