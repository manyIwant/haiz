# 创作与验收记录

## 一、读完旧版之后

第四版最强的文学细节是“不是买下来的星，只是把它找出来，指给您看”，以及眉批里那句
“以前，红笔总在老师手里。这一回，红圈是我画的”。最惊艳的互动是按住底片让光留下来。

它的问题不在完成度，而在主角：信封、印章、底片、银版、日冕仪——五件物都是天文和邮政的，
没有一件属于教室。把“星”字全部删掉，剩下的是一封写得不错的信，却看不出收信人是一位老师。
同时它要老师做五种不同的手势（按印章、抹名字、按底片、侧银版、遮星光），每一种都要学一次。

旧版里真正属于“学生对老师”的，只有那一行红笔的眉批。新版就从这一行长出来。

## 二、三条方向

| | 甲《没人布置的作业》 | 乙《光行》 | 丙《暗房》 |
|---|---|---|---|
| 叙事主轴 | 一本交上来的课外作业：题目、观测、正文、教师批阅 | 一束在她实习期间离开织女一的光，二十五年后才到；页面是一只慢得离谱的钟 | 红灯下的暗房：一张相纸在药水里慢慢显出一封信 |
| 独有的交互 | 请老师关灯——读着的那页纸变成星图；最后把红笔递给她 | 几乎没有交互；每次打开，光都走远了一点 | 晃动显影盘，字迹浮现 |
| 情感高潮 | 老师在“教师批阅”栏里写下她的字 | 意识到二〇五一年抬头看见的是“这个学期” | 最后一张相纸显出“谢谢您来过” |
| 没有星也成立吗 | 成立：仍是一份不用批改、却递上红笔的作业 | 不成立 | 勉强：只是一封显影的信 |
| 技术风险 | 作文格排版规则；触摸书写与滚动冲突；导出 | 太冷，像装置而不像礼物；依赖未核实的日期 | 没有真实照片可显影；与旧版底片、与本站“共感暗房”都重复 |

**选甲，并入乙最好的一格**（那条二十五年的刻度线，以及“看见的，就是这个学期”）。
丙整条放弃，只留下一个被改造过的细节：银版上的星点在一百秒里自己慢慢出现，页面不提示。

**为什么比第四版成熟：**

1. 主角换回来了。物件全部来自教室：作业本、作文格、四线格、注音、开关、红笔、“阅”。星是作业的内容，老师是作业交给的人。
2. 手势从五种减到三种，且都是她本来就会的：翻开、关灯、用红笔。第三种她实习期间做过无数次，只是这次意思不同。
3. 红色被管住了。全篇直到最后一页才出现红色，而且在她手里。
4. 纪念物不再是结尾的按钮。它包含收礼人自己的笔迹，是两个人一起完成的。
5. 没有 WebGL、没有库、没有声音、没有粒子。能双击打开，弱网也能读。

## 三、叙事脊柱（七个状态）

| # | 状态 | 观看方式 | 删掉会损失什么 |
|---|---|---|---|
| 0 | 封面：牛皮纸，“没人布置的 / 作业本”，老师：维嘉 | 点或上滑翻开 | 失去“这是交给一个具体的人的东西” |
| 1 | 题目页：作文格；Vega 上的铅笔注音；格子里的墨点；“麻烦您关一下灯” | 自然滚动 | 失去“为什么是她”和全篇的伏笔 |
| 2 | 关灯：同一页纸变成蓝晒星图，墨点是织女一 | 按开关，或继续下滑自动触发 | 失去唯一的魔术 |
| 3 | 二十五年：一条要滑过的刻度线 → “看见的，就是这个学期” | 滚动（距离用滚动的长度来感受） | 失去星与她之间的联系 |
| 4 | 银版与照片：光要等才留得下来；看清周围要先遮住自己 | 滚动 | 失去正文第一段的前提（4b 照片页可在配置里关掉） |
| 5 | 开灯：正文。普通的日子、真实回忆、谢谢您来过 | 滚动 | 失去礼物本身 |
| 6 | 教师批阅 → 收下最后一页 → 封底“老师再见。” | 拿起红笔后书写 | 失去转折与纪念物 |

状态模型：`closed → open(light=on) ⇄ light=off → light=on → reviewing(idle | writing | done) → keepsake`。
任何时刻可上下滚动、可合上重看；批阅结果存在本机，重访时封面出现“直接翻到最后一页”。

## 四、严苛回看

### 最容易变土的五处（及处理）

1. **银版像一部手机。** 第一稿是深色圆角矩形加金边。→ 已改：皮匣、黄铜衬框、椭圆窗，并把黄铜降了饱和度。
2. **纸纹像豹纹。** 第一稿的噪点低频太重，稿纸发脏。→ 已改：重做为细颗粒加纤维；云状纹理只留给蓝晒纸。
3. **贴照片的胶带。** 手帐感的老套路。→ 保留，因为学生确实这样贴图；只用两条，无图案。若仍嫌多，可把第四页整体关掉。
4. **刻度线上会呼吸的光点。** “发光小圆点”是模板感的重灾区。→ 已改：去掉外发光，只留一个缓慢明暗的白点。
5. **红笔的插画。** 扁平矢量加投影，略像剪贴画。→ 保留现状：它是全篇第一件红色的东西，必须一眼认出。未再细化。

### 逻辑最弱的三处

1. **“您不用批改”与“请批阅”。** 现在靠“说了不用批改。可作业本的最后，总有这么一栏”这句犹豫来接，成立但需要读者配合。
2. **哈勃照片页与师生之间没有明说的关系。** “我很喜欢这句话，却说不清为什么”是故意不解释，但它也因此是全篇最可删的一页。→ 已加开关 `showPhotoPage`。
3. **正文的中心仍是空的。** 没有真实回忆时，“普通的日子也会被记住”独自撑着感谢，分量不够。这不是代码能解决的，只能由作者填 `memories`。

### “看似精巧、其实可以删”的一处

银版上一百秒的慢曝光。绝大多数人会在它出现之前滑走，永远不知道它存在。保留的理由只有一个：
它恰好是那句“当时并不觉得什么，是一点一点留下来的”的字面意思，而且不向任何人要一秒钟。

### 最值得保留的三处

1. **墨点就是织女一。** 关灯时纸不换、格子不消失，只是字退下去、星出来，而那个点一格不差。
2. **用汉字给 Vega 注音。** 把名字的巧合落在一个只属于教室的小错误上。
3. **教师批阅栏。** 把最后一个动作、也是最熟的一个动作交给收礼人；她写的字就是纪念物的一部分。

### 手机上最容易失败的五处（及现状）

| 风险 | 现状 |
|---|---|
| 书写与页面滚动打架 | “拿起红笔”之前批阅栏不拦触摸；之后只有栏内 `touch-action: none` |
| 微信内置浏览器不支持下载 | 预览图用 `data:` 地址，可长按保存；检测到微信时隐藏“保存图片”按钮并改提示。**未在真机验证** |
| 作文格在 320px 上太小 | 实测一格 24px、字 17px，可读 |
| 字体没加载 | `font-display: block` 最多等 3 秒后退回系统楷体/宋体；实测拦截全部字体后版面完好 |
| iOS Safari 的 `dialog` / `inert` / `aspect-ratio` | 均需 iOS 15.4+；`dialog` 有非模态降级。**未在真机验证** |
