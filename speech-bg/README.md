# 「当我们说"我认为"的时候」演讲背景视频

语文演讲《当我们说「我认为」的时候——关于独立思考与自由》的配套背景动效。

![预览](preview.jpg)
全部画面由程序逐帧渲染（无素材、无模板），1920×1080 / 30fps / H.264。

这里有两套成品：

- **全文影片**（`film/`，由 `film.py` 渲染）：演讲的**每一句话**都按顺序出现在画面上，并按正常语速排好时间。每一部分都有自己的画面，用来"演"出这一段在说什么；部分与部分之间用"穿过眼睛"的跃迁转场衔接。见下方[全文影片](#全文影片)。
- **背景循环**（`out/`，由 `render.py` 渲染）：片头加若干段无缝循环背景，适合不想跟着视频节奏、只要一个氛围背景的情况。

## 全文影片

| 文件 | 说明 |
| --- | --- |
| `film/当我们说我认为的时候_全片.mp4` | 完整影片，约 10 分 10 秒，从序幕一直到「谢谢大家」 |
| `film/分段_00_序幕.mp4` … `film/分段_05_回到最初的选择.mp4` | 同一部影片按部分切开（每段从转场的闪光处开始），讲到哪部分就播哪段 |
| `film/时间轴.md` | 每一句话出现的时刻，用来对照练习语速 |

每一部分在画面上是怎么"演"的：

| 部分 | 画面 |
| --- | --- |
| 序幕 | 洪流从黑暗中浮现，轨道环绘出，标题逐字聚焦，「我认为」转金 |
| 一 · 多数人的答案 | 答题卡 A B C D → 铅笔涂满 A → 大量选票飞向 B 堆成一片 → A 颤抖 → 选票被吹散回洪流 → A、B 各自分出"背后的理由" |
| 二 · 我们的思想，真的独立吗？ | 「要努力学习。」等"别人的话"在四周浮现，再被吸进"我" → 三重围墙合拢（只相信自己）→ 围墙里只剩一个问号 → 勾股定理艰难地画出来，同时"距离高考"倒计时归零，盖上「高考结束」→ 银色的"前人的公式"和金色的"自己的推理" |
| 三 · 独立思考，就是不断怀疑吗？ | 「只要足够努力……」这句信念被一道裂纹劈开 → 两股气流对冲（冲突）→ 一点金色火花（起点）→ 新结论被红线划掉 → 新旧两个判断并排接受检验 → 层层嵌套、不断缩进的"怀疑"框 → 试卷被收走，只剩一个问号 → 洪流重新平静、有序 |
| 四 · 定义域与自由 | 蓝图网格、坐标轴、f(x) → x > 0 的阴影 → 阴影扩张成 x ∈ R、随手的草稿 → 弹回 x > 0 → x = −2 撞上边界被划掉 → 边界亮起 → 一条路分出许多条路，犹豫时闪烁 → 实线边界（真实存在）和虚线边界（未经质疑的假设）；虚线碎裂散去 |
| 五 · 回到最初的选择 | 答题卡回来 → "独立？""盲从？"被划掉 → 一条转向但没有断开的金线（改变观点不是屈服）→ 一条穿过"检验"环的直线（坚持不是固执）→ 一条随洪流前进、再回过头来的金线 → 终问 → 谢幕 |

转场：镜头加速推进"眼睛"，光线沿椭圆方向拉成星轨，轨道环飞掠而过，眼中心爆出一道光，随后减速"抵达"，光笔写出新部分的编号和标题。每部分开始后，标题缩进左上角作为小标签。

### 怎么配合演讲

- **跟着影片讲（最好的效果）**：影片按约 230 字/分钟排好了时间，大约是从容、有停顿的演讲语速。拿 `时间轴.md` 对照着练两三遍，就能和画面同步。
- **分段播放（最稳妥）**：PPT 里每页放一段 `分段_*.mp4`（开始方式"自动"，不要循环），讲到下一部分就翻页。每段都从转场的闪光开始，翻页时衔接很自然。如果某一段你讲得比画面慢，这一段会停在最后一帧；最后一帧是这一段最后一句话收尾后的平静画面。

## 设计概念：千流与一线

| 画面元素 | 对应演讲里的意思 |
| --- | --- |
| 银蓝色的光丝洪流，几万条细线朝同一个方向流动 | **多数人的答案**：大家都选了 B |
| 画面中央一块安静的椭圆"眼"，洪流从它两侧绕过 | **「我」**：世界从身边流过，我仍然站在这里思考；标题就放在这里 |
| 金色的丝线：被同一股洪流带着走，却又遵循自己的场，斜斜地穿过银色流线 | **接受影响，但不等于服从影响**。它不是逆流，也不是为了与众不同 |
| 椭圆轨道环、端点刻度、四角裁切线、边缘标尺 | **定义域与边界**：数学课里的 x > 0 |
| 一阵阵移动的"月光带"照亮洪流的不同部分 | 让画面在 7 分钟里始终有呼吸感，不显得重复 |

技术上，流场是"流函数的旋度"，所以它不可压缩：线条不会挤成一团，看起来像丝绸。洪流绕过椭圆使用的是精确的势流解，金线拥有自己独立的周期场。慢速粒子按"长曝光"做能量归一化，避免驻点处堆出亮斑。最后再做线性光合成、多级泛光、胶片颗粒和分离色调。

`python3 verify_seams.py` 会逐个检查循环接缝和「片头→循环」交接，确认它们与片内普通关键帧过渡没有区别。

所有循环版本共用**同一股洪流**（同一套模拟，只是中间的文字不同）。所以在 PPT 里用"淡化"切换时，观众看到的是文字在同一条不停的河流上变换，而不是换了一段视频。

## 在 PowerPoint 里怎么用（推荐做法）

1. **第 1 页 片头**：插入 `01_片头_标题动画.mp4`，铺满全屏。
   - 播放 → 开始：**自动**；不要勾选"循环播放"。
   - 切换 → 换片方式：勾选"设置自动换片时间"并填 `00:15.00`。片头放完会自动进入下一页。
2. **第 2 页 主标题**：插入 `02_循环_主标题.mp4`，开始：**自动**，勾选 **"循环播放，直到停止"**。
   切换效果选 **"无"**，因为片头最后一帧和循环第一帧本来就是连续的。
3. **第 3–7 页 五个章节**：各插入一个章节视频，开始：自动，勾选循环播放；
   切换效果选 **"淡化" / "淡出"，持续时间 1.00 秒左右**。讲到哪一部分，就翻到哪一页。
4. **最后一页**：`09_结尾_谢谢大家.mp4`，同样循环 + 淡化。

> 不想翻页的话，从头到尾只用 `02_循环_主标题.mp4`（或纯净版）循环播放也完全可以。
> 视频是 H.264 / MP4，Windows 和 Mac 上的 PowerPoint、WPS、Keynote 都能直接播放。

## 重新渲染

```bash
# 1. 字体：思源宋体 Source Han Serif SC（SIL OFL 1.1），从 npm 获取
npm pack @fontpkg/source-han-serif-sc && mkdir -p fonts && tar -xzf fontpkg-source-han-serif-sc-*.tgz -C fonts
# 2. 依赖
pip install numpy opencv-python-headless numexpr pillow
# 3. 预览几帧（PNG）
python3 render.py --fonts fonts/package preview --frames 0,600 --intro 6,9.5,12
# 4. 完整渲染（4 核约 40–60 分钟）
python3 render.py --fonts fonts/package render
# 全文影片：先看几帧，再完整渲染（分块并行；每块先预热 1000 帧，所以块与块之间的洪流是连续的）
pip install fonttools
python3 film.py --fonts fonts/package stills --t 18,40,165,300,410,575
python3 film.py --fonts fonts/package render --jobs 4
```

全文影片的文字和每句的时长在 `film.py` 顶部的 `SECTIONS` 里（`{…}` 表示金色强调）。每一部分的画面写在对应的 `S1`…`S5` 类里，引用的是句子的开始时间，所以改动文字后，画面会自动跟着重新排时间。

想改文字，可以修改 `Title`（主标题）和 `CHAPTERS`（各章节标题与金句）。颜色在 `Compositor` 和 `Title` 里。
无缝循环靠的是三条约束：每个流场模式在 60 秒内都转整数圈；每个粒子的寿命都能整除循环长度；
重生位置来自按周期取值的表。修改参数时请保留这三条约束。
