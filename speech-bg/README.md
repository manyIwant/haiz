# 「当我们说"我认为"的时候」演讲背景视频

语文演讲《当我们说「我认为」的时候——关于独立思考与自由》的配套背景动效。
全部画面由 `render.py` 以程序化方式逐帧渲染（无素材、无模板），1920×1080 / 30fps / H.264。

## 设计概念：千流与一线

| 画面元素 | 对应演讲里的意思 |
| --- | --- |
| 银蓝色的光丝洪流，几万条细线朝同一个方向流动 | **多数人的答案**：大家都选了 B |
| 画面中央一块安静的椭圆"眼"，洪流从它两侧绕过 | **「我」**：世界从身边流过，我仍然站在这里思考；标题就放在这里 |
| 金色的丝线：被同一股洪流带着走，却又遵循自己的场，斜斜地穿过银色流线 | **接受影响，但不等于服从影响**。它不是逆流，也不是为了与众不同 |
| 椭圆轨道环、端点刻度、四角裁切线、边缘标尺 | **定义域与边界**：数学课里的 x > 0 |
| 一阵阵移动的"月光带"照亮洪流的不同部分 | 让画面在 7 分钟里始终有呼吸感，不显得重复 |

技术上，流场是"流函数的旋度"，所以它不可压缩：线条不会挤成一团，看起来像丝绸。洪流绕过椭圆使用的是精确的势流解，金线拥有自己独立的周期场。慢速粒子按"长曝光"做能量归一化，避免驻点处堆出亮斑。最后再做线性光合成、多级泛光、胶片颗粒和分离色调。

所有循环版本共用**同一股洪流**（同一套模拟，只是中间的文字不同）。所以在 PPT 里用"淡化"切换时，观众看到的是文字在同一条不停的河流上变换，而不是换了一段视频。

## 在 PowerPoint 里怎么用（推荐做法）

1. **第 1 页 片头**：插入 `01_片头_标题动画.mp4`，铺满全屏。
   - 播放 → 开始：**自动**；不要勾选"循环播放"。
   - 切换 → 换片方式：勾选"设置自动换片时间"并填 `00:15.00`。片头放完会自动进入下一页。
2. **第 2 页 主标题**：插入 `02_循环_主标题.mp4`，开始：**自动**，勾选 **"循环播放，直到停止"**。
   切换效果选 **"无"**，因为片头最后一帧和循环第一帧本来就是连续的。
3. **第 3–7 页 五个章节**：各插入一个章节视频，开始：自动，勾选循环播放；
   切换效果选 **"淡化" / "淡出"，持续时间 1.00 秒左右**。讲到哪一部分，就翻到哪一页。
4. **最后一页**：`09_结尾_谢谢大家.mp4`，同样循环 + 淡化。

> 不想翻页的话，从头到尾只用 `02_循环_主标题.mp4`（或纯净版）循环播放也完全可以。
> 视频是 H.264 / MP4，Windows 和 Mac 上的 PowerPoint、WPS、Keynote 都能直接播放。

## 重新渲染

```bash
# 1. 字体：思源宋体 Source Han Serif SC（SIL OFL 1.1），从 npm 获取
npm pack @fontpkg/source-han-serif-sc && mkdir -p fonts && tar -xzf fontpkg-source-han-serif-sc-*.tgz -C fonts
# 2. 依赖
pip install numpy opencv-python-headless numexpr pillow
# 3. 预览几帧（PNG）
python3 render.py --fonts fonts/package preview --frames 0,600 --intro 6,9.5,12
# 4. 完整渲染（4 核约 40–60 分钟）
python3 render.py --fonts fonts/package render
```

想改文字，可以修改 `Title`（主标题）和 `CHAPTERS`（各章节标题与金句）。颜色在 `Compositor` 和 `Title` 里。
无缝循环靠的是三条约束：每个流场模式在 60 秒内都转整数圈；每个粒子的寿命都能整除循环长度；
重生位置来自按周期取值的表。修改参数时请保留这三条约束。
