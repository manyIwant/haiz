# haiz-type-and-content

## 何时使用
在工具页面用具体、简短、能够帮助用户完成工作的中文；学生活动专题可有人文表达，但不能套用到按钮上。

## 实施流程
1. 文案审计：把标题分为任务名称、页面名称、操作、状态、帮助、品牌内容。删去没有提供行动信息的口号和英文装饰眉题。
2. 重点考虑中文字符宽度、全角标点、数字日期、时间格式、长科目名、繁简切换与 Dynamic Type；不要一味把英文大写当作高级。
3. 实施信息层级：当前/下一节课与待完成任务最清晰；辅助状态次之；来源信息可逐步展开。
4. 操作反馈要如实表达本机/云端状态：“已保存到本机”“等待同步”“云端冲突，请选择”不是通用“完成”。
5. 为权限、OCR、通知监听写同意内容：收集什么、用途、保存位置、如何关闭。避免吓人或遮掩。
6. 以真实数据表验证：长标题、多行、凌晨跨日、无日期、错误消息、语音读屏。

## 验收条件
- 能去掉所有没意义的励志标题而不损失信息。
- 任何失败、离线、权限、空状态都有具体且准确的文案。
