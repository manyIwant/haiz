# haiz-anti-ai-ui

## 何时使用
Anti-slop 审美闸门；这是核心设计质量约束，不是简单禁用任何玻璃或渐变。

## 实施流程
1. 扫描界面文案：标记“今天也要闪闪发光”“留一点时间给自己”“一所正在发生的学校”等不帮助用户决策的文字。把它们替换成任务、时间、地点、状态或操作说明。
2. 每个大卡片回答：为什么必须是容器？是否可用列表、行分隔、留白或轻微背景代替？是否提供实际信息？
3. 警惕“4 张统计卡 + 英文眉题 + 大数字 + 渐变按钮 + 名言式标题”的模板结构；同一屏不能全是视觉主角。
4. 审查每个光效、blur、阴影、动效是否表达层级、反馈、连续性；没有功能价值则降级/删除。
5. 验证中文真实内容的排版，包含长作业题目、多个日期、不确定截止时间、空列表、保存失败。
6. 通过截图对比检查视觉层级，记录所有删除或保留装饰的理由。

## 验收条件
- 核心任务不依赖“氛围标语”才能被理解。
- 不同页面密度因任务而不同；不是机械同一栅格。
- 每处装饰有明确意义，且降效后仍易用。
