## 安全处置流程

1. 为候选分支查询完整 SHA、是否可达 main、是否被 Git 标签/工作流/文档/其他 PR 引用，以及是否仍有独立提交。
2. 对有依赖的 PR 自底向上核查，保留所有仍含未合并功能与安全修复的分支。
3. 确认为无独立内容后才能删除分支；关闭 PR 前须记录为何替代、原 HEAD、可能需要的恢复路径。
4. 不批量自动删除，不强推，不在未验证依赖前改 PR 的 base。
