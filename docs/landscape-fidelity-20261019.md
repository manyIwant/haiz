# 校园画面改进 · 2026-10-19

本轮目标是缩小模型与项目已有实拍的差距。主要对照 `campus_yanchi.jpg`、`campus_kexue.jpg`、`campus_yihao.jpg` 和 `fengqitang-1600.jpg`；日期按北京时间记录。

## 实际完成的画面工作

- 使用本地 **Blender 4.3.2 / Cycles** 制作三种有侵蚀凹槽、层状轮廓的石材，每种提供 1,808 / 288 三角面的两级几何。表面颜色、法线和遮蔽/粗糙度/金属度以三张 1024×1024 图片嵌入 GLB，不需要联网贴图或额外解码器。
- 砚池题名石采用实体轮廓、倒角和布尔凹刻，红色赋予刻槽内表面。文字以 Noto Serif CJK 排版，是照片题名的近似表达，未描摹原书法。题名石只放在砚池，不复制到植物园水景。
- 石岸由不规则层叠构成，近处使用详细网格，48 个模型单位之外或低画质时切换到低面数版本。两个水景共用六个几何模板和贴图；每处石岸每级仅三批实例。主砚池的石材三角面从 74,128 降至 11,808，约减少 84%。
- 椰树从整条带状叶面改为弯曲叶轴与独立羽状小叶；增加树皮环纹、带折面的阔叶植物及叶脉细节。静态合批保留顶点色与风动深度材质，使叶色变化和阴影跟随变形。
- 科学馆按实拍改成真实进深的外廊、连续白栏板、细柱、金属窗栏、窗上滴水檐及低矮屋顶构件。保留原占地、楼层数据和实心内部；不声称重建未拍摄的实验室。
- 墙面扫描材质采用统一尺寸投影，避免整张贴图被拉长到大立面或挤在细柱上。窗面改用深色介电材质、反射与可重复的百叶/窗缘明暗变化；这是着色近似，不是室内光线追踪。
- 主砚池仍使用一个平面反射，分辨率从 256² 调整至 512²；低画质关闭反射。石材随地面湿度变暗、降低粗糙度。移除砚池照片中未见的巨大浅绿圆形睡莲。
- 实拍对照新增砚池、科学馆和“照片与模型并看”：模型图来自当前真实 WebGL 画布。桌面左右排列，手机上下排列；可返回场景继续行走与调整机位。没有把实拍贴到镜头前冒充建模。

## 可复现资产

```sh
blender -b -t 4 --python scripts/build-landscape.py
```

需要 Blender 4.3.2、随 Blender 可用的 NumPy，以及系统 Noto Serif CJK 字体
`/usr/share/fonts/opentype/noto/NotoSerifCJK-Regular.ttc`。

输出：

- `assets/walk/models/campus-limestone.glb`：网页使用的模型，约 5.75 MB。
- `assets/walk/models/campus-limestone.json`：生成器版本、面数、字形来源及当前 SHA-256。
- `build/landscape/haiz-limestone.blend`：本地可编辑源场景，已打包烘焙图片；图片也保存在同一目录。该目录是被忽略的可再生输出，仓库保留完整生成代码。

模型与新烘焙贴图按 CC0 提供；既有照片、其他开源模型和独立窗台应用保持各自原许可。图像素材没有从游戏中提取。

## 验证与对照

```sh
npm run build
npm test
npm run test:landscape
```

普通回归覆盖原有页面、电影首页、路线、所有教室往返及碰撞。新浏览器检查实际解码 GLB，验证完整 PBR 通道、有限几何值、题名石唯一性、近远/低画质切换、实际着色器、晨光与雨后、并排对照、手机布局和模态框关闭后的状态恢复。另在触摸与减少动态效果模拟环境主动阻断 GLB 请求，检查回退后仍能进入校园和操作对照。

机器报告：`tests/landscape-browser-results.json`。人工观察截图位于被忽略的
`tests/artifacts/landscape-*.png`，包括砚池、科学馆、凤栖堂、一号楼、两种天气和手机对照。
本环境使用 SwiftShader；未测量真实手机帧率。

## 仍存在的差距

现有照片没有相机内外参、同场景多角度覆盖或现场尺寸。当前几何、构图、年代和光照不能逐像素匹配照片；测试通过也不等于照片级复刻。校园整体比例、建筑背面、真实种植分布、墙面老化和雕塑仍有明显近似。当前版本不输出没有依据的“相似度百分比”。

梦想之路的原 XAPK 地址本轮实际重试仍返回 HTTP 403（响应服务器标记为 Envoy）。2026-10-19 北京时间再次检查时，云环境状态已报告 unrestricted，但实际下载请求仍被拒绝；仅凭状态标签无法确定拒绝发生的具体层级。没有取得安装包，因此没有宣称核实游戏引擎、着色器或天气实现。此次改造根据真实校园照片和可在当前环境运行的 Blender 流程独立完成。
