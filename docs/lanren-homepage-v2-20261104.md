## 艺术方向：岛上的一棵树

- **没有建筑。** 粗糙的教学楼背景已移除。树立在雾中静水里的一座小岩岛上：海南是岛，校园里有砚池；静水给出倒影，雾与光承担空间层次。整体是**物种概念模型**，不是校园那棵树的测绘，页面上也这样标注。
- **树的形态。** 成年、孤立生长的大叶榄仁：短而粗、带板根的主干在约 2.7 m 处分出六根蜿蜒主枝，斜升后转为近水平伸展；枝叶聚成一层层水平叶盘（榄仁树典型的层状平展枝叶），叶盘之间留出天空，形成比树高更宽的伞状树冠。保留一根低而长、下探近水面再昂起的横枝，呼应校园那棵树「枝叶如龙腾伸展」的描述。
- **体积光照。** 每片叶子的法线在远处向所在叶盘的外法线混合，近处保留叶片自身起伏；树冠因此有受光面、背光面与透光的边缘，而不是一片片纸片。
- **一天，也是一个春天。** 滚动绕树一圈，光从黎明走到黄昏（每个视角单独布光：逆光、侧光、透光），树从冬末醒来。

## 生长：真实的结构变化，而不是淡入或缩放

榄仁树在海南冬末落叶、春天抽新梢、长新叶。滚动进度 `g`（0 → 1）驱动这一过程：

1. **冬末（g = 0）**：主枝、次级枝完整，三级枝只有约三分之二；约 320 个叶簇还挂着去年的红叶。
2. **红叶脱落（g ≈ 0.02–0.2）**：每片旧叶有自己的脱落时间；越过时它真的离枝，在风中翻转飘落，落在岩岛上或浮在水面漂移。倒着滚动时，叶子回到枝上。
3. **抽梢（g ≈ 0–0.45）**：三级枝末端与当季小枝从梢端延伸。每个树皮顶点在 Blender 中写入「出生时间」与环半径（TEXCOORD_1），着色器把尚未出生的环收拢到枝轴上，所以枝条是**从梢端长出来、随后加粗**的，切面连续。
4. **展叶（g ≈ 0.05–0.77）**：每片叶子有自己的萌发时间（梢端先、向外扩展）。芽是折叠、直立、古铜红的小芽；随后中脉对折逐渐打开、叶片从直立转为平展、长到全尺寸，颜色经嫩黄绿转为深绿。
5. **繁茂（g = 1）**：约 8.6 万片叶（高画质）、草从枯黄转绿、岩上苔藓转绿。

- 六个视角沿同一方向每步约 65° 平稳绕行，共约 314°。镜头在柱坐标中插值（方位、对数半径、高度），过渡时自动退到树冠包络之外，不会穿过枝叶或树干。
- 原生滚动（滚轮、触控板惯性、触屏、空格 / PageDown / End）由 **GSAP ScrollTrigger** 映射为进度：`scrub` 平滑，`snap` 吸附到视角（关闭惯性投射以免环形导航多走一站，保留方向性：轻滚即去往下一站）。
- 右下角**环形导航**是俯视的绕树轨道：每个点在它真实的方位上，指针随相机方位实时转动；点击即走到该视角。
- 每个视角的首要入口以玻璃卡片钉在画面里的真实部位（加载时从该视角射线求交树皮、岩岛或叶簇），细线连到落点；其余入口是可读的文字列表。点击时镜头推向落点，帷幕从点击处展开后跳转；返回主页时回到离开的视角。
- 文字层用 GSAP 时间轴：英文标题逐行遮罩揭示，中文与条目依次浮现。英文展示字体为自托管的 Cormorant Garamond（SIL OFL）。
- `index.html` 由 `scripts/lanren/build-home.mjs` 从 `lanren/js/chapters.js` 生成，所以无 JS / 无 WebGL 的静态页与三维视角描述同一组板块（18 个入口）。

## 渲染（Three.js r170）

- 叶片：独立实例（高 / 中 / 低 = 0.72 / 0.5 / 0.34 密度），生长、风、触碰都在顶点着色器中；阴影深度材质同步。
- 光斑：沿用 PCSS（按太阳视直径计算半影）。
- 水面：`Reflector` 实时倒影（高画质全分辨率、中画质半分辨率，低画质仅天空反射），微弱的大尺度涟漪。
- 后期：场景渲染到带 MSAA 与深度纹理的独立目标 → 大气通道（指数高度雾的解析积分、太阳方向前向散射、水面贴地薄雾、朝太阳屏幕位置步进的光束）→ 景深（仅近景视角，由深度计算弥散圆）→ 辉光（高 / 中）→ ACES 色调映射 → 分离色调、暗角、颗粒。
- 帧时持续过长时自动降低像素比。

## Blender 流程

`scripts/lanren/build_tree.py`（Blender 5.2 / PyPI `bpy`）生成树、岩岛与叶簇；Cycles 把 AO 烘焙进顶点色；生长数据存入第二套 UV，因为 gltfpack 会丢弃自定义属性但保留标准属性。`scripts/lanren/pack.sh` 用 gltfpack（meshopt）压缩。产物：树 4.3 MB（约 21 万顶点，含生长数据）、岛 0.2 MB、叶簇 0.9 MB（14687 个叶簇，37 个叶盘）。

## 验证

- `node tests/lanren.cjs`：生长随进度单调；镜头路径连续（每 1% 进度 ≤ 0.54 m）、始终在水面以上、不进入树干、共绕行 314°；各视角光照参数完整；18 个入口存在且与生成的 HTML 一致；Blender 资产的生长数据、叶盘与去年红叶。
- `node tests/home-browser.cjs`（Chromium + SwiftShader 软件渲染）：原生滚动进入视角 02 且生长值正确、环形导航点击到达 04、End 键到达 05 且满叶、接住飘落的叶子并夹进书页、点击条目经帷幕跳转、返回后回到视角 02 且书页仍在、静态回退列出全部入口、390×844 手机无横向溢出。
- 过程中发现并修复：滚动吸附惯性导致多走一站；初始化顺序覆盖了「返回原视角」的记录；镜头路径在树冠包络处跳变；季节/生长曲线连续性。
- **未在真实 GPU 与真机上测帧率。** 软件渲染约 0.1–0.3 fps，截图只代表画面，不代表流畅度。高画质（8.6 万片叶 + 倒影 + 4096 阴影 + 后期）面向桌面独显；集成显卡与手机默认中 / 低画质，实际帧率需真机确认。

```bash

blender -b --python scripts/lanren/build_tree.py   # 树、岛、叶簇（或 PyPI bpy）
./scripts/lanren/pack.sh                           # gltfpack 压缩
node scripts/lanren/build-home.mjs                 # 由 chapters.js 生成 index.html
node tests/lanren.cjs && node tests/home-browser.cjs
node tests/lanren-capture.cjs tests/artifacts/v2 0 1 2 3 4 5        # 各视角评审截图
node tests/lanren-capture.cjs tests/artifacts/look "L,30,7,-20,2.5,6.5,0.4,5"   # 看样：自定机位与生长阶段
```

`?quality=low|medium|high` 固定画质，`?static` 查看静态页。
