## 补全与纠正

- 原来已经有六片篮球场，但它们硬编码在操场对象中；整体连同缓冲带超出了原 `court_basket` 矩形，并侵入相邻场地区域。现在改为独立、数据驱动的 3 × 2 排布，严格落在既有占地内，并非宣称新发现六片此前不存在的场地。
- 原 `court_volley` 仅以绿色地块表示。本轮改为硬地排球区，补场线、六根网柱与三张网。**三片的细分数量是基于旧矩形的配置推演，影像不能确认**；用途名称来自旧数据。三处地图均提供推演说明，不把它当作已核实的校园现状。
- 篮球场补十二套立体支柱、篮板目标框、篮圈、收口篮网；蓝色颗粒面层、暖色中圈/限制区及完整场线均为原创程序重建。影像用于区分区域和大色块，不是扫描纹理；篮架样式、颜色、精确尺度和缓冲距离仍是解释性表达。
- 操场跑道和看台保留。34 个原有建筑节点、两个坐标锚点、道路、水体与原始树木点数据不移动。场地占用登记阻止散布树生成在球场内，场景树数由 305 变为 295；这是纠正穿插，不是降低植被画质。原始树点仍保留，便于后续核对。
- 漫游大小地图、导演台 SVG 和学校介绍页手图使用同一份派生场地数据。学校页原先读取 `data/buildings.json`，现改读 `assets/walk/campus.json`；两者原有建筑矩形与坐标变换一致。

维护入口为 `data/campus-sports.json`。构建时按 `sourceLawn` 从原数据查找占地，缺失就报错；不会在脚本里偷偷换坐标。执行 `npm run build` 同步 JSON 与离线回退脚本。原 `lawns` 记录保留作来源，不再重复绘制成草地。

## 性能改动及证据

1. 小地图不再每次重画道路、楼宇、网格和地标文字。按原画布分辨率缓存静态底图，移动时只合成位置/朝向标记，位置和朝向未变则完全跳过。大地图第一次打开才建立自己的缓存，尺寸变化或显式失效后重建。
2. 场线采用不透明材料，地面涂装、篮架、篮网及球网按共享材质合批，并沿用既有索引几何和静态变换缓存。透明轮廓用 alpha-test，网孔可透视，不新增每帧 JS 几何更新。
3. 不调整分辨率、阴影尺寸、反射配置或原有动画更新频率；不恢复阻塞式资源预热。新纹理为本地程序生成，复用已存在的颗粒/法线/粗糙度资源；没有新增外部图片、模型或运行时 CDN 请求。

`tests/map-results.json` 与 `tests/sports-browser-results.json` 分别在原生 Canvas2D 和 Chromium 比较 360/1000 像素地图：四组位置/朝向的缓存版和直接重画版逐像素一致；位置标记正常更新，100 次静止调用没有额外合成。CPU 耗时只用于排查实现，不换算成手机 FPS。

`tests/performance-browser-results.json` 以固定 640 × 400 的真实 WebGL 场景检查索引保留和静态变换缓存：与同一新版场景的展开/逐帧变换版本比较帧缓冲，同时核对 4000 个碰撞样本和吊扇动画。报告内历史 `baseline` 早于艺术中心细化，不应当作本轮直接前后对比；前一提交 `9b587f8` 的同测试记录可从 Git 历史取得。

本轮最终场景在该固定机位记录 417 次绘制调用，前一提交记录为 568；像素比例仍为 1、阴影仍为 2048，每帧矩阵组合仍为 92。减少调用包含场线合批与场地/树木穿插修正的综合影响，不是纯 GPU 算法提速百分比。新增十二套篮架与篮网后，篮球区为 8 个网格批次，排球区为 6 个。缓存/非缓存、索引/展开的帧缓冲差异均为 0，4000 个碰撞样本也无差异。

场地纠偏、涂装与篮架是可见内容变化，不能称为与旧版画面逐像素相同；逐像素一致只针对**同一新版场景的性能实现开关**。云端使用 SwiftShader，未做真实手机硬件帧率测试，也不保证任何设备绝不卡顿。

## 验证与复现

```sh
npm run build
npm test
npm run test:map
npm run test:performance
npm run test:loading
npm run test:browser
```

- 几何：场地/篮架不越原矩形、场地内部可走、柱体有碰撞、散布树不穿入球场、球网合批，保留教室和原有路线通行。
- 实际浏览器：球场俯视与地面视角、晨光/雨后渲染、390 px 地图弹窗开关、触摸模拟下导演台与校园手图操作、请求与脚本错误检查。
- 加载：默认首页仍与 `descent.html` 一致；点击前不请求校园，校园握手不可用也不阻塞开场。
- 发布缓存：三处地图请求和离线回退脚本统一更新版本号，避免旧缓存数据缺少 `sports` 而导致新版本球场消失。
- 本地截图：`tests/artifacts/sports-overview.png`、`sports-ground.png`、`sports-map-mobile.png`。截图由测试拍摄，不是参考照片，也不混用为摄影效果证明。
