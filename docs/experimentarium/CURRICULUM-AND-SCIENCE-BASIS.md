# HAIZ · EXPERIMENTARIUM — 课程映射、科学依据与合规边界

## 1. 课程标准依据与海南地区教材版本政策

### 1.1 课程标准框架
全目录严格依据中华人民共和国教育部颁布的《普通高中课程标准（2017 年版 2020 年修订）》各学科课程标准中的“学生必做实验”、“必修/选择性必修核心探究活动”及学科核心素养要求梳理建档，不按主观预设凑数。

### 1.2 海南中学教材版本诚实核查原则
针对“不要未经核实就假定所有学科采用同一出版社教材，不要虚构内部教材版本或官方要求”的底线原则，我们在 `curriculum-matrix.json` 中确立严格的两级字段 `editionVerificationStatus`：
- **`confirmed-national-unified`（国家统编教材已确认）**：适用于**语文、历史、思想政治**三科——依据国家教材政策，全国普通高中统一使用人民教育出版社统编版教材。
- **`provincial-mainstream-pending-school-booklist`（省主流目录参考·待核对海南中学当学期校本征订清单）**：适用于**物理、化学、生物学、地理、数学、英语、信息技术、通用技术**八科。矩阵中同时标注海南省中小学教学用书目录主流并行版本（如物理同时标明人教版 2019 与鲁科版、化学同时标明人教版与鲁科版/苏教版参考条目、英语注明人教/外研并行、信息技术注明浙教/沪科/教科参考），待海南中学内部征订书单核实后即可一键精准锁定，绝不在未见原件前妄断或捏造。

## 3. 各学科知识结构与核心科学模型边界

1. **物理科学模型与误差分离原则**：  
   - **单摆（`phy-pendulum`）**：四阶龙格–库塔求解 $\theta'' = -(g/l)\sin\theta - \gamma\theta'$（步长 $1/240\,\text{s}$）对比小角解析模型 $\theta'' = -(g/l)\theta - \gamma\theta'$；明确假设悬线无质量不可伸长、质点摆球、仅取线性阻尼项；专设“漏加摆球半径 2.5 cm”误区开关暴露 $T^2\text{–}l$ 纵截距系统偏差。
   - **牛顿第二定律（`phy-newton2`）**：暴露 $m_{\text{钩}} \ll M_{\text{车}}$ 成立边界，真实加速度 $a = (m_0 g - \mu Mg\cos\theta + Mg\sin\theta)/(M+m_0)$ 使 $a\text{–}F$ 图像在高拉力段真实向下弯曲。
   - **测金属丝电阻率与电动势内阻（`phy-resistivity-caliper`, `phy-emf`）**：真实内置电压表内阻（$3000\,\Omega$）与电流表内阻（$0.5\,\Omega$），令“电流表内接法 vs 外接法”产生的系统误差可以直接在回归直线与待测值之间定量读出。
2. **化学平衡与热力学求解原则**：  
   - **酸碱滴定（`chem-titration`）**：严禁使用固定预设数组，而是对强酸及弱酸按 $\mathrm{H^+ + Na^+ = OH^- + A^-}$ 全区间电荷与物料守恒实时二分求解（误差 `< 1e-12`），因此强碱滴弱酸时的半当量缓冲平台（$\mathrm{pH = pK_a}$）与碱性等当点突变全属自然涌现。
   - **粗盐提纯（`chem-crude-salt`）**：用化学反应状态机检查 $\mathrm{BaCl_2, NaOH, Na_2CO_3, 过滤, HCl}$ 的实际加样排列组合，证明只要碳酸钠早于氯化钡或盐酸加在过滤前，就会必然留下 $\mathrm{Ba^{2+}}$ 杂质或使沉淀复溶。
3. **生物学统计与显微形态模型**：  
   - **有丝分裂（`bio-microscope-mitosis`）**与**孟德尔遗传（`bio-mendel`）**：采用确定性伪随机核相/配子模拟并配以 Pearson 卡方检验 $\chi^2 = \sum (O - E)^2 / E$ 与自由度对照门槛，让学生真正看到“样本量越大，随机波动才向理论比率收敛”。
4. **地理、数学、技术与人文社科**：  
   - **海口热带海绵校园水文（`geo-sponge-hydrology`）**：基于海南台风强降雨情景，计算渗透率、滞留蓄水与线性水库汇流过程线，定量展示透水砖/绿屋顶对洪峰削减与峰现延迟效应；严禁将其用于现实防洪工程设计认证。
   - **圆锥曲线统一定义（`math-conic-locus`）**：实时计算与双圆锥和截平面同时相切的丹德林球心、半径、焦点、焦半径与截面偏心率 $e = \sin\theta/\cos\alpha$，以及 $d=0$ 时退化为单点/母线/双相交直线的奇异过渡。
   - **诗律与三段论（`chn-meter`, `chn-syllogism`）**：严格标注常用唐诗字表外的生僻字进入“待查”而不强行乱判；词项逻辑采用四格 256 式形式检验规则严格捕捉中项不周延及大小项不当周延谬误；历史双轨时间尺跨越公元前后且遵循“无公元 0 年”规则，并对公元前 841 年共和元年以前注明断代争议区间。
