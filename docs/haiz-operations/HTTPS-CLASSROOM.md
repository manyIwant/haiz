# HTTPS 教师到教室的授权作业链路

更新：2026-10-25。本轮为受控虚构数据试用，不是学校正式部署；新增内容没有制作成新的APK/IPA。

## 已贯通的路径

现有 HTTPS Flow 邀请登录 → “班级作业” → 教师预览发布 → 同一服务端存储 → 授权教室/学生会话读取 → 教室客户端状态报告 → 教师查看接收状态。

教师、管理员、学生与教室共用既有HttpOnly/Secure/SameSite会话、Origin校验、会话到期/撤销和速率限制。前端不再跳往HTTPS服务未提供的旧`../#homework`页面。管理员结束试用的明确清理操作同时清理Flow与公共作业，撤销其他会话。

`world/classroom/assignments.mjs`是共享作业命令规则：旧localhost服务和HTTPS服务共同使用它处理角色/范围/归属、乐观版本、容量和持久化幂等约定。两个部署各自保存数据，**没有自动将旧localhost内容同步或迁移到HTTPS服务**。HTTPS身份当前仍为固定虚构班级，不是正式学籍/教务目录。

## 教师与只读客户端

- 教师可切换自己的授权班级，保存当前会话草稿、预览、返回修改、发布、修改和撤回。管理员可审核待审内容。其他教师不能修改发布者内容。
- 学生与教室只取得本班、当天、已审核、未撤回清单；响应不包含发布者账号字段或任何私人Flow正文。
- 教室可手动隐藏。更新不会自动覆盖隐藏选择。首屏明确标为手动展示，没有声称接入真实ClassIsland或自动识别晚修。
- 在线可见页面每10秒拉取一次；窗口重新可见时主动同步，可手动刷新。显示只在当前已打开页面内保留有效公开快照；断网时不承诺冷启动、安装包或完整PWA离线能力。
- 跨日收起缓存；首次读取失败可明确重试；会话撤销/退出后下一次请求401会收起公开列表。后台暂停轮询，不采集个人使用轨迹。
- 页面时间采用Asia/Shanghai，日期由学校日历语义统一。更改客户端日期导致与快照不符时，不报告已呈现。

## 回执的准确含义

回执是受控试用客户端的自报状态，**不是屏幕摄影验证、可信硬件证明或学生已阅读证据**。目前会话被称为“display-a试用会话”，未伪装成已登记的真实教室设备。

服务端向教室返回短期签名凭据，绑定会话、班级、学校日期、清单版本和公开条目的ID/版本摘要。客户端只有在更新DOM并经过绘制机会后报告`rendered`；隐藏时报告`suppressed`，未呈现前仅为`received`。签名仅证明快照归属，不证明浏览器诚实或物理屏幕确实可见。

凭据90秒过期。清单修订或撤回后，旧快照回执被拒绝；其他会话、错误角色和篡改凭据也被拒绝。乱序的旧回执不能覆盖较新的状态。同一凭据下`received`不能降级覆盖已经上报的呈现/隐藏。服务端返回回执剩余有效时长，教师页面也会在本地递减；即使断网且没有新的服务响应，也不能一直显示新鲜状态。计时从请求发出开始，包含往返耗时；页面重新可见时先撤销旧的新鲜状态，再重新核验。字段包括当天有效条目数，不将未来作业或待审作业混为已显示。

为避免无限增长，新回执提交时清理已撤销或过期会话的旧状态。后续改进已将有效性绑定到本班当天公开条目的ID/版本摘要；其他班级或未来日期作业的更新不再无故让当前清单回执失效。全局修订号继续保留作诊断，不再单独决定本班回执有效性。该改进不是数据库、多校吞吐或可信设备验收。

## 运行与文件

沿用[HTTPS试用部署说明](../haiz-pilot/DEPLOY.md)启动独立服务。只在经授权的测试环境提供可信TLS入口；本轮没有开通公网地址或连接校园网络。

登录`/world/flow/`后点击“班级作业”，到`/world/classroom/`；同一个浏览器会话无需重复输入邀请。不同教师/教室使用分别签发的邀请。固定演示关系：teacher-a可发布演示一班和二班；teacher-b只在三班；display-a、student-a在一班，display-b在三班。

新增私有文件为数据目录中的`classroom.json`，和`flow.json`、`identities.json`一起管理。更新前停止服务并在受控目录备份完整数据目录；身份及邀请文件不得公开。原格式不自动覆盖成新数据，损坏数据会阻止启动。公共作业写入临时文件后原子替换；写盘失败不返回保存成功。该方式适合单进程试用，不是多副本数据库或完成灾备演练的证明。

- 原localhost作业19组浏览器回归、原HTTPS Flow浏览器走查、核心17项、服务4项和Flow/pilot接口3项也已重跑通过。
- 专用CI扩展`.github/workflows/haiz-operations.yml`；本地通过不等于CI、原生或真实教学设备通过。

TLS测试仅在临时目录生成证书，Node客户端信任该测试CA，浏览器仅在测试上下文接受该证书。不是建议正式环境关闭证书验证。

## 当前边界与下一道门槛

本轮贯通了HTTPS中的身份与公共作业；原有Flow通知仍保留自身契约，不伪装成已经完成所有公共内容的数据迁移。未接入学校SSO、正式任课目录、真实教学设备登记、原生App远程身份配置或ClassIsland宿主。原localhost晚修自动逻辑继续保留，但新HTTPS教室页目前为手动展示。

24是认证会话存储上限，不是24个活跃客户端的吞吐验收。本轮仍按小规模三人试用定位；公共快照/回执轮询与已有Flow轮询共享速率预算，扩大试点前需做真实并发、磁盘和网络测试，再调整同步机制与限额。

下一道实质门槛是：在获许可的普通Windows环境固定ClassIsland版本，验证读取最后两节自习、授课时隐藏、休眠恢复和异常停用；再把已验证的只读课表适配输出接入这条HTTPS链路。未达到该门槛前，不能承诺学校晚修自动投屏。

## 教师工作台后续改进

清单支持授权班级、日期、有效/待审/撤回状态筛选，计数区分当前匹配条目与已同步总数。筛选只改变列表，不会修改草稿的班级、日期或正文。发布成功后自动切到本次发布范围，明日作业也能立即在教师端找到；这不改变教室只显示当天有效公开内容的规则。

手机页面提供区域跳转，连接中断只显示中文状态，重连后清除旧警告。`test:workbench:browser`新增10组浏览器检查，覆盖未来日期跨班发布、筛选不丢草稿、待审和撤回区分、只读投影、教师离线本地回执过期、重连及390px布局。时钟受控的浏览器/服务端模拟不等于真实设备休眠测试。

新增送审操作也经过真实表单走查：确认后自动显示待审列表，教室仍只显示原有已审核作业。筛选在刷新页面时回到今天的默认范围，工作草稿单独恢复。

## 多设备版本冲突与草稿恢复

编辑已有作业时，客户端保存当时的公开字段及版本作为比较基线。服务器仍负责最终的权限与版本检查，客户端比较不会替代校验。

另一设备更新后，若两边修改不同字段，会接续独立修改；同一字段两边都改过且内容不同，必须逐项选择本机或服务器内容。冲突项优先显示，无冲突项可展开核对；不拼接两段正文，不调用AI决定。缺少完整基线的旧草稿按保守方式比较，不能推断的差异都需确认。

采用比较结果只返回编辑器，不写服务器；之后仍要预览、确认发布，且基于刚读取的版本。如果其间再次更新，会再次触发冲突。接续新版本后丢弃旧发布请求标识，避免把新的修改当成旧请求重放。读取最新版本期间暂停编辑输入，防止读取返回时覆盖刚输入的新文字。

如果服务器已撤回，比较窗口和之后的预览都会明确提示；重新发布必须再次确认。刷新后过时的工作草稿会恢复原文并提供“比较最新版本”，不再只留一个提示却无法取回文字。记录已不存在或无权修改时，不能凭本机草稿绕过权限。

教师可以导出当前公共作业草稿为TXT；会话失效时清单仍会收起，但原页面保留导出本机未发布草稿的入口。导出仅包含班级、学科、日期、作业要求、准备与交付字段，不自动加入Cookie、账号标识或Flow私人正文。TXT用于人工保留和复制回编辑器，没有宣称是可直接导入的完整备份；用户自行写入作业正文的敏感内容不会自动脱敏。试用仍限虚构数据和可信个人浏览器。

验证入口：`npm --prefix world run test:conflicts:browser`。8组真实TLS浏览器走查涵盖同一教师两台设备、冲突必选、独立修改接续、显式二次发布、刷新恢复、并发撤回、390px导出和退出后的本机恢复。合并规则与导出字段另有2项单元测试，纳入`test:classroom`。本轮未进行学校或原生设备验证。
