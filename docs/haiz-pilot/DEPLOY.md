# 三人 HTTPS 自托管试用

本轮没有公网演示地址。当前环境未配置服务器供应商身份、域名或托管凭据；不能声称已经部署、实际跨物理设备通过。以下是独立的可运行部署包，不是把旧loopback文件服务改成0.0.0.0。

## 运行前提

Node 22、一个由你控制的域名和可信HTTPS证书、同主机Caddy反向代理、可持久化私有目录。需要服务器提供商及域名的实际授权；费用、地区、备份政策由运营者选择，本项目不假设免费额度或数据地域。三个测试者只输入虚构内容。一个实例=一个独立试用空间，不支持多个学校共用同一数据库或多个进程共享文件。

1. 将本源码放在服务器 `/opt/haiz`。创建非管理员用户haiz及其私有持久目录`/var/lib/haiz-pilot`（仅该用户可读写）。
2. 复制 `world/pilot/.env.example` 到服务器私有配置文件，填写你控制的HTTPS来源和存储目录。复制 `Caddyfile.example` 并替换域名。Caddy只转发到本机8790；**8790不可暴露到公网**。不要启用旧classroom-server来承载远程试用。
3. Node22启动：`node --env-file=/etc/haiz-pilot.env /opt/haiz/world/pilot/server.mjs`。可按`haiz-pilot.service.example`安装为受限服务；该示例未在生产系统安装验证。Caddy检查配置并获得可信证书后，通过你的HTTPS域名打开`/world/flow/`。

Node自身仍绑定127.0.0.1；公网TLS由你部署的Caddy负责。PUBLIC_ORIGIN必须准确匹配真实HTTPS来源；Host、Origin、Cookie和CSP不允许为了“能连上”而关闭。此方案的远程能力取决于以上真实部署，当前只做本机HTTPS测试。

## 邀请、撤销和清理

首次启动在数据目录生成`bootstrap-invite.txt`，权限0600，控制台只输出路径，不输出秘密。运营者在服务器私下读取它并通过浏览器登录管理员；使用后文件删除。邀请码30分钟过期；管理员为每台设备签发一次性邀请。手机和桌面选同一个teacher-a，各用一份新邀请。不要把邀请写进URL、截图、仓库、安装包或公开聊天。

身份：teacher-a授权演示一班/二班；teacher-b仅演示三班；student-a/display-a只读演示一班公开摘要；display-b只读演示三班；admin管理邀请和会话但不能读取教师草稿。

会话8小时过期，Secure/HttpOnly/SameSite=Strict，JS不能读取令牌。管理页可撤销指定会话；退出也使服务端会话失效。服务重启保留有效会话和业务状态。最多24会话、24未用邀请，每位教师100草稿，公共通知200条、写请求幂等账本2000条，超限需管理员清理；60秒限速，登录失败也计数。同主机Caddy后的IP限速按代理连接共享计数，适合三人试用；不信任客户端自报的X-Forwarded-For，规模化前需单独设计代理身份与限速。

“清理虚构数据”需输入同名确认文字：删除业务状态，撤销其他会话及所有未用邀请，保留当前管理员会话和最近500条不含正文的安全事件。离线设备不能远程擦除，测试结束时每位测试者要在每个窗口退出/清理站点数据；自习页手记在当前标签会话里，关闭前保留需要的文字。数据文件为JSON、0600、临时文件原子替换，不是加密数据库。磁盘备份由运营者管理，试用后删除业务备份。

管理员邀请过期且没有有效管理会话时：停止服务，备份需要保留的测试数据后，删除`identities.json`和旧bootstrap文件，再启动生成新管理员邀请。该操作使所有旧邀请/会话失效，不应在服务运行中手改文件。业务`flow.json`不会自动删除。

## 本机复现，不需要公网

`node --test world/tests/pilot-server.test.mjs` 自动生成临时自签证书、验证CA、运行HTTPS角色/会话/重启/清理测试，再删除测试目录。

`HAIZ_CHROMIUM=/usr/bin/chromium node world/tests/pilot-browser.mjs` 使用Linux本机Chromium；没有该路径时先在world安装Playwright并下载浏览器，再省略环境变量。测试证书是临时自签：浏览器测试明确忽略该证书错误，不能将此配置带到测试者设备或生产。Node接口测试明确使用临时CA并保持TLS校验。

可信公网TLS、两个物理设备、iPhone/Android安装均未验证。GitHub Pages只可托管公开静态入口，不能提供这些API；不要把私人数据放进Pages。
