# HAIZ LUCENT 设计系统

Obsidian：墨蓝基底、雾白文字、钴蓝行动色，铜杏与青绿仅作局部图形强调。
Porcelain：暖白基底、墨色文字、钴蓝行动色，铜杏承接纸页与桌面。
Ocean：深海青基底、浅青文字、青绿行动色，淡紫和铜杏形成局部对比。

语义变量包括 background-base、surface-raised、surface-secondary、text-primary/secondary、accent-action/warm/extra、border-subtle、glass-nav/lens/highlight 与状态色。代码权威来源为 world/apps/mobile/mobile-shell.css；浅色不是简单翻转深色。

玻璃用于导航和浮层，长文本保留实色表面。界面使用系统中文字体，按钮最小44px，保留键盘焦点。低耗电和减少动效关闭电影与持续弹簧运动，核心操作保持可用。

功能页标题采用“我的书桌”“今日作业”“思考书架”，不修改校园作者的叙事文字。空间渲染目前属于原创概念场景，不能作为真实校园建筑还原。
