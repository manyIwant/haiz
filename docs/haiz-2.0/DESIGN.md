# HAIZ 2.0 设计说明：纸面与朱批

> 适用范围：`app/`（Flutter App / PWA）。根站 haiz.space 的视觉规范仍见仓库根目录 `DESIGN.md`。
> 代码位置：`app/lib/design/tokens.dart`（Token）、`theme.dart`（主题）、`components.dart`（组件）。

## 1. 一句话方向

**墨色写在纸上，只有"现在需要注意的东西"用朱红标出**——像老师用红笔批改作业本：当前这节课、此刻的时间线、逾期的作业、完成时的那一笔勾。其余信息全部靠字号、字重、留白和发丝线组织，不靠卡片、渐变和阴影。

## 2. 研究：从成熟产品里拿到的具体方法

只记录能核实的行为和它在 HAIZ 里的落点；不搬运任何产品的图形、图标或整屏布局。

| 产品 | 观察到的做法 | 为什么有效 | HAIZ 的落点 | 不照搬的部分 |
|---|---|---|---|---|
| Things 3（[App Store](https://apps.apple.com/us/app/id904237743)） | Today 由"已安排的事"自动组成，并拆出 This Evening；Quick Entry 随处新建；勾选后条目短暂停留再离开 | Today 是唯一需要每天看的清单；短暂停留让误触可撤销 | 「今天」= 逾期 + 今天 + 明天到期；完成后行保留 0.9 秒再折叠，配撤销提示；Ctrl/⌘ N 随处录入 | 拖拽 Magic Plus 插入位置（手机上与滚动冲突，学生任务量也不需要） |
| Linear（[2024 重构说明](https://linear.app/blog/how-we-redesigned-the-linear-ui)） | 重构目标是降低视觉噪声、提高导航层级与信息密度；Cmd K 命令面板 | 高频工具的品质来自密度和对齐，而不是装饰 | 列表不套卡片，用发丝线和分组标题；单一强调色；Ctrl/⌘ K 全局搜索 | 深色优先和英文缩写式标签 |
| Fantastical（[视图说明](https://flexibits.com/fantastical-ios/help/calendar-views)） | 顶部日期条 + 下方当日列表，二者联动 | 先选日子，再看细节，两种粒度在一屏内 | 「课表 · 日」视图：周一至周日日期条 + 当日课程列表 + 当前时间线 | 横向滚动的无限日期条（课表以周为单位，7 天足够） |
| Apple HIG 标签栏（[Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)） | 用必要的最少标签，按使用频率权衡每个标签，避免"更多" | 标签栏位置有限，低频功能会挤占高频功能 | 「专注」从标签降为任务上的一种模式；账号、备份、更新从三个悬浮按钮收进「我的」 | iOS 26 的玻璃材质 |
| Bear / Craft | 写作界面几乎无控件，首行即标题 | 记录想法时，任何字段都是阻力 | 备忘编辑器：整页文本、首行作标题、自动保存 | 富文本和块编辑 |
| Apple Music 迷你播放条 | 正在进行的活动以一条常驻横条留在底部 | 不打断当前页面，又随时可回到它 | 专注进行中时，标签栏上方出现专注条；点开后专注页从底部升起 | 封面图与大面积模糊 |

由此得出的可验证设计决定：

1. **今天只放今明两天要处理的事**：逾期、今天到期、明天到期，外加正在上/下一节课和待确认的消息。其余任务在「待办」按日期排好。
2. **任务与备忘是两种记录**：录入前明确选择；备忘不进入任何到期视图，转为任务必须手动并保留双向关联。
3. **识别只给建议**：输入"明天交物理"会提示「识别到『明天』· 11月5日」「科目：物理」，点一下才采用；按钮上方一行写明将创建什么。
4. **完成可以反悔**：数据立即写入，行保留片刻后折叠，提示里有撤销；删除进入「最近删除」，可找回。
5. **课表按"第几节"对齐**：高中生读课表的方式是"第 3 节"，而不是按分钟比例；午休作为分隔出现；常用教室只在网格下方写一次，只有换教室的课才在格子里标出。
6. **失败要看得见、有出路**：保存失败显示在内容里（不是悬浮），给出重试；云端冲突给出"合并 / 使用云端版本"，不盲目覆盖。

## 3. 探索过的三个方向

| 方向 | 描述 | 结论 |
|---|---|---|
| **A. 纸面与朱批**（采用） | 暖白纸面、墨色文字、朱红作为唯一信号色；列表直接落在纸上；只有 Sheet 是"卡片"——真实的一层 | 与学生每天面对的作业本、课表、红笔批改同源；在教室白天光线下可读；身份来自用色纪律而非 Logo |
| B. 冷静精密 | 深色优先、等宽数字、高密度，接近 Linear | 适合电脑上的长时间工作，但对高中生日常显得冷漠；白天教室里深色界面可读性差。保留其中的密度与对齐原则 |
| C. 校园影像空间 | 每页以校园照片打底，暖色光影 | 照片会和任务抢注意力，也会拖慢低端设备。只在欢迎页和「校园」页使用真实照片 |

## 4. 视觉系统

### 颜色（`HaizColors`）

| Token | 浅色 | 深色（晚自习） | 用途 |
|---|---|---|---|
| canvas | `#F6F4EF` | `#121314` | 页面 |
| surface | `#FDFCF9` | `#1B1C1E` | Sheet、编辑器 |
| raised | `#ECE9E1` | `#26282B` | 按下、输入框底 |
| ink / ink2 / ink3 | `#17181A` / `#55595F` / `#8C9095` | `#ECEAE5` / `#A4A6A9` / `#6E7175` | 主 / 次 / 辅助文字 |
| rule / ruleStrong | `#E2DED3` / `#CBC5B8` | `#2B2D30` / `#3B3E42` | 发丝线 |
| **signal（朱）** | `#D13C20` | `#FF6B4F` | 当前节次、时间线、逾期、完成勾。**不用于装饰** |
| amber | `#9C6410` | `#E2A445` | 待确认（识别不确定的日期） |
| green | `#2E7653` | `#6DBB8E` | 已保存/已确认 |

科目使用低彩度色相（数学石板蓝、语文赭、英语青……），课表格子只用约 11% 的底色，文字始终是墨色。主按钮是墨色实心，不是朱红——朱红留给"注意"。

### 字体与排版（`TypeScale`）

- 中文优先，使用系统字体（iOS PingFang、Android Noto Sans CJK、Web 为 Noto Sans SC），不引入装饰字体。
- 字号取整像素：大标题 28 / 标题 20 / 行标题 17 / 正文 16 / 次要 15 / 注释 13 / 说明 12 / 微型 11。
- 所有会原地变化的数字（时间、倒计时、计数）使用等宽数字。
- 页面标题就是内容本身：「11月4日 周三」「待办」「课表」，不使用口号或英文眉题。

### 形状与容器

- 圆角按角色区分：课表格子 6、芯片 8、控件 10、面板 14、Sheet 20。
- 任务、课程、设置都是落在纸上的行，用发丝线分隔；按下时整行底色立即变深（无缩放、无水波纹）。
- 阴影只出现在两个地方：录入按钮和 Sheet。

### 签名细节

- **朱批勾**：完成时一笔红色勾画过圆圈，并略微越出右上角，像红笔批改；圆圈同时淡出。
- **现在**：正在上课的块左侧是朱红竖线和进度线；课表里当前节次描红边；日视图里有朱红时间线。
- **标签栏**：选中项顶部有一段 20×2 的朱红短线，随弹簧曲线移动。

## 5. 动效与交互语言

| 场景 | 行为 | 时长 |
|---|---|---|
| 按下 | 行底色立即变深；按钮缩放至 0.97 | 90 ms |
| 完成任务 | 写入 → 勾画 260 ms → 停留 900 ms → 折叠 220 ms；提示含撤销 | — |
| 切换标签 | 每个标签保持状态（滚动、草稿），进入时淡入 | 220 ms |
| Sheet | 从底部升起，减速曲线 `Cubic(0.2, 0, 0, 1)` | 320 ms |
| 专注页 | 从底部专注条方向升起并淡入 | 320 ms |
| 页面滚动 | 大标题滚出后，顶部紧凑栏淡入标题并出现发丝线 | 150 ms |

- 写入永远先于动画；动画只是数据的视觉副本。
- 系统"减少动态效果"开启时，所有时长归零，状态仍立即变化（有测试覆盖）。
- 触觉：只在提交时（完成、开始/结束专注）给轻触反馈；切换标签为选择反馈；Web 无触觉。
- 不使用实时模糊、折射 Shader、漂浮粒子。1.5.5 的光学玻璃底栏已移除。

## 6. 信息架构

```
今天   日期 · 正在上/下一节 · 待确认消息 · 逾期/今天/明天到期 · 今天已完成 · 今日（放学后为明天）课程
待办   任务（按到期分组、科目筛选、已完成、最近删除） | 备忘（独立列表与编辑器）
课表   周（按节次对齐的网格） | 日（日期条 + 列表 + 时间线）
收件   待处理（本机队列）· 粘贴或导入 · 等待你确认 · 自动收集设置 · 数据去向
我的   账号与同步 · 本周记录 · 校园 · 班级同步 · 外观 · 数据与备份 · 日历导出 · 收件与隐私 · 更新 · 关于
专注   模式：从今天/任务进入；进行中显示专注条
```

## 7. 反模式清单（评审时逐条检查）

- 口号式标题（"留一点时间，给自己"）、英文装饰眉题（`01 / DAILY NOTES`）。
- 同圆角同阴影的卡片堆叠；为"高级感"加的渐变、发光边、毛玻璃。
- 没有信息的统计卡（"完成率 72%"）；连续打卡、积分。
- 悬浮在内容上的常驻按钮（1.5.5 的备份/更新/账号三个圆钮曾与页眉图标重叠）。
- 禁用但不解释的按钮；只说"完成"不说"保存到了哪里"的提示。
- 未接入的学校服务显示任何假数据。
