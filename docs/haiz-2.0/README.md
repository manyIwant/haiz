## 这一版做了什么

**信息架构**：今天 · 待办 · 课表 · 收件 · 我的。专注从标签降为"任务上的一种模式"，进行中时在标签栏上方常驻一条专注条。1.5.5 中长期悬浮在内容上的备份、更新、账号三个圆钮收进「我的」（它们曾与页眉图标重叠）。首次打开是本地欢迎页，不再等待远程 WebView。

**页面**：见 DESIGN.md 第 6 节。要点：

- 今天：日期即标题；正在上/下一节课（含剩余时间与进度）；逾期/今天/明天到期；待确认消息；放学后改为显示明天的课程。新用户看到三步开始指引。
- 任务与备忘分开：录入前选择类型；识别出的日期、科目只作为建议，点一下才采用；备忘有独立列表和编辑器，"转为任务"保留双向关联。
- 完成、删除都可撤销；删除进入「最近删除」可恢复；任务记录创建、修改、完成时间。
- 课表：按"第几节"对齐的周网格（当前节描红、午休分隔、常用教室只写一次），日视图带当前时间线；课程可原地修改，同一节课可一次添加到多天。
- 收件：沿用经过审计的工作流逻辑（隐私闸门、确认后才写入、写入成功后才移除原消息），重做界面；不含作业的通知可以存为备忘。
- 专注：以墙钟时间为准，暂停/继续/结束/放弃；切后台、杀进程后回来会补记且只记一次。
- 我的：账号与同步状态、本周真实记录、校园、班级同步、外观（自动/浅/深）、备份、导出 .ics、收件与隐私、更新、关于。

## 架构改动

| 问题（1.5.5） | 2.0 的处理 |
|---|---|
| 根组件监听整个 Store，专注计时每秒重建整个 MaterialApp | 根只在主题和"加载/欢迎/工作区"切换时重建；计时器是独立 `ValueNotifier`，只重绘时间文字；各页面自己订阅数据 |
| 专注计时只在内存，切后台或杀进程即丢失 | 会话持久化在个人记录里，剩余时间由开始/结束时间计算；恢复时幂等补记（`completedSessions` 防重） |
| 云端保存失败后只能重启 | 区分"可重试的失败"（显示重试）和"版本冲突"（合并 / 使用云端），读取失败仍保持只读保护原文 |
| 速记实际创建任务 | 新的 `NoteItem` 实体，与任务分离 |
| 切换标签草稿消失 | 标签保持状态；录入框、收件粘贴框的草稿保存在 Store（访客另存本机，账号仅内存，切换账号即清空） |
| `main.dart` 承担导航、浮层、账号逻辑 | `app/`（根、Shell、导航动作）、`design/`、`features/*`、纯规则 `domain/planning.dart` |
| 启动依赖远程 Lamp WebView（8 秒超时回退） | 本地欢迎页，只在首次出现 |
| `pubspec.lock` 缺少 supabase 等传递依赖 | 已提交与 CI 工具链一致的锁文件 |

刻意没有做的：没有引入 Riverpod/BLoC，没有把 `PocketStore` 拆成多个各自写盘的仓库——所有写入仍经过同一个串行队列和代际票据，这是现有账号隔离测试所依赖的安全边界。拆分方向见"下一步"。

保留并改用新主题的 1.5.5 页面：班级同步（AcademicPage）、纸带实验（TickerLabPage）、登录/注册、备份、应用更新 Sheet。

## 已知问题

- 登录账号仍不能离线编辑：账号数据按安全设计不落盘到本机，断网时只读。需要加密本机缓存方案后再做。
- 若同一账号仍有 1.5.5 设备在编辑，1.5.5 保存时会丢弃 2.0 的备忘/最近删除（核心数据不受影响），见 MIGRATION.md。
- 收件识别仍是规则解析，候选标题会保留"明天交"等原词；识别质量本身没有在这一版改进。
- 网页版 CJK 字体从 Google 字体服务按需加载；离线首次打开时中文可能缺字。预览包已自带字体分片，正式 PWA 尚未。
- `webview_flutter` 依赖和 `optical_backdrop.dart`/光学 Shader 已不再被主界面使用，待 Android 构建验证后移除。
- 应用内版本号仍为 1.5.5+2105：2.0 预览不应占用正式 versionCode，发布 2.0 前需要你决定版本号。
