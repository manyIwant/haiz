# 主页：一棵榄仁树（2026-11-03）

haiz.space 的根地址 `index.html` 现在是一号教学楼前的百年榄仁树。原「从星球到树荫」降落镜头保留在 `descent.html`，杂志首页仍在 `journal.html`，所有原有页面与功能未删除。

## 设计

**榄仁树是主页，主页是空间，空间就是进入 HAIZ 的方式。**

- **六个停留，滚动即绕树而行。** 滚轮、下滑、方向键、Home/End 或右侧「树的索引」都在同一条连续镜头路径上移动：此刻（照片机位）→ 根 → 干 → 枝（沿龙枝侧面，从枝下走过）→ 冠（仰望）→ 叶（拉远全景）。没有切镜。一次轻滚就会走到下一站并在那里停稳；拖动可以自由环顾，再次滚动时视线回到路径。
- **树的结构就是网站结构。** 根＝来处（学校、新闻档案、校友、三次停留）；干＝走进校园（第一人称校园、从星球到树荫、建筑手册、导演台）；枝＝日子（杂志、社团、课间电台、来访招生）；冠＝课间（窗台、暗房、物理实验室、HAIZ Pocket、登录）；叶＝留下（书页、拨动时间、关于本站）。
- **条目是可读的文字，不是发光按钮。** 每站的入口是一列衬线文字，用细线连到画面里真实存在的东西上：加载时从该站机位沿预设屏幕位置射线求交（树皮、巨石、教学楼、地面、叶簇），交点就是锚点。悬停或聚焦条目时，那一处的枝叶会被拨动；点击时镜头推向锚点，帷幕从锚点展开后跳转（阅读页为纸色、三维页为深色）。返回主页时回到离开的那一站。
- **真实的此刻。** 太阳位置按海口经纬度与本地时间计算（海口 UTC+8）；季节按物候模型推演（见下）。默认显示「海口此刻」；拨动「一日 / 一年」进入「推演」状态，界面明确标注，可一键回到此刻。夜里，教学楼的窗在推想的晚自习时段亮起。
- **第二次来仍有理由。** 在树下停留，总会有一片叶子落下（第一片会在你看得到的地方落下，并提示「接住它」）。点击接住，它会以与树上完全相同的颜色模型成为一张标本：日期、时刻、当时的季节、模型中的长度，可写一句话，夹进「书页」（仅存于本机浏览器，可导出整页 PNG）。一月的红叶只能在一月接到。再次来访会被告知上次来时树的样子与现在的不同。
- **触感。** 鼠标掠过树冠会拨动叶片（着色器里的冲量），点按会摇动枝条，秋冬时可能碰落一片叶子。声音默认关闭；打开后，风声与叶声跟随驱动树冠的同一个阵风信号，夏季白天有合成蝉鸣，夜里有虫声——都是合成，不冒充录音。

## 树：Blender 制作流程

`scripts/lanren/build_tree.py`（Blender 5.2，可用 PyPI 的 `bpy` 运行）：

1. **骨架依实拍手工设定**（`assets/images/web/lanshu-1600.jpg`，区大伟摄）：粗大主干在约 2.6 m 处分叉；一根「龙枝」向东近乎水平伸出十余米，在巨石旁压到离地约 1.9 m，再昂起成自己的树冠。照片从树的北侧朝教学楼拍摄，龙枝在画面左侧，即东侧。
2. **细枝按榄仁树的生长方式**：合轴、近水平的分层侧枝（Aubréville 模型），枝梢上翘；叶子簇生于短枝顶端（属名 *Terminalia* 即「末端」）。二级、三级枝与小枝扇形展开，用空间网格避免拥挤，形成层层平展的树冠。
3. 管状网格带板根截面、枝领、瘤状起伏，UV 沿枝长展开（树皮裂纹顺枝走向）；Cycles 烘焙环境光遮蔽写入顶点色（R），风摆权重（G）、嫩枝程度（B）。
4. 巨石与树池同样在 Blender 中生成并烘焙 AO。
5. 导出 glTF 后用 gltfpack（meshopt + 量化）压缩：树 1.8 MB、石头 0.14 MB。
6. 叶簇（5773 个，含朝向、遮蔽度、风摆）与果实写成二进制，运行时展开为约 4.9 万（高）/ 2.7 万（低）片独立叶子。

纹理全部由 `scripts/lanren/textures.py` 从数学生成（不描摹照片）：四种叶形（倒卵形、楔形基部、短尖、7–9 对弧形侧脉、网脉、虫孔与叶缘缺口），通道里存有「衰老顺序」遮罩，使叶子由脉间斑块开始变黄、转红、成赭褐；可平铺树皮（纵裂纹、苔藓与地衣）；60 cm 石材铺地。

`build/lanren/lanren-tree.blend` 为可编辑源文件（不入库，运行脚本即可重建）。

## 实时渲染（Three.js r170，自写着色器）

- **光斑是光学，不是贴图。** 阴影采用按太阳视直径 0.53° 计算半影的 PCSS：叶隙离地越高，地上的光斑越大越柔，像真实树荫下那样是太阳的圆形像。
- 叶片：双面，正面光泽、背面浅而哑；直射与天空光的透射让逆光的叶子亮起来；按叶簇遮蔽度压暗内部；风摆与触碰在顶点着色器中进行，阴影深度材质同步，影子跟着叶子动。
- 季节：每片叶子有自己的转色顺序；着色器与 CPU（标本、测试）使用同一套模型。
- 天空、云、雾随太阳高度变化，环境光由天空实时生成 PMREM。远处的校园树木是把这棵树离屏渲染成的 impostor 立在广场四周，随光照重新烘焙。
- 画质分级：高 / 中 / 低（阴影分辨率、PCSS 采样、叶片密度、像素比），帧时过长时自动降低分辨率。不支持 WebGL2、开启省流量或加 `?static` 时，主页成为一张可读的静态页，全部 18 个入口照常可用；无 JavaScript 时同样如此。

## 物候模型（推演，非观测）

资料（经检索摘要；部分站点在本环境无法直连）：叶在落前转红或转黄；在多数分布区一年落叶一至两次，例如新加坡的 1–2 月与 7–8 月（Corner 1997，转引自物种资料）；核果约 4–7 cm，青熟转黄或红。海口冬季较凉而干，本站据此把主要红叶期放在 12–2 月，2 月下旬近乎光秃，3–4 月抽新叶，7–8 月约 14% 叶片小规模换叶，夏秋挂果。这是本站的近似模型，**不是对这棵树的观测**，页面上同样注明。

## 验证

- `node tests/lanren.cjs`：太阳几何（20°N 夏至正午太阳在天顶以北约 3.4°、冬至正午高度约 46.6°）、全年季节状态逐 6 小时连续（叶片脱落除外）、镜头路径连续且不穿过树干与巨石、18 个入口与 HTML 一致且目标存在、Blender 资产尺寸与 meshopt 压缩。
- `node tests/home-browser.cjs`（Chromium + SwiftShader 软件渲染）：一次轻滚走到下一站、键盘 End/Home、索引跳转与 4 条导引线落在屏幕内、点击接住飘落的叶子并夹进书页、点击条目经帷幕跳转到 about.html、返回后恢复停留处与书页、静态回退列出全部入口、390×844 手机无横向溢出。
- 按用户提供的 `blender-asset-qa` skill 对 .blend 做了自动检查：石头无 UV（程序化着色，有意为之）；树皮 UV 重叠（可平铺树皮，有意为之）；约 10 根三棱小枝与父枝未接触、369 对共面三角形，均位于叶簇内，记为已接受警告。
- 软件渲染约 0.3 fps，**未在真实 GPU 与真机上测帧率**；高画质约 4.9 万片叶子、18 万三角形树皮、4096 阴影，桌面独显应无压力，移动端默认低画质，实际表现仍需真机确认。
- 既有的 `tests/cinematic-runtime.cjs` 在未改动的主干上同样失败（与本次无关，未修改）。

## 维护

```bash
python3 scripts/lanren/textures.py            # 叶、树皮、铺地纹理
blender -b --python scripts/lanren/build_tree.py   # 或用 PyPI bpy 运行；--quick 降低 AO 采样
./scripts/lanren/pack.sh                      # gltfpack 压缩到 lanren/assets/
node tests/lanren.cjs && node tests/home-browser.cjs
node tests/lanren-capture.cjs tests/artifacts/home "0@2026-11-03T16:40" "3@2027-01-18T15:00"   # 评审截图
```

停留的文字、来源与机位在 `lanren/js/chapters.js` 与 `index.html` 中（两处由测试保持一致）；季节曲线在 `lanren/js/season.js`。评审链接可加 `?t=2027-01-18T15:00` 固定海口时间，`?quality=low|medium|high` 固定画质，`?static` 查看静态回退。
