## Gate 0 · 选定代码主线（目前未通过）

- [ ] 确认 HAIZ Space 的 main 静态发布路径保持不变。
- [ ] 决定 App、Academic、教师 Web 与 HAIZ Space 采用 monorepo 还是独立仓库。
- [ ] 制定 main 55638e8 与 preview 663b51d 的迁移映射；当前 **No common ancestor**。
- [ ] 清点 20 个 Draft PR；标注每个 PR 的 base/head、依赖与是否移植。
- [ ] 指定后端唯一负责人，避免 Academic 和 Flow 两套数据库并行扩张。

验收材料：架构决议、源树对照、同步 API v1、独立 QA 基线。

## Gate 1 · 核心权限与个人数据（必须优先）

- [ ] Flutter 不同账号、不同班级和访客的数据完全隔离。
- [ ] 旧 pocket.tasks.v1 任务安全迁移到明确的本机私有命名空间，禁止迁移失败直接清空。
- [ ] 登录、退出、账号切换、权限撤销后的缓存访问测试。
- [ ] 教师未确认的草稿绝不出现在“正式班级作业”或 ClassIsland 正式屏。
- [ ] 账号注册、会话超时、异常登录、伪造身份与邀请码滥用的安全测试。
- [ ] 未具备正式学校授权时，所有含学校学籍号/身份信息的同步保持关闭。

验收材料：覆盖“账号 A 保存隐私笔记，账号 B 登录后不可读”的真实设备/模拟集成测试；权限测试日志。

## Gate 2 · 可靠的作业生命周期

- [ ] Assignment id 作为稳定身份，定义 revision、发布人、修改/撤销状态和权限。
- [ ] Teacher create / preview / publish / edit / retract 全流程真实可操作。
- [ ] 学生保留个人笔记与计划，不被老师编辑原始作业覆盖。
- [ ] 不同端收到修订与撤回后，界面/个人任务正确提示并允许人工处理。
- [ ] 离线队列、同步游标、幂等、并发冲突恢复、长时间断线后恢复。
- [ ] 已查看、学生自标完成、已正式提交各有独立状态；无提交服务不可显示“已提交”。
- [ ] 静态 HAIZ Teacher 和 Academic 工作台要么共用正式 API，要么明确分为“离线草稿工具”和“班级服务”。

验收材料：至少教师 Web + 两个学生会话 + 教室只读端的自动化契约测试，包含撤回、同名消息、版本冲突与重复接收。

## Gate 3 · 文件与教学功能实用性

- [ ] Android 真机对中文截图、小字截图、含表格图片进行 OCR 逐条核对。
- [ ] 真实 TXT、Word、文本型 PDF、扫描型 PDF（若仍未支持须明确提示）导入检验。
- [ ] 相对截止时间能够关联原消息时间；未知时间标记待确认。
- [ ] ICS 在目标系统日历中导入，事件更新/重复导入不产生意外重复项。
- [ ] 课程临时调整、学期课表（若版本声称支持，则必须实测）。
- [ ] 物理打点计时器在教师大屏和学生手机实测数值/时间步一致，明确理想模型局限。
- [ ] 不声称多学科引擎、OCR 教师端 HAIZ SCAN 或高级图形已完成，除非单独验收。

## Gate 4 · 外部服务与插件

**QQ**：
- [ ] 由授权主体提供官方 AppID/AppSecret；机器人审核、群场景权限与消息事件经确认。
- [ ] 测试官方事件对象、消息去重、签名、重试、来源映射、教师审核。
- [ ] 保留运行失败的可观察日志，但不得在日志中记录敏感消息或令牌。
- [ ] 如无授权，发行版本明确标记“可选适配器，仅合成测试”。

**正式学校身份**：
- [ ] 学校书面授权或正式批准及接口说明。
- [ ] 身份提供方协议、字段白名单、撤销/恢复一致性、最小化同步与隐私文件。
- [ ] 不允许以手工 HAIZ 用户身份映射冒充学校统一登录。

**ClassIsland**：
- [ ] 目标 Windows + ClassIsland 具体版本，安装与升级成功。
- [ ] 45s 轮询、断网、同一教室双设备、只读凭据撤销、过期和权限边界测试。
- [ ] 教室实际屏幕展示内容与 Academic 发布一致；不出现学生隐私。

## Gate 5 · 发版与运营

- [ ] Flutter unit/widget + Android UI/端到端 + API contract + Playwright 浏览器分层自动化。
- [ ] 真实 Android 安装、启动、后台恢复和断网重连；有条件时 iOS IPA/Xcode/TestFlight 验证。
- [ ] 性能预算（学生页、教师 Windows 大屏、ClassIsland CPU/内存）与 Reduced Motion 验收。
- [ ] 公私密钥和 Cookies 安全检查、可恢复备份、回滚、数据库迁移、日志脱敏。
- [ ] 开源许可/第三方模型与校园资料来源复核，保留 windowsill 等 AGPL 义务。
- [ ] 公开发行说明如实列出：已实现、已测试、尚需授权、未经真机验证。
- [ ] 仅在 Gate 0–4 针对承诺范围通过后创建 GitHub 预发行版；main 部署另设独立门槛。

## 推荐 v1.4 最小公开承诺

只承诺：**自建且经批准的班级、教师确认的作业、学生个人隔离、可核对的导入、可追溯的修订与撤回、可靠的离线恢复**。

把“海南中学官方账号连接”“自动读取任意 QQ 群”“真实学生成绩/学籍”“Windows ClassIsland 全型号兼容”“iOS 官方上架”全部列为单独的**授权/平台验收里程碑**，不写进未验证的发行宣传。

## 开发阻塞优先级

1. **P0：主线分离 + 跨账号缓存隔离**。两个问题不解决，不适合扩大学生试点。
2. **P1：统一教师发布与版本化同步**。否则多端展示可能不一致。
3. **P1：设备证据**。先做最小 Android 和 Windows ClassIsland 真实设备演示。
4. **P2：导入准确率、日历/课表和教学体验**，再添加大范围附加功能。

本报告不批准正式校级上线。它只给出可逐项核实的下一次版本门槛。
