# HAIZ Pocket 第一阶段：移动端班级任务中继与语义解析

> 开发分支：`feat/mobile-class-task-relay-20261029`，不代表已部署、已通过真机验收或已获得学校正式授权。

## 目标与真实链路

1. **Android 手机**：用户明确授权系统通知访问，并只设置经过许可的班群。现有 NotificationListener 读取可见的指定群通知，写入本机消息队列。微信禁用通知或隐藏通知正文时无法采集；不是读取微信私人数据库。
2. **混合解析**：本机 `NoticeParser` 提供零网络回退。用户可在已认证的班级学生账号下单独开启 AI 语义预解析；打开收件箱时，对最多 4 条未处理的新通知顺序尝试远端解析。该行为**只在 App 运行且登录会话有效时发生，不是后台常驻模型**。
3. **隐私屏障**：AI 服务默认关闭。开启时有独立告知，发送前对电话号码、邮箱、URL 做基础替换；原始消息只保存在手机本地，不作为班级任务草稿提交。**简单替换不保证彻底匿名化**；如果班级、群成员不同意第三方模型处理，不应开启。
4. **任务语义解析**：模型可拆分多个科目/任务、提取动作、解析相对截止时间。每一项必须附上与输入严格匹配的连续原文证据。无证据的模型结果丢弃；凭空出现的截止日期退回待核对状态。日期歧义仍需用户处理，模型不会自动发布。
5. **班级分享**：学生从候选任务选择“提交班级审核”，发送**科目、标题、截止日期和幂等键**到 HAIZ Academic。服务端不允许该接口包含微信聊天正文、发送者、群名称或聊天记录。学生权限仅限于已核准的班级。
6. **教师审核**：教师网页“来自学生手机的作业候选”可以编辑结构化任务、忽略或发布。学生无法自行发布到全班。
7. **跨端接收**：已发布的任务通过现有 `/api/my/assignments` 接口面向班级已核准成员。Android 和 iOS 首页可显示已发布的班级作业；登录会话存在且 App 在前台时每 3 分钟刷新，回前台时立即刷新。

## 消息理解示例

输入（示例虚构）：“数学练习册第12页明天交。英语先复习 Unit 4，什么时候检查另行通知。”

预期：数学“完成练习册第12页”，截止日期以**手机原消息接收时间**和时区为准；英语“复习 Unit 4”，截止日期 null、标记有歧义。没有明确行动要求的闲聊输出空候选。该示例说明结构能力，并不代表所有 AI 模型都有可靠的理解效果。

## AI 后端管理员配置（必须显式开启）

默认未配置时，用户端继续使用本机规则，**没有可用的 AI 模型**。可以使用自己有权使用的、可信的 OpenAI 兼容 Chat Completions API 服务，支持 JSON object response_format。

在 HAIZ Academic 服务的**私有服务端环境**配置（不要提交到 GitHub，也不要把密钥放在 Flutter App 内）：

```bash
export HAIZ_AI_ENABLE=1
export HAIZ_AI_BASE_URL=https://YOUR-TRUSTED-PROVIDER.example/v1
export HAIZ_AI_MODEL=YOUR-SUPPORTED-MODEL-ID
export HAIZ_AI_API_KEY='YOUR_PRIVATE_SERVER_SIDE_KEY'
```

请求只发送到以 HTTPS 开头的管理员指定地址，使用 `POST /chat/completions`；15 秒超时，不自动重定向，单个请求最多 2800 字符，服务端会做有限脱敏。不存储原始聊天和模型响应。接口 `POST /api/ai/extract` 需要有效 HAIZ 学生会话、已核准班级成员资格和本次请求的 consent=true，并对单账号按小时限流。

目前尚未使用用户真实模型密钥完成活体验证。选择哪家模型提供商需核实其隐私政策、可用地区、账号使用条款及学生数据处理许可；优先选择可信的私有部署。

## 测试 / 安全

- Node.js 24 Academic 新增 `tests/mobile-suggestions.test.mjs` 与 `tests/intelligence.test.mjs`，覆盖无授权/未核准用户拦截、群消息字段拒绝、去重、教师审核后班级可见、重启恢复、模型输出证据/无效日期以及基础隐私脱敏。
- Flutter `test/academic_session_test.dart` 验证 AI 账号隔离和明确同意，`test/mobile_semantic_task_test.dart` 验证任务去重，原始收件箱工作流保留。
- 不自动同步手机私人任务到其他同学；无管理员、教师真实凭据默认不创建公共班级。
- 服务端自建数据库、会话和相关 HTTPS 代理必须在授权环境部署。真实校园使用前需要班级管理者/学校许可、隐私审查、模型提供商数据处理评估、真机权限/耗电测试及数据删除机制。

## 还未完成的功能

- **iOS 直接后台监听微信：不可实现**；本阶段 iPhone 是已发布任务的接收端。
- **Android 通知关闭仍自动读取私人微信：不支持**；要不依赖通知，需要真正有权提供消息的上游渠道。
- **App 退出或锁屏时系统级推送**：未实现 APNs / FCM；当前是有会话的前台轮询，不能声称“手机关闭 App 也即时收到”。
- **手机本地离线大模型**：未打包模型；AI 模块目前是管理员可选配置的服务端推理。
- **真实多学生规模运行/老师账号上线/生产发布**：尚未完成。不能从开发测试直接推导实际通知覆盖率、AI 准确率或可靠性。
