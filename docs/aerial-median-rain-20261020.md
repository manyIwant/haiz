## 性能：保留雨丝，减少重复屋顶检查

旧实现每帧为最多 160 条雨线扫描屋顶列表。新版建立保守的 XZ 空间索引，候选屋顶仍用完全相同的旋转矩形判定；以 Float64 保存最高遮挡高度，保留严格边界比较。

雨线的水平偏移不随时间变化：摄像机只转向、上下轻微摆动或原地看雨时，每条雨线可复用已算好的屋顶高度。摄像机 X/Z 有任何改变都会失效；雨量或画质提高时只补算此前未使用的列。时间、云层、雨丝下落、数量上限、颜色、分辨率、阴影、湿润与反射效果保持原逻辑。

验证记录：

- `tests/rain-index-results.json`：21,000 次随机/屋顶边界比对，与原线性判定一致；240 个原地动画帧、180 个移动帧、画质切换、雨量切换及室内切换的有效雨丝顶点逐字节一致。
- `tests/rain-performance-browser-results.json`：真实校园中，240 个原地帧的屋顶精确检查从参考算法的 614,660 次变成 0 次，雨仍在下落；120 个移动帧从 276,285 次降至 30,153 次。与原算法生成的雨线比较，800 × 500 帧缓冲差异为 0。
- 固定机位的这些计数说明消除了重复 CPU 工作，**不是整站 FPS 提升百分比**。新增植物有其渲染成本，不把这一轮说成全场景几何减少；没有实测手机 GPU 帧率。
- 继续保留上一轮的地图静态缓存、索引合批、碰撞索引；`index.html` 与 `descent.html` 同源，点击前不加载完整校园，没有全量预热门槛。
