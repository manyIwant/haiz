## 1. 这一轮在做什么：一个傍晚

上一版的时间线是：01 黎明 → 02 清晨 → 03 上午 → 04 正午 → 05 黄金时刻 → **06 又回到正午**。第五幕里人物跃下、走开，光线却在行走中途从夕阳跳回蓝天白云：电影里最重要的那一分钟没有时间感。

本轮把六幕定为**一天**：从 01 逆光里的黎明剪影，到 06 同一棵树在最后的低角度阳光里被完整照亮。05 与 06 成为**同一个傍晚**：太阳在电影进行中从 12° 降到 8.5°，方位从 302° 移到 298°。

这个决定带来了本轮最想让你看的画面：

> 人物走开、停下、回头。目光先落在地上：**自己的影子被低垂的太阳拉得很长，横过铺地，指向那棵树**。目光沿着影子走到树根，升上树干，进入整个树冠。树后的一号教学楼立面被夕阳照暖，树冠的影子投在墙上。

（`ab-film.jpg` 最后两行；`final-06.jpg`）

影子不是贴图也不是特效：是太阳的真实阴影。低太阳让 V4 的阴影相机沿光线方向覆盖得更远，人物站在 06 的位置时恰好在它的范围内（实测）。第一人称的人不可能看见自己，只能看见自己的影子：它是「你已经成为这个人」的证据，同时是镜头运动的动机。

## 2. 第五 → 第六幕：重新导演（`lanren/world/film.js`）

上一版从第五幕的第一帧起就是第一人称，大部分时间镜头对着地面。本轮按你说的「角色从环境中的一个存在，逐渐成为观众的身体」重写：

| q | 镜头 | 身体 |
|---|---|---|
| 0.00 | V4 第五幕原机位（不变） | 不可见 |
| 0.03–0.15 | **第三人称**：目光离开远方，向左下找到长枝上站着的一个人；镜头从他身后三分之四处绕到过肩位置，看他所看的方向。浅景深对焦在他身上 | 站立休息：重心在一条腿上，抬头看夕阳，中途低头看一眼校园 |
| 0.15–0.19 | 镜头滑进他的头里 | 收起放松的站姿 |
| 0.19–0.24 | 第一人称低头：自己的手、白衬衫与绿领、脚下的树皮与 3 米落差 | 双臂抬起保持平衡，手向前进入视野 |
| 0.24–0.345 | 沿长枝三步 | 上身左右晃动（roll），双臂反向调整（tilt），镜头随之偏几度 |
| 0.345–0.38 | 目光落到落点 | 蓄力：屈膝、双臂后摆、前倾 |
| 0.38–0.475 | 跃起；弧线顶点抬眼看校园，然后看地面 | 蹬离（脚仍在树皮上）→ 双臂前抛 → 收腿 → 张臂准备落地 |
| 0.475–0.56 | 冲击时看地，然后抬起 | 膝盖吸收，顺势向前一步接住重心，站起 |
| 0.56–0.80 | 朝着太阳走开，中途侧头看一眼被照亮的校园 | 起步加速、匀速、减速停步（不是对称缓动）；髋部扭转、肩部反扭、骨盆随步伐起伏，头保持稳定 |

| 0.84–0.93 | 回头：先头、再肩、后脚；目光低，落在自己的影子上 | 原地小步转身，向转身方向微倾 |
| 0.93–1.00 | 目光沿影子升到树冠，镜头焦距变长（66° → 38°） | 放松站立 |

滚动吸附点改为 0.15（过肩）、0.215（看见自己）、0.56（落地）、0.84（停住）：每一个都是能单独成立的画面。

**仍然保证的**：整段是滚动进度的纯函数（前进、后退、跳转得到同一帧，2001 个采样逐位相同）；从 0.19 起镜头始终在画出的人物头部（误差 < 1e-6 m，转头与上身侧倾都计算在内）；脚在树皮上或地面上；落地弧线不低于地面；第六幕的眼睛精确落在 V4 06 机位、看同一个点、同一个焦距。

### 人物动作的质量（`skeleton.js`、`body.js`）

方块风格不变（尺寸、配色、像素材质都保留）。新增的是关节层面的表演：
- 走路时髋部随步伐转动、肩部反向扭转，头部抵消两者、视线稳定；骨盆向摆动腿一侧下沉。
- 上身侧倾（平衡）与双臂的不对称外展（跟随侧倾）。
- 头部可以抬起、低下（只影响画出的头，不影响眼睛）。
- 站立休息的单腿重心：骨盆倾斜，放松腿的膝盖微屈。
- 呼吸：静止时胸腔轻微起伏（只是绘制，不移动眼睛）。
- 头部六个面各自有贴图：正面是脸，背面与顶部是头发，两侧有耳朵。上一版头部六个面都是同一张脸：第三人称从背后看会看到脸。衬衫背面不再印着前胸口袋。

### 第六幕：让这个镜头拥有自己的时间（`world.js`、`world.css`）

- 目光升向树冠的最后 10% 和到达后的 2.8 秒里，**屏幕上没有文字、按钮和导航**（第六幕文字、玻璃板、「走进校园」、顶栏、绕树导航、生长线全部淡出）。之后它们自己慢慢浮现（1.6 s）。
- 到达后约一秒，树冠里落下一片叶子（使用已有的落叶系统，能接住，进入书页）。
- 减少动态效果时不做这段等待。
- 等待期间按 ↓ / Enter / 再滚动一次仍然可以交接，等待只是不催促。

## 3. 校园：窗后有房间（`lanren/map/section.js`）

上一版的窗是一块块相同的深色玻璃，五层楼一百多扇窗完全一样，这是「程序化重复感」最主要的来源。

每一块玻璃后面现在有一个**有深度的房间**（interior mapping：按视线算出看到的是后墙、天花、地面还是侧墙，不增加任何几何体）：
- 房间按教室的网格划分（沿墙 6.6 m、每层 3.4 m），后墙上有黑板。
- 傍晚（太阳高度越低越多）一部分教室开灯，大多是**冷白色的日光灯管**（天花上能看到灯管），少数是暖光。外面是暖色的夕阳，里面是冷白的灯：这是中国校园傍晚最常见的颜色对比。
- 约三分之一的窗挂着窗帘，从一侧拉开，长短各异；开灯的房间窗帘透光。
- 斜看时玻璃反射天空（菲涅耳），正看时看进房间。
- 远处的细节（灯管、窗帘褶、墙面色块）随距离淡出成平均色，不在远处闪烁。
- 玻璃不再接受太阳的漫反射（玻璃本来不漫反射），只保留反射与高光：这去掉了窗洞里阴影采样的噪点。

## 8. 没有做到的事（不冒充已完成）

- **跃下的顶点**：弧线顶点仍在树冠下层枝叶之间，画面有一簇近处的叶子，没有达到「校园在眼前展开」的效果。需要换一根起跳的枝或改跃下方向，牵涉落点与构图避障测试，留到下一轮。
- **第一、二、四幕没有重新导演。** 第一幕的黎明剪影本来就是全片最强的画面之一；第二、四幕本轮只受益于帧率修复。第二幕「旧照片投在叶片上难读」仍未解决。
- **漫游现在是傍晚。** 交接之后的校园在同一个傍晚里（窗灯会亮）。如果你希望漫游在白天，可以只让漫游的光回到正午，但那样会失去「同一个傍晚」的连续性。需要你决定。
- **校园其他部分**：近景树木仍是程序化的圆冠小树（06 树左边那棵最明显）；建筑仍是近似体量。窗与房间改善了立面，但没有新增空调外机、栏杆、雨痕等几何细节。
- **第三幕进入的枝干问题**只做了时间上的分散，没有在真 GPU 上确认是否就是审查看到的现象。
- **真机**：iOS Safari、Android Chrome、Apple M5 / Metal 都没有测。所有画面来自软件渲染，真机上亮度、颗粒和景深会有差异。窗后房间每个玻璃像素多约 40 次运算，玻璃只占屏幕一小部分，但手机帧率需要实测。
- `tests/world-browser.cjs` 全流程（上一轮记录单次需数小时）本轮只跑了电影段（见第 9 节）。
