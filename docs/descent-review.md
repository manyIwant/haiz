# 从星球到树荫：下降转场与地面材质

2026-10-17

## 镜头设计

`descent.html` 重新实现为一段 32 秒的固定地理焦点下降镜头。地球、海南、海口、府城与校园使用同一射线／球体投影，六级 Mercator 影像按相同地理中心嵌套并羽化边缘，避免旧版多张无关联图片切换、旋转与坐标漂移。页面使用宋体标题、暗海蓝与暖纸白；不再叠加密集 HUD。

最后阶段预载同源校园 iframe，以协议驱动相机从 300 米上空降至北门外 1.85 米眼高。用户接管时继续使用同一相机位置和方向。支持暂停、拖动、反向回看、章节、键盘、减少动态效果与 WebGL 不可用时的图片降级；校园未就绪时保留独立入口。

## 坐标与影像

旧中心 `19.996067, 110.347227` 来自高德坐标，属于 GCJ-02。直接作为 WGS84 采样会偏到校园东侧。本次影像改用近似逆转换后的 WGS84 `19.998054574, 110.342822993`，并与 OSM 校园轮廓 way 1127981105 的位置交叉核对。该点是取景中心，并非测绘得到的北门位置。原 KML 与本地模型坐标保持兼容。

影像为 Esri World Imagery 的六级公开地图导出，范围依次为 1800、580、85、12、1.8、0.6 千米，各 1024 像素。最后一级避免校园接近阶段放大整片城区低清图片。图片随站点本地提供；运行时不依赖第三方地图请求。来源 URL、范围、分辨率和署名记录于 `assets/cinematic/aligned/manifest.json`。照片有时间差，校园模型仍为近似重建。

- [Esri World Imagery](https://doc.arcgis.com/en/data-appliance/2024/maps/world-imagery.htm)
- [高德坐标转换说明](https://lbs.amap.com/api/webservice/guide/api/convert)
- [OSM 校园轮廓](https://www.openstreetmap.org/way/1127981105)

## 地面材质

校道（包括 KML 多边形）与草坪重新按米制 UV 铺设纹理，分别使用约 2 米和 1.8 米的重复尺度。去掉被新材质覆盖的旧粗噪点纹理分配；采用 mipmap、线性过滤、设备允许的各向异性过滤以及较柔和的法线。降级贴图改为 1024 像素细颗粒；自动画质不再降至低于 CSS 像素的渲染分辨率。

## 验证范围

`npm test` 包含链接与本地资源、材质解码、实际几何和碰撞、地表纹理密度、10,000 个下降采样、相同投影中心、实际转场脚本的播放／回看／接管／降级行为，以及校园启动与到达相机测试。运行测试使用真实 Three.js 数学和几何，但模拟渲染器。

当前环境没有受支持的浏览器控制能力，未做真实 GPU 着色器编译、画面或手机设备验收；发布成功只验证部署，不等同于这些画面检查。
