# 设计系统与八种页面

共同品牌 haiz.space。世界是森林绿的风景入口，教师是暖纸上的清晰任务，学生使用自然色社团封面。保留附带原型的配色与中文语气，将手机模型中的 UI 展开为可在实际浏览器使用的响应式页面。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| forest | #203F33 | 主操作、教师工作台强调 |
| night | #10211A | 世界背景与导航 |
| paper | #F7F2E8 | 工作台、按钮、文本 |
| gold | #E3B57A | 光照、世界注释 |
| leaf | #A3BC9E | 次要标记 |
| clay | #CB896B | 小面积语气点缀 |

英文展示标题用系统 Georgia；中文标题用宋体系系统字体，正文系统中文字体搭配本地 Sora。无运行时字体 CDN。主体圆角 8–10px、按钮 6px、对话框 14px；交互 180ms，减少动态偏好关闭过渡和连续观景。主操作目标约 44–48px。

## 真实截图清单

交付截图包含 1440px 桌面与 390px 手机两组，320px 另做溢出验收：

1. 世界首页：静态主视觉、环境风格、三处地点、窗台入口。
2. 日落漫游：实际 Three.js 画面与地图/机位/质量控件。
3. 雨夜自习室：旧窗台实际场景和新的持久化专注工具。
4. 教师首页：下一节课、今日工作、随手收纳、社团协作。
5. 教师课前卡：材料、课时、上次留下的重点。
6. 教师活动协作：活动草稿与作品审核。
7. 社团星图：四个虚构兴趣社团，可键盘操作。
8. 学生活动/作品详情：演示活动信息与私有作品状态。

首屏概念图不是实时 3D 的效果承诺。截图中的本机示例记录只为展示工作流，不是学校真实活动。
