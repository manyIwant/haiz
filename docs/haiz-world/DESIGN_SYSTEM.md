# 设计系统与八种页面

## ROUND 02：两种场景，同一个校园

Study 使用暖纸 `#f7f3eb`、松绿 `#293f36`、鼠尾草强调 `#71866a`；正文辅助色调整为 `#68785f`，避免浅灰字消失。宋体式中文标题与本地 Sora/系统中文正文搭配。首页主卡是学习上下文，计时留在第一轮辅助窗台。空间预览默认静态，无自动播放声音；纯工具模式移除场景，雨夜书写区增加连续输入面积，榄仁树可将摘记送入书架，砚池便笺可带入下一步规划。四处各自保存便笺，场景不只换背景。

Classroom 使用 `#13251d` 深绿底、`#e4e9d1` 暖浅公告层与 `#586f45` 正文。1920×1080 时核心标题为 64px、公告正文 24px；次要状态单独一行，不与核心提醒争抢视觉注意力。3 米可读性尚未在希沃实测。课堂模式保留只读当前/下一节与简表，去除普通通知；教师一键隐藏优先于模拟课程事件。界面是普通窗口，不实现未经验证的系统悬浮覆盖。

新增六个真实交互界面：教室默认/纯净课堂、课间公告、教师发布、Study 2.0、思路编辑与恢复、服务端授权联动。另有思考书架、纸笔打印、公共学习资源与放学模式。桌面 1440、教室 1920×1080、移动 390 与 320 做布局验证；键盘采用原生按钮、表单、select、dialog，Esc 可离开对话框。

没有新建持续粒子特效。旧三维窗台单独按需加载，低画质为默认，静态图是低功耗回退；本轮没有额外完成 Blender 预烘焙资产流水线，沿用原场景与静态预览，不能宣称新的烘焙成果。

共同品牌 haiz.space。世界是森林绿的风景入口，教师是暖纸上的清晰任务，学生使用自然色社团封面。保留附带原型的配色与中文语气，将手机模型中的 UI 展开为可在实际浏览器使用的响应式页面。

英文展示标题用系统 Georgia；中文标题用宋体系系统字体，正文系统中文字体搭配本地 Sora。无运行时字体 CDN。主体圆角 8–10px、按钮 6px、对话框 14px；交互 180ms，减少动态偏好关闭过渡和连续观景。主操作目标约 44–48px。

## 真实截图清单

交付截图包含 1440px 桌面与 390px 手机两组，320px 另做溢出验收：

1. 世界首页：静态主视觉、环境风格、三处地点、窗台入口。
2. 日落漫游：实际 Three.js 画面与地图/机位/质量控件。
3. 雨夜自习室：旧窗台实际场景和新的持久化专注工具。
4. 教师首页：下一节课、今日工作、随手收纳、社团协作。
5. 教师课前卡：材料、课时、上次留下的重点。
6. 教师活动协作：活动草稿与作品审核。
7. 社团星图：四个虚构兴趣社团，可键盘操作。
8. 学生活动/作品详情：演示活动信息与私有作品状态。

首屏概念图不是实时 3D 的效果承诺。截图中的本机示例记录只为展示工作流，不是学校真实活动。
