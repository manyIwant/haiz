## 核验状态定义

- **仓库可查**：存在文件、提交、截图或脚本，但不能据此认定完整创作权属。
- **来源已核**：来源页面、许可原文和版权人署名已核；不代表获得额外商业权利。
- **权利人明确授权**：有适用于该具体作品与用途的授权记录，适合再讨论是否加入艺术授权清单。
- **待核**：来源、版权主体或使用权限缺乏足够证据；保留不确定性，避免自行推定。

## 安全保存方式

公开仓库只保存可以公开的**摘要、哈希、版本和经许可的证据**。如果确需保留未公开的原始画稿、采购合同、授权邮件或包含第三方身份的素材，应由有权人自行在受限存储中保管；公开档案仅记录“有此类证据，未公开”，不存放私人内容、不提供绕过授权的路径。

公开登记存在的独立文档和 README 不代表材料的法律权属已经定案；出现争议应依据文件内容、实际创作证据、所在地法律及相关权利人意见核查。
