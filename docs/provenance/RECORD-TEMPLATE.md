# 新增原创成果记录模板

> 复制本文件，使用短 ID 命名（例 `2026-11-10-tree-leaf-shader.md`）。填写**可公开且可验证**的内容，不要填写身份证、住址、私人账号、学生姓名或未公开聊天内容。

- 仓库路径（精确文件，不仅是目录）：
- 基准 Commit SHA（完整 40 位）：
- 本轮最初可核实的提交（若有）：
- 公开可引用的成品/预览地址：
- 当前状态：已合入 main / 开发分支 / 只读历史存档

## 2 · 创作与决策

- 希望解决的问题与设计意图（具体陈述）：
- 重要设计决策、提出方案与确认的角色（可使用公开项目账号或“项目负责人”，不必公布真实姓名）：
- 制作过程简述（脚本、手工制作、建模、AI 辅助、选型与改稿分别记录）：
- 可以核验的人类选择、修改或组合工作： 
- 主要迭代、放弃方案与原因：
- 相关截图、生成脚本、原始项目文件和测试结果：
- 需要说明的效果与实际能力差异：

> AI 辅助创作应如实记录。不能简单把“提交由 AI 工具执行”当成人类创作权的充分证据，也不能反过来假设所有 AI 辅助作品都没有人类贡献。
