## 1. 一号教学楼（`yihao`）

### 1.1 朝向：入口朝向榄仁树（本轮最重要的修正）

证据：
1. 学校原文（`campus.json`）：「**楼前**大叶榄仁树……与**楼前**太湖石题词『虎踞龙盘』相互呼应」。
2. `campus.json` 的平面校正：主轴角由「**北门—太湖石—一号教学楼正中**」三点共线反解（残差 1.54 m）。原图「上南下北」，北门在图底；榄仁树（图像 y≈1250）位于一号楼（y 1024–1186）与北门之间。
3. `campus_yihao.jpg`：太湖石立在入口台阶前的广场上。
4. 第二幕 2023 年代使用的照片 `assets/images/web/lanshu-1600.jpg`（画面署名「区大伟 摄」，转载授权待确认；本轮只作对照，未新增使用）：说明为「一号教学楼前的大叶榄仁树：长长的横枝伸向太湖石，树下是台阶」；画面中树后是一号楼**有窗的立面**（一层可见红色窗框），不是外廊。

结论：一号楼的入口（正立面）朝向北门、太湖石和榄仁树。此前通用的「教学楼」造型把入口门廊放在 +Z，把开放外廊放在 −Z，而这栋楼的 −Z 恰好朝向树。第六幕回望时看到的其实是楼的背面外廊。

处理：`lanren/map/campus3d.js` 为一号楼单独建造型（`FORMS.yihao`），并在**同一矩形内转 180°**（`OWN.yihao.turn`）。占地矩形、楼层数、高度、平面坐标、碰撞矩形、第四幕平面数据都没有改；`tests/campus-model.cjs` 与 `tests/world-film.cjs` 中关于占地、高度、闭合实体、剖切和碰撞的检查全部通过。

保留的已知差异：HAIZ 的太湖石按 V4 设计与榄仁树同在小岛上；照片与平面校正显示真实的太湖石位于一号楼正中轴线上，距离那棵树约 35 m。这是第一幕以来既定的世界设计，本轮不改。

### 1.3 材质

- 墙：照片为偏冷的浅灰涂料，`#cdcfca`（线性反照率约 0.6），细微的程序化色差与雨痕沿用上一轮。
- 壁柱：中灰 `#9a9c97`。
- 花岗岩：深灰 `#4a4a48`，0.6 m 错缝石材分缝。
- 窗框：灰色铝框 `#6f7472`（金属度 0.25）。
- 玻璃：保留上一轮「窗后的房间」：室内映射、傍晚的教室灯、窗帘。

## 2. 校园树木

依据：`campus.json` 的树种名录（来自官网《校园景观简介》的绿化树种）与每棵树的位置、高度、冠幅、变体。

| 树种（数据键） | 数量 | 本轮形态 | 依据（树形特征） |
|---|---|---|---|
| 大叶榄仁 terminalia | 70 | 分层（tiered）：四层水平轮生枝，逐层内收 | 榄仁属典型的塔层状水平分枝（与主角榄仁树呼应） |
| 椰子 / 棕榈 palm | 64 | 微弯有环纹的灰色树干，18 片拱起下垂的羽叶（V 形折叶），少数枯叶下垂 | 椰子树形 |
| 重阳木 chongyang | 37 | 卵圆形密冠 | 重阳木圆整浓密的树冠 |
| 红豆 hongdou | 27 | 卵圆形冠 | 近似处理 |
| 木棉 kapok | 20 | 高直树干、稀疏的轮生水平枝 | 木棉通直主干与层状侧枝 |
| 榕树 banyan | 19 | 粗短树干、宽阔低平的穹顶冠、少量气根 | 榕树伞状大冠与气生根 |
| 火焰木 huoyan | 19 | 卵圆形冠 | 未加花（花期未核实，不画） |
| 风铃木 fengling | 16 | 低分叉、三主枝向上外展的开放瓶形冠 | 风铃木开展的树冠 |
| 灌木 shrub、botanic、mixed | 28 | 低矮丘状 / 卵圆 | 近似 |

做法（`lanren/map/section.js`）：每种形态三个变体，叶团是围绕真实枝干的低多边形团块，加一圈小团块打碎轮廓，着色器做叶面法线扰动和零星转色叶。仍是近似的程序化树，不是测绘；具体每棵树的形态未经实地核对。
