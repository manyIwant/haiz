# HAIZ Pocket · 界面整理（unslop）2026-11-13

本轮按 [unslop](https://github.com/heydamir/unslop)（Damir Sokolovsky，[@heydamir](https://x.com/heydamir)，CC BY 4.0）的九轮流程整理 Flutter app 界面：间距 → 颜色 → 图标 → 文案 → 字体 → 布局 → 细节 → 视觉 → 动效。功能、数据和页面分区不变。

## 方向

- **产品**：给府城校区学生用的本地优先学习口袋工具（今天、课表、收件、专注、校园）
- **气质**：安静、有记忆、带一点南方的温度
- **世界**：榄仁树下的老校园、纸和墨、午后的光
- **重点时刻**：校园照片面板、专注计时环；其余界面保持安静
- **标志细节**：页眉的章节编号 `01 今天` … `05 校园`，与 haiz.space 网页一致

## 设计令牌（`app/lib/ui/kit.dart`）

| 类别 | 值 |
| --- | --- |
| 间距 | 4px 网格；页面边距 24，区块间 32，标签到内容 12，列表行间 8 |
| 圆角 | 标签 6，内层 8，控件 10，卡片 16，面板/弹层 20，底栏 24；内圆角 = 外圆角 − 内边距 |
| 字体 | 标题衬线 30；区块 17；条目 15/500；正文 15；次要 13；元信息 12（等宽数字）；字重只用 400/500 |
| 颜色 | 每个外观一条中性梯度 + 三种文字角色 + 一个主色；边框为主文字色 10% 细线 |
| 动效 | 统一缓动 `cubic-bezier(0.22, 1, 0.36, 1)`；反馈 150ms，菜单 200ms，进入 360ms |

## 主要变化

- 去掉全大写英文眉标和宽字距；页眉统一为字标 + 章节编号；页面标题去掉句号
- 底栏去掉主色光晕、渐变选中块和高光描边，改为半透明表面 + 细线；选中态是平面表面台阶；图标统一为 Material outlined
- 卡片阴影收敛为 1px；图标不再用主色，主色只留给主要操作、选中态和一个关键数字
- 账号、备份、更新三个悬浮按钮合并为页眉里的一个菜单按钮，随页面滚动，不再与搜索图标重叠
- 修复：页面切换容器会把内容不满一屏的页面垂直居中
- 欢迎页：去掉 `P O C K E T / C A M P U S` 和问候语标题，渐变卡片改为纯色表面；灯光动画保留，作为入口的重点时刻
