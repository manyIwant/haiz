# 原创图形转场分镜

30fps，共168帧（5.6秒），竖屏1080×1920。素材身份明确：原创概念自习室，不是海南中学实景复原。

- 0–18：HAIZ结构分块保持字形识别，视觉中心停留。
- 18–36：十个对应四边形分解，沿字形结构移位，颜色错峰变化。
- 36–54：对应控制点连续插值成为书页与窗框。
- 54–72：窗框作为遮罩开口揭示真实渲染的3D镜头，继承中心轴。
- 54–161：108帧三维摄影机运动，进入书桌。不是一张图放大。
- 162–167：落在poster；交互工具使用同一末帧背景。

identity.js 中每个图形保留稳定 id 和四段三次曲线路径拓扑，插值锚点与曲率；无随机碎片或仅透明度交替。三主题有独立局部色板。Remotion只生成影片，实时Dock与页面由自身交互代码驱动。

现实限制：当前概念空间采样较低，墙面和家具细节还未达到用户要求的最终美术品质；不能将技术闭环等同专业品牌动画验收。参考视频1000108476.mp4不可读取，因此没有逐帧模仿或分析该视频的声明。

复现：用 Blender 打开 source/HAIZ-concept-study.blend，输出1–108帧PNG至自定目录。运行 `npm ci`（remotion目录），再 `HAIZ_FRAMES=/绝对路径 bash render-films.sh`。当前工作样片以720×1280、4 samples渲染空间，再由Remotion输出1080×1920；1080输出不意味着空间原始渲染是1080。轻度时空去噪用于降低采样噪点，不能替代高品质重渲染。
