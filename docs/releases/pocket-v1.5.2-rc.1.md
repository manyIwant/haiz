# HAIZ Pocket 1.5.2 RC1 · 修复微信通知设置灰屏

## 修复
- 修复 Android 收件箱「指定群通知自动收集」展开后整块灰色的异常占位区域。
- 使用私有的展开状态代替 ExpansionTile 的 PageStorage 状态恢复，防止页面滚动偏移（double）被误读为展开值（bool）。
- 添加 Android 390×844 视口下的展开、输入群名、滚动、收起与再次展开回归测试。
- 保留原有微信通知授权、指定群过滤与人工审核逻辑，不引入后台读取聊天记录。

## 安装区别
- QA APK 使用独立包名，只用于并行验证，**不会**更新现有的正式应用。
- 旧 HAIZ 正式应用需要用原始 Android 签名密钥签发的 1.5.2 包覆盖升级。预发行页本身不能完成这一点。
- iOS IPA 未签名，必须在 Apple 开发环境中完成有效签名后使用。
