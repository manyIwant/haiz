# HAIZ Pocket 1.5.5 · 账号注册入口与体验更新

- 欢迎页直接显示「登录」与「注册」，仍可免登录进入本机空间；保留原灯光欢迎动效和游客模式。
- 注册使用真实 Supabase 邮箱密码接口，增加确认密码、邮箱格式校验和邮件验证说明。
- 登录与注册模式分离：注册时不显示「忘记密码」；切换时清理密码和过期错误信息。
- 登录页保留密码重置、显示密码、返回本机空间；不向登录灯光 WebView 传递密码。
- 继承此前的设备级消息通知诊断和用户数据隔离；不自动合并访客数据到云端账号。
- 版本 1.5.5+2105，Android 原应用包名 `space.haiz.app.preview`，要求与 1.5.4 相同证书签名，避免卸载重装。
- 云同步需要经过真实邮箱验证、账号登录及 RLS 线上验收；自动化测试不能替代生产数据库和 SMTP 的端到端验证。
