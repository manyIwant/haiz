# HAIZ Pocket 1.5.3 RC1 · 微信通知接入诊断

- Android 收件箱新增微信诊断面板：监测关闭、缺少授权、通知监听服务未连接、没有新微信通知、群名不匹配、正文不可见、没有作业关键词、重复、成功收件。
- 诊断仅在用户明确开启后记录微信通知的粗分类、次数和时间；不保存被过滤的聊天原文、群名、发送者及消息 ID，不上传云端。
- 修改监测配置自动清零计数，亦可手动清零而不删除待审核消息。
- 保持原有指定群过滤、微信单独开启、Android 授权及人工审核。
- 新增 Flutter 桥接与状态测试、Kotlin 分类测试；Android CI 增加 JVM 单测。
- QA Android APK 不可覆盖正式版；正式版需由原始密钥在独立校验后本地签发。iOS IPA 仍未签名。
