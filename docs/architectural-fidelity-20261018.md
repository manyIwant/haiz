# 建筑外观细化与设计库研究

本轮回应“外观仍像小游戏、希望更接近照片”的反馈。按北京时间记为 2026-10-18。仍保留现有 34 个模型节点、坐标锚点、开放教室、电影默认入口、路线导演台与机位收藏。

## 实际读取的网上资料

1. `https://github.com/VoltAgent/awesome-design-md`，提交 `3b605329240ce735b510037cca322f1831fdd7f8`。读取 README、MIT 许可及 Oura / Linear 设计分析，采用摄影主导、暖纸留白、精简工具层级、克制圆角和有限时长转场。不是复制其品牌、字体、商标或产品图片；本项目规则见根目录 `DESIGN.md`。
2. `https://github.com/KhronosGroup/glTF-Sample-Assets`，提交 `edc7c9e67c639d230715049ee31f9a96a6babbbe`。检查 Sponza、Barn Lamp、Water Bottle、Diffuse Transmission Plant 等样例的实际许可。Sponza 标记 Cryengine Limited License Agreement，不作为简单开放授权资产使用；灯具的较新各向异性扩展也未直接塞进旧渲染器。
3. 采用 DiffuseTransmissionPlant 中的盆与叶片。原模型是 Rico Cilliers / Poly Haven 的 `potted_plant_02`（2021 CC0）；改编材质和动画是 Eric Chadwick / Darmstadt Graphics Group GmbH（2024 CC BY 4.0）。提供页面署名、模型元数据、独立 NOTICE、来源链接与哈希。
4. 读取 Three.js r128 官方源码提交 `d4aa9e00ea29808534a3e082f602c544e5f2419c`，复用同版本 MIT `GLTFLoader.js`，不跨版本升级引擎。

官网 HTTPS、Poly Haven API 和素材 CDN 的普通读取仍遭遇平台代理 403；申请放宽执行权限访问 Poly Haven API 后同样失败。GitHub 原生 HTTPS Git 读取成功，使用现有平台认证，没有索取令牌或改写代理配置。没有获得新的学校照片，也没有声称完成这轮外部建筑照片核验。建筑依据仍是项目已有的一号楼、二号楼、凤栖堂和图书馆实拍。

## 几何工作

- 原四坡屋顶的前后面使用窄箱体，难以表达完整坡面。改为四个完整的曲面网格，包含翘起的檐缘、立体正脊与斜脊，检查朝上法线与有限坐标。
- 凤栖堂：独立重建两层曲面屋檐，近景使用真实瓦槽起伏与实例化瓦端；木椽、细柱柱础、柱头层次、金色细线、内退木格窗、双门、台阶与栏板均是几何。去掉原来的大块绿色标牌。生成器提供低密度瓦槽版本，但页面运行中切换画质不会重新生成已建好的屋面。
- 教学楼：保留首层通行及原空间体量，上部核心墙退入，外墙按窗位拆出窗间墙与上下窗裙，形成真正的深度。校正一号楼门廊宽度与低坡红檐，不改成不相干的通用欧式建筑模型。
- 图书馆：从竖条方盒改为照片可辨的横向楼板、窗框、栏杆、弧形蓝玻璃、金属圆顶与立缝、大台阶及雨棚。台阶目前是展示结构，不提供垂直攀爬；室内平面没有测绘。
- 降低填充光与环境光，调整晨光方向，让柱、窗框和檐下产生可读的投影；校正绿瓦过强的釉层反光。默认观察机位抬高，避免裁掉圆顶或只看到首层。

比例、构件尺寸、圆顶位置和历史细部仍是照片推演。没有把新增盆栽称为真实校园布置，没有添加身份不明的雕像冒充孔子像，也没有把真实照片盖在镜头前当成完成建模。模型尚不是摄影测量或照片级重建。

## 开源模型的准备和降级

`scripts/prepare-plant.cjs` 对上游 GLB 做确定性提取，保留盆和叶片的原网格、UV、法线及五张选定嵌入纹理；没有重新绘制或缩小纹理。去除高密度碎石、萤火虫、动画、相机、额外灯光、自发光和 r128 不支持的 diffuse-transmission 扩展。输出 3,874,144 字节，具体哈希见 `assets/walk/credits.json`。

使用常规 PBR 与 alpha-cutout 叶片回退，不冒称渲染了新的透射扩展。玩家接近时才加载；只创建三个实例，按 75 个模型单位距离隐藏。低画质或加载失败保留预先建好的盆体。碰撞使用加载前的盆体边界，路径规划器建立后不再偷偷插入新的碰撞物。模型加载不阻塞主校园启动。

## UI 和动效

阅读页使用摄影和真实资料做主视觉；暖纸背景、较大图片、细边界卡片、单一深绿操作色与章节胶囊导航。材质实验区使用深色舞台，但加载前只显示一个平面预览，不叠放空白容器。3D 场景工具改成安静的深色半透明控件，避免大块纸片遮住建筑。

移除阅读卡片的整体透视倾斜，改用有限时长的小幅入场、图片容器内轻微放大、短对话框转场。支持减少动态效果、键盘焦点和手机视口。`R` / 暂停面板提供实拍对照，照片与模型分开展示，不伪装成标定后的视角匹配。

## 验证

```sh
npm run build
npm test
npm run test:browser
npm run test:atelier
```

普通回归包括链接、原路线、四站自选路线、碰撞、16 间教室往返、电影交接、摄影下载与机位恢复。新增检查包括曲面屋顶朝上法线、低画质几何降级、特征标记、三处盆栽、GLB 字节边界、哈希与许可署名。

专门的浏览器检查实际解码本地 GLB，检查原 PBR 和透明叶片，渲染三处建筑，测试参考照片切换、恢复取景、低画质隐藏及桌面/手机页面布局。截图保存在被忽略的 `tests/artifacts/atelier-*.png`，报告在 `tests/atelier-browser-results.json`。截图用于人工观察轮廓、裁切和高光；自动测试通过不等于照片级真实感达标。

云端 WebGL 使用 SwiftShader 软件渲染，手机为视口模拟，未做用户设备帧率或现场尺寸验收。开发环境继续使用现有依赖与 Chromium，无新增安装要求或常驻服务，不需要覆盖现有环境配置。
