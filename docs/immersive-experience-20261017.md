# 从星球到取景框

## 入口与内容

静态托管网站的默认文档是 `index.html`。构建先把原杂志生成到 `journal.html`，再由 `scripts/build-experience.cjs` 注入全站探索资源，并将 `descent.html` 完整复制为 `index.html`。因此根地址直接呈现降落体验，不依靠 JavaScript 重定向；`descent.html` 仍可单独访问。静态测试断言两文件内容完全一致。

电影首页增加杂志入口、播放速度、触摸拖动与星空细节。用户开始前不加载三维校园 iframe；开始后才提前准备校园，保留抵达后的同源消息交接及独立校园入口。局部地理影像按高度逐渐混入，避免星球视角上的小块高分辨率贴片。

## 全站探索

`assets/js/experience.js` 提供有键盘操作的搜索、随机地点、数字校园足迹与合成声景。搜索只索引项目中真实存在的页面与模型地点，无远程搜索服务。输入为普通文本匹配，结果使用 DOM 文本节点创建。足迹只存地点 ID，可清空；建筑收藏、新闻收藏和便笺仍使用各自明确的本机存储。

声景使用 WebAudio 合成低通风声、高通雨声与一次性课铃。它们是创作声音，不是校园实地录音。音频上下文在明确点击时创建，不自动播放；页面隐藏时暂停。电影把控制权交给校园时关闭父页声景，避免重复声音。

动态效果包含渐入、图卡轻微视差/倾斜、浏览器支持时的跨页面 View Transition，以及同步树叶与阴影的微风。减少动态效果偏好会禁用连续摆动、自动旋转及转场动画。低画质也关闭叶片摆动。

## 材质与互动实验

`assets/walk/surfaces.js` 的四类原创材质升级到 512×512：

- 颜色图按 sRGB 解码；高度、法线和粗糙度保持线性数据。
- 法线来自可平铺高度场的中央差分；接缝使用循环采样，保留微小颗粒与瓦筒起伏。
- 墙砖与绿瓦使用不同程度的物理釉层，红瓦更粗糙，石材和木构保留各自的粗糙度。
- 空间贴图密度按模型长度投影，不随着楼体宽度直接拉伸。
- 气候按材质类型改变暗度、粗糙度和釉层，干燥后恢复基线；水面与既有地面反射仍按画质和距离启用。

`assets/js/material-lab.js` 仅在材质实验区域接近视口时初始化 WebGL。它复用校园的生成器、本地 HDR 与正确颜色管理，提供拖动旋转、材质球/铺装板、湿度、铺设密度与光照选择。切换到平面或高度图、离开视口、隐藏页面时停止连续渲染。纹理复制仅供实验室调整密度，避免改变校园材质。WebGL 不可用时保留颜色/高度图。

这些是参考既有实拍的程序材质，不是新增实景扫描，不改变照片和已有 CC0 素材的授权状态；尺寸仍是设计近似值。

## 摄影

`assets/walk/workshop.js` 复用当前场景：32°–80° 镜头、模拟气候、无界面明信片下载、地点入口分享。截图在一次实际渲染后立即读出，不全程保留绘图缓冲区；明信片由浏览器合成地点、模拟光照与日期，注明是数字校园创作模型。照片只下载到用户设备，不上传，不占用本机足迹存储。

## 验证与发布边界

运行 `npm run build`、`npm test`、`npm run test:browser`。后者验证真实 Chromium WebGL 的首页与材质着色器、桌面/手机视口、搜索、声景开关、釉层/法线与湿度响应、摄影镜头及 PNG 下载。`tests/browser-results.json` 为结果，`tests/artifacts/` 为不进 Git 的截图与明信片。

云端渲染器为 SwiftShader，手机测试是视口与触摸能力模拟；没有声称完成用户硬件帧率、听感、物理手机多点触控或现场尺寸校验。仓库分支更新不等于 GitHub Pages 或 `haiz.space` 已发布。
