# 树荫下的三次停留 · 本轮交付记录

基线：main / c8ca4aa9621cb55fce130aa1fda4a741e9a9b8a7。工作分支：feat/memory-climate-route。
本轮未覆盖 main、probe 或线上 haiz.space。GitHub 创建分支返回 403（Resource not accessible by integration），无法同步。

## 设计判断与范围

1. 真实感首先取决于轮廓：北门的进深过厚、榄仁树的低分叉与横枝缺失、砚池像规则水盆。优先修正这三项，保持全校坐标与建筑占地。
2. 空间和文章缺少共同资料入口：以 memory.js 为共享档案，连接三维地点、静态阅读页、相关报道卡片。
3. 原始测绘证据缺失：继承转换坐标，但不把路线称作现场验证导航。未取得原 KML、转换脚本、立面尺寸或摄影机标定。

选择“树荫下的三次停留”为主线，天气作为同一地点的观察条件。未选择“百年叠影”（缺少准确年代和机位）；“校园一日光谱”作为三种环境预设，而非另开大型时间系统。

艺术规则：暖纸色界面、深绿文字、陶土色提示；先看门洞，再看横枝，最后停在岸边；同一地面高度连续行走，不飞越建筑。环境切换平滑改变照明和材质，不以全屏滤镜冒充天气。手机保留触屏行走，文字阅读与三维入口并存。

## 实现

- 北门：参照仓库实拍，缩小柱体与檐部进深，调整中央和侧屋檐比例；不改南门。
- 榄仁树：接回上轮未提交 memory-art.js 的曲线枝干、低处分叉、树根与实例化叶簇。旧草稿未覆盖。
- 砚池：保留已有池体边界，增加靠岸层叠石块和植被；小幅水面法线变化。矩形边界仍需实测改进。
- 三种环境：晨光、雨后、薄暮，联动天空、雾距、太阳方向与颜色、曝光、路面湿润程度、水色与涟漪；全部明确标注模拟。没有实时气象数据，没有降雨粒子或录音。
- 三站路线：A* 查询实际碰撞场景、连续线段相交检查；到站停下阅读记忆；键盘、摇杆、环顾均可原地接管。路线可能经过模型内开放地面，不声称贴合现实校道。
- 轻量入口：memory-walk.html 无需 JavaScript 或 WebGL；全站导航、对应新闻卡片及三维地点可相互跳转。
- Three.js r128、34 个节点、原有教室和资源体系保留，无新增运行时依赖。

## 对抗审查与修正

- 发现路线抽样漏掉墙角擦边，导致途中中断：改用扩张障碍盒的连续线段相交判定，三站再次跑通。
- 发现到达航点的宽松阈值可能切角：必须走到航点，再转向下一段。
- 发现手机环境标记与小地图重叠的样式风险：环境标记改到左上方，路线按钮下移。
- 防止参考北门的修改同时改变南门：将新比例限定到 beimen。
- 实拍授权与原始测绘未核实：明确列出，不生成伪历史或测量精度。

## 尚未验证 / 不应提前上线的原因

本环境没有受支持的浏览器控制能力，因此没有浏览器截图、WebGL 着色器画面检查、Lighthouse、实机帧率、内存测量或真实用户测试。运行测试的 renderer 是替身，不能代表 GPU 画面。尚不能声称“真实复刻”或“电影级画质验收完成”。

下一步验收：在真实浏览器进入 campus-3d.html，暂停面板启动三次停留和切换气候；分别在北门正面、树下与池岸拍对照截图；在用户旧 Mac 与 Android 上检查帧率、触屏、文字遮挡和水面表现。补充现场尺寸、路线确认与影像许可后再考虑合并。
