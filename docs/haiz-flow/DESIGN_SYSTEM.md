# UI设计系统

来源：用户UI V1六张截图与交互HTML；暖白、森林绿、珊瑚强调、编辑式标题沿用。所有交付截图由运行网页截取。

CSS tokens见world/flow/style.css首行：canvas #F4F5F2 / dark #151C19；surface白 / #233029；brand #31594E / #B0D5BD；正文15px，提示14px，关键标题32–44px。12px仅用于非关键英文眉题。内容卡不透明，无常驻玻璃模糊。触控按钮最小44px，卡圆角22px。

布局：1440桌面222px导航+主列+286px上下文；中等窗口收起上下文，650px以下单列与底部导航；屏幕大字28px摘要。提供浅/深/高对比，focus-visible，reduced-motion；未打包Apple字体或SF Symbols。

组件：私有编辑器、受众与时间选择、公开预览、同步状态、双版本冲突卡、恢复历史、作品草稿、社团搜索卡、只读公告、情境选择、命令面板。

状态语义：本机保存≠已同步；版本冲突≠保存失败；服务端确认才显示已发布；本机图片明确不上传；离线保留有效缓存并显示上次成功同步。公开/权限/失败文案不玩梗。学生语气只作用于轻松内容。
