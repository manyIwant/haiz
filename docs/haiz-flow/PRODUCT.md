# 一件工作，在合适的屏幕继续

教师D：手机记录，桌面完善，确认后公开。草稿是私人工作资料，公告是独立公共对象。Windows没有手机展示框，提供三栏；手机缩短到单列编辑与底部动作。情境可手动切换，不收集位置、声音或行为。

学生C：今日必要信息、有限示例社团、作品草稿和自习入口。默认有趣，支持安静/抽象；关键事务文案保持明确，不做排名、无限流或伪造报名。

公共屏：只读本班摘要、有效期、来源与同步时间。纯净课堂/手动隐藏由现场控制。即使没有手机，学生仍能获取公共提醒和原晚修作业。后台故障不修改ClassIsland的课表、铃声。

教师节时、误发减少与学生使用价值尚无用户研究证据。应请真实愿意参与的教师完成“查材料、手机接力、发布撤回”，记录用时/错误/需帮助次数，再与原流程比较；不要以开发者自测替代需求验证。
