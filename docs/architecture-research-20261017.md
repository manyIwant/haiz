# 府城校园外观与室内资料复核

## 本轮结论

“更像真实校园”的优先级是：纠正错误影像对应 → 窗面与墙体层次 → 建筑之间的轮廓差异 → 统一光照、天空与水面 → 室内材料和家具。没有凭公开照片推导完整室内平面图。

本轮搜索覆盖学校官网域名、海南日报、人民网、公开全景、室内设计项目目录及 Three.js 官方源码。学校官网请求超时；一项设计项目目录搜索摘要显示“衍林书屋”，但打开后的正文是无关营销内容，因此排除，不能拿搜索摘要当设计证据。

## 错标影像处理

- `campus_yanlintang.jpg` 的画面是亭子，不足以证明是衍林堂主体。保留文件以免破坏用户资产，撤掉 data/buildings.json 中该堂的错误实拍关联，把候选路径与原因保存在 imageReview。
- `xxgk-yanlintang-800.jpg` 实际画面是校门，不能依据文件名建模。本轮不采用它作为衍林堂立面参考。
- 衍林堂本轮保留近似体量，并给出历史资料入口；没有把黑白历史影像直接重建成当下建筑。
- 新查到的外部照片只在研究时查看，没有重新发布或用作模型纹理；新增源码依赖的授权另列于 credits.json。

## 开源复用

直接复用了 Three.js **r128** 的 `examples/js/objects/Water.js` 和 `Sky.js`，保持与仓库运行版本一致，没有跨版本升级渲染引擎。对应 MIT 许可证随项目保存在 `assets/vendor/THREE-LICENSE.txt`。

- Water：主砚池 256×256 平面反射；距池岸 55 个模型单位以内、非室内且画质不是 low 时启用。只建立一个水面反射对象。低画质自动恢复标准材质水面。
- Sky：官方大气散射着色器；太阳方向与校园阴影、水面光向一致，雨后模式改变浑浊度。是艺术气候模拟，不是实时气象或准确太阳历。
- Poly Haven：继续使用项目现有 CC0 草地、混凝土、灰泥、木材、水磨石与环境光照资源。没有引入另一套不相干的通用校园游戏资产。

## 实现与验证

1. 修复窗玻璃藏在实体墙内的问题，增加实例化窗边框、窗台和中梃。CPU 射线测试确认：一号楼抽样上层窗户的玻璃在墙面之前被命中。
2. 一号楼补充中央立面分隔和浅屋檐；二号楼不再沿用相同的大坡顶。凤栖堂补充红金柱体与木窗格。细节按建筑合并或实例化。
3. 室内增加蓝色座椅、浅绿窗帘、书柜、讲台与显示设备。仍是 16 间近似室内，不是实际班级布置。
4. 地点面板增加建筑照片对照和可信度说明；科学馆、二号楼加入原有地图目的地列表。
5. 建筑观察镜头平滑切换至 48° 视角，隐藏准星和小地图；可随时在暂停面板关闭。
6. 本地 file:// 模式使用内置空间与生成材质，避免继续读取被浏览器安全机制拦截的扫描纹理。HTTPS 模式保留完整扫描材质。

构建：`npm run build`。自动验证：`npm test`。结果分别在 `tests/site-results.json`、`tests/walk/results.json`、`tests/walk/runtime-results.json`。

运行测试覆盖正常 HTTPS JSON、本地 file://、JSON 网络失败回退、桌面/手机输入、三站行走、观察模式控制和水面反射质量切换。渲染器是测试替身，**没有进行 GPU 着色器、真实画面、实机帧率或触屏布局验收**。当前没有 Sites 支持的 control-browser 能力，按该流程没有另装或绕用浏览器。

## 上传状态与后续门槛

本轮通过 GitHub 插件重新尝试创建独立分支 `feat/campus-architecture-20261017`，接口仍返回 `403 Resource not accessible by integration`。仓库元数据中的 push 权限不代表当前集成令牌具备创建 ref 的能力。没有直接覆盖 main 或 probe，也没有绕过拒绝。
