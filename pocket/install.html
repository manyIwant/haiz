在 iPhone 上安装（约 4 步）

  1. 用 Safari 打开此页面。若当前在微信、QQ 等内置浏览器，请选择「在浏览器打开」或复制地址到 Safari。
  2. 点击上面的 打开 HAIZ Pocket，等应用界面加载完成。
  3. 在 HAIZ Pocket 页面打开 Safari 的「分享」菜单，选择添加到主屏幕（新版本可先选「编辑操作」）。如出现「作为网页 App 打开」选项，请保持开启。
  4. 点「添加」，以后从 iPhone 主屏幕的 HAIZ Pocket 图标启动。

重要：一定在打开 HAIZ Pocket 后再添加到主屏幕，避免把本说明页安装成图标。

第一版能做什么，不能做什么？

可以使用 Flutter Web 版的学习界面。首次联网并完成资源缓存后，部分功能可离线打开；首次安装、更新、登录和同步仍可能需要网络。

不能自动读取微信或 QQ 消息，也没有 iOS 原生系统分享扩展。推送提醒尚未作为本版可用功能交付。

先保存自己的数据

HAIZ Pocket 的访客空间提供「数据备份与恢复」，可以导出、校验并合并恢复 JSON 文件。重要课表、任务和记录建议先备份到 iPhone「文件」。备份包含私人信息，不要把 JSON 发到公开群聊。

清理 Safari 网站数据、删除网页 App 或系统回收存储空间，都可能导致本地数据丢失。不同设备、浏览器或独立网页 App 的本地存储也不保证互通。应用更新通常只替换程序资源，但不能代替个人备份。

HAIZ 是学生独立创作的非官方校园学习工具，不代表海南中学。网页 App 的离线能力和视觉兼容性仍需真实 iPhone 验收。
