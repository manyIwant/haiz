HAIZ / Pocket / Web App

把学习空间
放进主屏幕。

无需 IPA、证书或 App Store。HAIZ Pocket 可以作为网页 App 运行，界面与原生 Flutter Pocket 共用业务代码。

打开 HAIZ Pocket 返回 HAIZ 校园网站

在 iPhone 上安装

  1. 用 Safari 打开此页面，并点「打开 HAIZ Pocket」。
  2. 点击 Safari 的 分享 按钮。
  3. 找到并选择 添加到主屏幕，名称保留「HAIZ Pocket」。
  4. 点「添加」，从主屏幕打开 HAIZ Pocket，即可获得独立 App 窗口。

你能获得什么

课表、任务、学习记录、专注工具、文件选择，以及已缓存资源可用时的离线启动。联网重新打开会检查新版本；发现更新时由你确认刷新。

注意：网页版不能在后台自动读取微信聊天，也不能充当 iOS 原生分享扩展。推送提醒还需要部署经用户授权的 Web Push 服务。浏览器本地记录也可能在清理网站数据时丢失，请妥善备份重要内容。
