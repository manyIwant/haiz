## 内容

- **首页**：校园品牌、学术板块、校园生活、3D 入口
- **学校**：学校概况与办学历史
- **学术**：学科建设、教研活动
- **校园生活**：社团、艺术、体育
- **新闻**：校园新闻（基于公开报道）
- **招生 / 校友 / 社团**：分类信息
- **3D 数字校园**（`campus-3d.html`）：基于真实平面图的 WebGL 校园
- **关于这个网站**：联系方式、隐私政策、免责声明、网站地图、创作者介绍

## 本地预览

```bash
cd site/
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

> 注：3D 校园页依赖 WebGL，请在桌面浏览器中查看以获得最佳效果。

## 技术栈

- 纯静态站点：HTML + CSS + 原生 JavaScript，无构建步骤
- 3D：`three.js` r128（`assets/vendor/`，本地引入，无 CDN 依赖）
- 数据：`fetch('data/*.json')` 读取（相对路径，子路径部署友好）
- 设计系统：CSS 自定义属性 + 模块化组件类

## 部署

- **GitHub Pages**：直接推送到 `main` 分支即可启用 Pages
- 所有路径为相对路径，子路径部署无障碍
- 仓库体积约 17 MB（不含开发备份），单文件 < 700 KB
