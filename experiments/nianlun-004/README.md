## 一、从「抽出一年」到「活木时光」的五项核心进化

### 1. 活体形成层（Living Cambium）：重新设计年轮的详略关系
- **问题**：原有 104 圈年轮按雨量近乎均匀分布，桌面端每圈仅 ~2.9 px、手机端仅 ~1.5 px，近期学年（2026）与历史年份一样细密，手机手指极难精准选中。
- **方案**：模拟真实树木**「心材致密沉淀、边材与形成层活跃舒展」**的生理结构，提出非均匀径向权重函数（`physics.js` `cambiumBoost`）：
  - **今岁形成层（2026）**：自动舒展至 ~30–35 px（桌面）/ ~18–22 px（手机），外圈嵌有温和呼吸的**今日琥珀刻痕（11 月 25 日）**与考试/任务微印，手机端可直接轻点抽出；
  - **近岁边材（2022–2025，含百年校庆 2023）**：平滑衰减过渡，覆盖整个中学阶段与近年记忆；
  - **百年心材（1923–2021）**：紧凑沉淀同时保留雨量宽窄与年代线，并配合**自适应径向鱼眼**（内圈高放大、外圈低抖动）与**磁吸迟滞刻度（Magnetic Detent）**；
  - **手机精准选轮条（Touch Precision Bar）**：移动端触碰心材历史圈时自动在顶部锁定所选年份，支持 `−1年 / +1年` 步进微调与一键「抽出此年」，彻底摆脱拇指遮挡与松手漂移；
  - **可逆疏密切换**：右上角「疏密 · 今岁舒展 ⇄ 百年均分」一键弹簧过渡，兼顾日常效率与百年均分视角；
  - **快径直达**：树干下方提供极简墨线快径（`今日 · 11月25日` · `本周课表与待办` · `本学期` · `2026 抽出` · `2023 百年`），高频日常无需每次等待完整卷轴动画。

### 2. 多材质时间带（Multi-Material Time Ribbons）
不再将传统卡片硬贴到时间轴上，而是让六类时间信息通过**材质、纹理、色彩、空间形态与触觉声效**原生生长在同一根同步时间坐标上：

| 时间带层 | 材质隐喻 | 承载内容 | 视觉与触觉语言 |
| --- | --- | --- | --- |
| **木 · 天候校史** | 原生榄仁木带（WebGL 2） | 31,732 天 ERA5 气候档案、14 条 HAIZ 校史、6 条公开新闻 | 保留 PR #114 原版木纹着色器、雨天着墨、台风留疤与校史木结，新增今日琥珀脊线 |
| **竹 · 课表作息** | 刻槽竹简（Canvas 2D） | 完整周课表、海南中学夏季/冬季作息（源自 `data/news.json n10`）、关联教室与实验册 | 淡青竹纹与周期竹节；矿物质颜料（朱砂/赭红/群青/石青/松绿）编织每日学科节拍 |
| **纸 · 作业待办** | 压痕棉纸签条 | 学科作业、截止日期、预计耗时、完成态、关联课程与错题来源 | 宣纸纤维与折痕边；临近/紧急呈朱砂渗边；已完成淡墨划除；**可直接揭起跨带拖拽** |
| **靛 · 个人日程** | 靛蓝织布留白带 | 个人学习计划、复盘、社团与运动（**默认仅本人可见**） | 扣除作息/课表/考试后自动计算并透亮显示**可用空闲时段**；冲突处涌现**朱砂波纹警示** |
| **朱 · 考试成绩** | 宣纸朱砂方印与墨韵脊线 | 考试安排、历次成绩、学科均衡、失分归因与错题库（**默认仅本人可见**） | 已考为实印、待考为虚框印，墨韵成绩脊线串联历次起伏；**点击方印二次抽出完整学情卷** |
| **叶 · 校园成长** | 拓叶与火漆印记 | 校园活动通知与个人成长日记（清晰区分校方公开与私密成长） | 官印青戳（校园）与琥珀叶印（私密成长） |

### 3. 连续语义缩放（百年 → 年 → 学期 → 月 → 周 → 日 → 小时）
- **树干 → 木带**：支持「全年 / 本学期 / 本月 / 本周」弹簧窗口缩放与左右平移（顶部刻度、滚轮缩放、键盘 `+`/`−`），主木带 WebGL 着色器与所有剥离材质带保持亚像素级同步；
- **手机竖向并排挂轴**：竖屏下仅看木带时完整保留 PR #114 的右侧竖挂轴；剥离多层后木带优雅左移，竹/纸/靛/朱/叶并行向右展开为多列同步竖卷，零横向溢出；
- **日视图 · 校园天空与时辰作息地平线**：打开任意一天展开府城校区真实日月天空，底部地平线可在「全年木带」与「**今日时辰作息带（06:00–23:00）**」之间一键切换，拖动太阳时一道柔光垂线同步掠过早读、八节课、文体活动与晚修。

### 4. 跨时间带真实交互（Cross-Ribbon Functional Value）
- **作业纸签 → 个人日程空闲时段**：直接拖动纸签作业带上的任务至靛布日程带的透亮空闲时段（或点击「排入空闲时段」），自动建立日程块并拉出丝线关联；
- **考试安排 × 个人计划实时冲突检测**：采用区间扫描线算法即时发现重叠（内置 11 月 26 日物理阶段测验 × 科创社冲突示例），在时间带上以朱砂波纹警示并支持「一键顺延至空闲时段」；
- **抽出考试 → 借鉴智学网的本地学情分析卷**：点击朱砂方印抽出考试卷轴，提供原始总分、与上次对比进退步、学科均衡稳健度、墨韵学科均衡与历次叠合图、**失分归因拆解（概念/审题/计算/思路/时间，量化「易拿回分值」）**、CSV/表格粘贴批量导入成绩；
- **考试错题 → 1-3-7 天复习计划**：在错题本中一键「转 1-3-7 天复习」，自动按间隔重复节律排入未来 +1/+3/+7 天空闲时段，同步写入作业带与个人日程带；
- **课程 ↔ 作业 ↔ 校园地图/实验册关联**：点击课程可直看关联作业、对应教学楼（`data/buildings.json`）与 HAIZ 实验册互动实验（`lab/js/catalog.js`），并可一键为该课布置作业；
- **圈选缺席区间 → 缺席补课汇总单**：激活「圈选缺席」并在时间带上拖选（或自定起止日期），自动汇总该时段错过的全部课程、作业、考试与校园通知，支持「一键排入补学日程」。

### 5. 真正可用、隐私隔离与 HAIZ 生态预留
- 全部模块支持真实的新增、编辑、删除、完成状态、时间调整、学科筛选与跨层关联，自动持久化至 `localStorage`（兼容 HAIZ `src/account/session-guard.js` 账号作用域隔离），刷新页面完整保留；
- 内置清晰标注「演示」的 2026 秋季学期高二演示数据，支持「一键清空演示数据，开始我的记录」、「恢复演示数据」、完整 JSON 备份导入导出以及 **HAIZ Pocket `PersonalSnapshot v1` 快照导出**；
- 成绩、错题、私人日程与成长记录均标为 `visibility: "private"`（仅本人可见）；**绝不连接未经授权的智学网接口，绝不收集任何外部账号密码**；
- 附带 `supabase-schema.sql` 蓝图，沿用 HAIZ `supabase/migrations/202610310001_pocket_snapshots.sql` 的非匿名 `auth.uid()` RLS 与乐观锁 CAS 契约，为后续接入正式账号系统做好准备。

## 三、诚实的边界

- 气候数据为 ERA5 25 km 网格再分析（截至 2026-11-16），非校内气象站实测；夏季作息表源自 `data/news.json (n10)`，冬季作息为季节微调参考；标准分参考估算仅基于本地录入百分位/得分率换算，不代表海南省考试局官方赋分。
- 浏览器 E2E 验收与截图/录屏在 Linux Chromium（SwiftShader 软件渲染）及桌面/iPhone 13/360px 视口仿真下完成；物理真机 iOS Safari / 微信内置浏览器帧率与震动手感仍需真机实测确认。
- 本实验完全独立于 `experiments/nianlun-pull-a-year/`（NIANLUN 003）及生产站页面，未修改任何根仓库共享代码。
