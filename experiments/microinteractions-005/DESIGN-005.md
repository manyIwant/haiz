# DESIGN-005 · HAIZ 的行为美学

> 视觉美学回答“它看起来是什么”；行为美学回答“它怎样让开、怎样生长、怎样回到原处”。

## 1. 从三种 Dock 到一种语言

Experiment 004 留下三条路：A 让位（相邻格位按距离让出宽度）、B 同源（整条导航是一条液态轮廓）、C 生长（从折痕处展开一块可操作的舞台）。三者各自成立，叠在一起就成了特效的堆砌。005 不叠加它们，而是问：**它们共同的物理是什么？** 答案是四条定律，所有动态组件都只用这四条。

| 定律 | 含义 | 来源 | 在哪里 |
| --- | --- | --- | --- |
| **让位 Yield** | 一个东西变大，邻居按距离衰减让出空间（1 → .31 → .09），总量守恒。不放大，不遮挡。 | 004-A | Dock 格位、周视图的五列、侧栏的悬停底板、详情面板出现时页面让出宽度、专注时外壳退后 |
| **同源 One contour** | 新的表面从已有的轮廓里长出来，和它共用一条边界，没有接缝。 | 004-B | Dock 的舞台与搜索、顶栏搜索框长成命令面板、按钮长成菜单（Select）、铃长成通知面板、手机上列表行变成底部抽屉 |
| **生长 Growth** | 展开有方向、有先后：轮廓先到，内容按距离依次显现；收起按原路返回。 | 004-C | 舞台内容的 `--i` 交错、页面切换从手势原点按距离错时出现、详情从被按下的那一行出发 |
| **基准 Datum** | 一条细线承载“你在哪里”，并携带屏幕上**唯一的亮点**。 | Hairline | Dock 底部随焦点弯曲的基准线与亮点、侧栏的竖向基准、滑块下沉的基准、时间轴的“现在”线 |

### 三个深度：掠 · 停 · 入

同一个对象对注意力有三档回应，不需要额外的提示：

- **掠 Pass**：指针经过。几何先变化（让位、图标前倾），在点击之前就告诉你“这是可以去的地方”。
- **停 Dwell**：静止 280ms（触屏长按 380ms）。从同一条轮廓里长出舞台，给出这一处的现在与两个动作。
- **入 Enter**：点下。亮点沿基准线滑到新位置，页面从手势原点展开。

速度仍在移动的指针不会触发“停”：只有最近 70ms 内真的停下才算，扫过时不会弹出任何东西。

### 打断与反向

所有连续变化都是弹簧，目标随时可以改；从来没有“等动画播完”。Dock 的焦点切换只在离开当前格位时发生，并且新索引永远按**静止布局**计算，所以快速来回扫动时焦点不会在两个格位之间抖动（验收台的“高速折返打断”专门检验这一点）。

## 2. 两种时间

- **连续的**用弹簧：跟随指针、让位、拖动。参数分几档（follow / ui / lift / soft / snap），不按组件各自调。
- **离散的**用 700ms 的 `cubic-bezier(.32, .72, 0, 1)`：数值换了（柱高、叶色、状态），一次落定。

全部动效共用**一个时钟**（`src/kernel/motion.ts`）。它可以整体慢放、暂停、单帧步进（验收台用的就是它），也能在“动态强度”为 0 或系统开启“减少动态效果”时让一切立即落定。CSS 过渡同样挂在这个时钟上：时长写成 `calc(Xs / var(--ts))`，减少动态时 `--ts` 设为 1000。没有东西在动时时钟不申请动画帧，验收记录里“空闲 2 秒走了 0 帧”就是这条。

## 3. 材质

| 材质 | 用在哪里 | 规则 |
| --- | --- | --- |
| 纸 Paper | 所有页面的地 | 暖、哑光，从不纯白；深色时是墨绿的夜 |
| 墨 Ink | 文字与线 | 一种绿黑的四个强度；层级靠墨的深浅，不靠颜色 |
| 琉璃 Glaze | 只给浮起的工具：Dock、命令面板、弹出层 | 磨砂、微染、上缘一道亮边，取自府城北门的绿琉璃瓦；SVG 轮廓 + `clip-path` 的玻璃层 + 只画在外侧的描边 |
| 木 Grain | 与时间有关的场景：日程、年轮、成长、专注记录 | 暖底色，不用纹理图片 |
| 光 Lit | 屏幕上唯一的亮点 | 琉璃绿；榄仁红只留给未读与截止；教师身份换成陶土色 |

不用的东西：粒子、外发光、装饰性渐变、假 3D、伪造的照片融合、把所有元素都做成胶囊。

## 4. 每个区域如何使用这套语言

- **底部 Dock**（手机为主导航，桌面为当前页的工具）：掠 → 停 → 入；搜索时胶囊收成当前页的圆，卫星长成输入框，结果向上生长；专注时 Dock 变成计时器自己的控制。
- **侧栏**：悬停底板是液态的，竖向基准向当前项与指针弯曲；紧凑模式下标签从图标里长出来。
- **顶栏与全局搜索**：搜索框本身长成命令面板（⌘K 或 /），面包屑按面板展开的程度让位。
- **页面切换**：从手势原点按距离错时出现；手机二级页从右侧推入。
- **列表 ↔ 详情**：桌面在右侧打开检查器，页面让出宽度，一道液态桥把被按下的行和面板连起来再退去；手机上那一行自己变成底部抽屉，向下拖回到原处。
- **基础组件**：开关的旋钮按速度拉长；滑块的基准在拇指下下沉，读数从拇指里长出；分段控件只有一块共享的底板在滑行；输入框的亮线从按下的位置向两侧长出；勾选的笔画被画出来。
- **图标**：26 个带物理的线稿，掠时先变化，按下时形变，选中时点亮唯一的亮点；只在运动时重绘。

## 5. 研究与取舍

- **OJO 原型**只作为信息架构与排版参考：今日、学习、校园、我的结构保留；它的卡片堆叠和通用图标没有沿用。
- **Hairline**：吸收了它的等距线稿语法（亮轮廓、暗内部、真实的遮挡顺序、楼层线只画在内部）、衰减曲线、“一个亮点”、睡眠的循环。校园地图直接用 HAIZ 校园模型的真实平面以这种语法绘制，不做低精度模型。
- **真实资产**：校园平面与说明、照片、ERA5 天气档案、painted-lab 的渲染与绘画都来自 HAIZ 仓库；painted-lab 的渲染图原本带有对比滑块的标记，用可复现的脚本修除（中缝处两种着色方案的差异如实保留并注明）。
- **刻意不做**：macOS 式放大、所有组件同一种动效、全屏胶囊化。

## 6. 已知局限

- 帧时间在无头 Chromium 中测得，不代表具体手机；真机上的 GPU 与发热未测。
- 课表、通知、社团等是演示数据，没有接入后台。
- 琉璃材质的模糊依赖 `backdrop-filter`；不支持的浏览器上只剩半透明的琉璃底色，文字仍然清楚，但没有磨砂感。
