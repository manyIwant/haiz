# NIANLUN · 年轮 第二代交互研究报告
## 形态、运动与空间的重构（Interaction Lab 002）

> **核心追问**：我们不是在创造一个圆形的界面，而是在探索——**当人的手触碰界面之后，空间本身能够发生什么？**

---

## 一、为什么推翻上一代（PR #110）并重新开始

第一代年轮时间仪（PR #110）完成了极坐标多尺度刻度与天文计算，但复盘真实体验后，我们发现它没有突破传统范式：

- **本质仍是「圆形导航 + 侧边卡片」**：圆盘只负责选时间，真正的阅读与操作依然发生在右侧传统的矩形卡片面板中。
- **空间割裂**：圆盘与内容之间没有物理连续性；点击事件后依然靠传统列表与表单承接。

因此，本轮（002）彻底放弃「做完整日历应用」的包袱，改为建立一个**交互研究实验场（Interaction Research Lab）**：
围绕**完全相同的 5 个真实可操作对象**（节律 `Pulse`、日照 `Helios`、单摆 `Pendulum`、校景 `Atlas`、年轮 `Cambium`），实现并实时对比**四种具有根本差异的交互机制**。

## 二、外部研究与「不重复造轮子」的技术落地

在编写代码前，我们逐一研读了外部优秀交互项目与开源源码，并直接将成熟引擎引入工程（详见 [`THIRD-PARTY-LICENSES.md`](THIRD-PARTY-LICENSES.md)）：

| 外部研究对象 | 核心洞见 | 在本实验场的真实落地与复用 |
| --- | --- | --- |
| **Kando** (`kando-menu/kando`) | 之所以真正实用，是因为「在指针处唤出 + 拐角/停顿即进入下一层」让熟手用一笔划穿多层级，同时新手可以逐层点击 | 直接移植其 MIT 授权的 `GestureDetector`（`src/kando-gesture.js`）驱动 **实验 III「一笔穿层」** |
| **d3-fisheye** (`duaneatat/d3-fisheye`) | 平滑 Sarkar-Brown 径向畸变 + 可逆变换，让焦点放大而周边自然折叠让位，彻底消灭弹窗遮挡 | 直接引入 `d3-fisheye@2.1.2` + `d3-delaunay@6.0.6` 驱动 **实验 II「时空透镜」** 60fps Voronoi 连续细胞膜 |
| **Codrops ElasticSVG / ShapeMorph & Flubber** | 有机轮廓形变与弹性过冲赋予界面「生物张力」，让对象在原位生长而不发生容器替换 | 直接引入 `flubber@0.4.2` 2D 路径插值 + `gsap@3.15.1` 弹性物理缓动 + `d3-force@3.0.1` 碰撞引擎驱动 **实验 I「让位生长」** |
| **D3 Zoomable Sunburst** (`d3-hierarchy` / `d3-shape`) | 极坐标层级展开时，子级继承父级的角度与方向脉络 | 直接引入 `d3-hierarchy@3.1.3` + `d3-shape@3.2.0` + `d3-interpolate@3.0.1`，并升级为 **实验 IV「年轮解体」**（圆心同步变为实操画布） |

## 三、四种截然不同的交互机制对照

| 实验 | 空间法则 | 打开一个对象时发生什么？ | 周围信息去哪了？ | 独特交互潜力 |
| --- | --- | --- | --- | --- |
| **I. 让位生长** (`#yielding`) | 弹性粒子空间 (`d3-force` + `flubber`) | 节点**自身在原位弹性生长**为柔和超椭圆画布，直接内置实操控件 | 被 Velocity Verlet 物理碰撞推开让位，零遮挡 | 支持**多对象拖动共生**（如日照⇄校景实时投射阴影、单摆⇄节律过零击节） |
| **II. 时空透镜** (`#fisheye`) | 连续细胞膜 (`d3-fisheye` + `d3-delaunay`) | 指针与点按弯折整张 Voronoi 拓扑，目标多边形膨胀，实操画布嵌入细胞壁内 | 其余 4 个对象与年轮心平滑折叠于周边弧缘，点任一邻居即刻流转焦点 | 无需「打开/关闭弹窗」概念，焦点与全局始终同屏连续 |
| **III. 一笔穿层** (`#marking`) | 随手唤出的瞬态径向场 (`Kando GestureDetector`) | 任意处按住→划向对象→**拐弯或微停**→子环就地裂变，一笔直达参数并松手完成 | 画布始终完整呈现 5 个对象交织的实时世界雕塑 | 高频操作耗时可压至 `<0.5s`，同时保留点击模式照顾首次访问者 |
| **IV. 年轮解体** (`#sunburst`) | 同心语义层级 (`d3-hierarchy` + `d3-shape`) | 被选扇弧沿原角度展开至 360°，子参数继承方向脉络环绕四周，圆心变为实操画布 | 非当前分支平滑收卷退场，点圆心或「收拢」随时可逆打断 | 深层级、结构清晰的参数导航与语义缩放 |

## 四、严格的自我审查（诚实回答 7 个拷问）

1. **如果删除圆形轮廓、刻度、颜色及装饰，这个交互还有没有独特价值？**
   - **实验 I（让位生长）**：去掉一切圆形装饰后，「点击原位生长 + 物理排斥邻居让位 + 拖动两对象靠近自动建立功能耦合」依然完全成立。
   - **实验 II（时空透镜）**：去掉装饰后，它本质是 Focus+Context 连续拓扑缩放，彻底消除了遮罩弹窗。
   - **实验 III（一笔穿层）**：去掉图形后，它本质是方向性肌肉记忆手势（Marking Menu），可盲操加速高频动作。
   - **实验 IV（年轮解体）**：最依赖径向几何语义，但「点击扇区展开 360° + 圆心变为该分支的活体工作区」比纯静态 Sunburst 图表迈出了一大步。

2. **它是否本质上仍然是一个普通菜单加一个弹窗？**
   - 实验 I、II、IV 均彻底移除了独立弹窗与侧边栏：内容直接生长在节点本体、Voronoi 细胞内部或解体后的圆心内。实验 III 的唤出环在外观上接近径向菜单，但其价值在于「画布即实时世界 + 一笔穿层免点击」。

3. **它只是改变了内容容器的形状，还是改变了人与信息互动的方式？**
   - 在实验 I 中，**拖动两个对象靠近直接触发「校园日影」「摆锤击节」「光声共振」**——这是传统菜单和卡片完全无法自然表达的「多对象空间合成」；在实验 II 中，**移动手指即可连续调节焦点/上下文比例**。

4. **界面形变是否承担了实际的交互职责？**
   - 是。`flubber` 形变把种子态变成可容纳操控控件的开口；`d3-force` 位移负责防止重叠；`d3-fisheye` 弯折负责在不隐藏邻居的前提下腾出操作面积；`d3-hierarchy` 展开负责让子级继承父级方位。

5. **用户能否在不学习设计理论的情况下自然使用？**
   - 实验 I、II、IV 首次打开只需「点按」即可立刻操作，零前置学习成本。实验 III 的「拐弯一笔穿层」有一定熟手门槛，因此我们专门保留了「轻点即切换为逐层点击模式」与底部的「在中心唤出年轮」按钮作为自然过渡。

6. **它是否值得被反复操作，而不只是看一遍动画？**
   - 5 个对象本身都是真实可玩、可组合的小仪器（可拨动的单摆、可调时的真实海口日影、可发声的五声八拍节律、真实校景方位、历史年轮），且在 **⇄ 双屏对照** 下跨机制实时同步。

7. **哪些部分还有局限或待继续推进？**
   - **长文本/复杂表格**：这四种机制都最适合「直觉操作、参数探索、空间关联」，并不适合阅读 5000 字长文或编辑大型财务表格。
   - **实验 II 多边形裁剪边界**：Voronoi 细胞在极端狭长时，内嵌微控件（矩形 DOM 叠层）的四角接近斜边；本轮已通过收紧容器尺寸与居中标题显著缓解，若继续深入可用 SVG `<foreignObject>` + 动态 `<clipPath>` 或 Canvas 渲染实现彻底贴壁。
   - **真机触控实测**：所有验证均在 Chromium 桌面（1440×900）与模拟手机视口（390×844）完成，尚未在物理 iPhone / Android 真机上测试高刷触控阻尼与单指手势冲突。

## 五、本地运行、测试与动图资产

```bash
cd experiments/nianlun-interaction-lab
npm install
npm run build        # Rollup 打包真实 npm 开源库至 bundle/app.js
npm run test:unit    # Node 核心算法与开源库集成单元测试
npm run test:e2e     # Playwright 桌面+移动端交互验收并录制 4 组 GIF
```
