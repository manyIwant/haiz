# 抽出一年 · NIANLUN 交互研究 003

> 按住一圈年轮，把它拉出来。它离开树干时是一圈有弹性的木环；松手，它在新年那一点断开，像手卷一样沿着轨道滚开，把这一年的 365 天印成一条木带。沿着木带滑动，日子在手指下膨胀；把某一天从带子上拉下来，它就展开成那一天府城校区上空的天。

在线预览：<https://manyiwant.github.io/haiz-nianlun-preview/pull-a-year/>
本地运行：在本目录执行 `python3 -m http.server`，打开 <http://localhost:8000/>。需要支持 WebGL 2 的浏览器。

## 这次和前几版有什么不同

PR #108、#110、#112 的问题是：交互对象本身仍然是菜单、卡片和图表，只是换了形状。这一版只做**一个动作**，并让这个动作贯穿三个深度：

| 深度 | 你看到的 | 你做的 | 界面怎样回应 |
| --- | --- | --- | --- |
| 树干 | 104 圈年轮：树心是 1923 年建校，树皮下是今年 | 手指（或鼠标）放上去 | 手指附近的年轮膨胀（径向鱼眼），2 px 宽的一年也能找到；树干外侧浮出这一年的雨量、最热、最大阵风和校史 |
| 一年 | 被拉出的那一圈 | 按住往外拉 | 木环被拉起、变大、跟手晃动；越拉越吃力，过了一个点「啪」地脱离；树干在它身后合拢，留下一道浅槽。松手后，木环飞到轨道起点，在 1 月 1 日断开，一边滚一边铺开，每铺完一个月轻敲一声 |
| 一天 | 一条年份的木带：底色是气温，雨天着墨，台风留疤，有日期的校史是带子里的小「结」（结本身又是一圈圈小年轮） | 沿带子滑动；点一天，或把它从带子上拉下来 | 手指下的日子膨胀，读数跟着走，纸面颜色随那天的冷暖干湿微微变化。拉下的那一格长成整片天空：当天真实的太阳轨迹、云量、风向和雨；木带退到地平线，成了可以继续滑动的「时间地平线」 |

每一步都能原路退回：天空缩回它那一格，木带卷回成环，木环飞回树干，树干让出位置把它收进去。左上角缩小的树干一直在，点它就回去。

年轮是起点而不是始终维持的形状：它先是截面，然后是手里的环，然后是一条线，最后在天空里又以「太阳走过的弧」出现。

## 用了哪些真实内容

- **31,732 天 ERA5 逐日天气**（1940-01-01 至 2026-11-16），与 HAIZ 首页「年轮」同一份档案。1923—1939 年没有逐日数据，那 17 圈留白，拉出来是一条空白的木带。
- **校史 14 条、新闻 5 条**，全部摘自 HAIZ 第二幕「根脉」与新闻档案，保留史料等级与出处链接。只知道月份的事在带子上是一段暗色，只知道年份的写在带子开头的「题签」上，绝不硬放到某一天。
- **日出日落、月相**按日期与校园经纬度计算（HAIZ `sun.js` / `almanac.js`）。

一些值得去拉的年份：2014 年（7 月 18 日「威马逊」，大暴雨 211 mm、阵风 12 级，全年雨最大、风最大）；2023 年（10 月 30 日《海南日报》报道、11 月 1 日百年华诞）；1988 年（4 月 26 日海南建省）；1930 年（没有天气，只有空白）。

## 操作

- **桌面**：悬停找年份；按住拖出来，或直接点一下。木带上移动看每一天，点一天打开；抓住木带右端往回推，它会卷回成环（推过七成松手就放回树干）。键盘：方向键选年份，回车抽出；再用方向键选一天，回车打开；`↑ ↓` 改时辰，`Esc` 退回。
- **手机**：手指按在年轮上滑动找年份，停一下（会有轻微震动）再拉出来；轻点也可以直接抽出。木带竖着挂在右边，像挂轴；沿它上下滑，把某一天往左一拉就打开。
- 右上角「声」可以关掉木头的声音（Web Audio 合成，默认很轻）。

## 文件

| 文件 | 作用 |
| --- | --- |
| `app.js` | 状态、手势、三层之间的转场；木带的形状（插槽中的环 / 手里的弹性环 / 滚动展开 / 平铺 + 鱼眼） |
| `gl.js` | WebGL 2：树干截面着色器（径向鱼眼与合拢由查找表驱动）与木带三角带；两者读同一张「每天一个像素」的纹理，所以一年在树干里、手里和铺开时颜色完全一致 |
| `physics.js` | 弹簧与一维鱼眼 |
| `sky.js` | 纸面与那一天的天空 |
| `sound.js` | 合成的木头声 |
| `content.js` | 校史与新闻条目 |
| `lib/` | 原样复制的 HAIZ 年轮模块与数据 |
| `THIRD-PARTY.md` | 第三方授权与借鉴说明 |

## 诚实的边界

- 年轮是数据的画法，不是那棵榄仁树真实的年轮；天气是模式再分析，不是校内观测；天空颜色是美术表达。页面左下角「这些从哪来」写的是同一件事。
- 开发环境只有软件渲染（SwiftShader）。我在其中逐帧操作并截图检查了桌面（1440×900）与手机（iPhone 13 视口）上的全部流程，但**真机 GPU 上的帧率与手感、iOS Safari 的触控与震动、声音的听感都还没有在真实设备上验证**。
- 这是独立实验，不接入生产站的六幕，也不修改任何现有页面。
