# JUDOU / 句读 — 中文原生交互设计实验 001：可改写的教科书

## 1. 研究背景与核心命题

在 HAIZ Design Laboratory（[PR #108](https://github.com/manyIwant/haiz/pull/108)）中，第一代「句读」确立了**组合轴（横读为句）**与**聚合轴（竖换为选）**的基本规律，并通过着重号、双行夹注、朱线疏和句末标点状态完成了日常界面的语言化改造。

本次独立实验（`experiments/judou-lab/`）进一步追问：

> **我们要研究的不是如何用中文书写界面，而是中文本身能否成为一种界面。**
> **如果教科书中的文字不再只是描述现象，而是直接成为控制现象、推演知识与重构逻辑的媒介，阅读与理解会发生什么变化？**

## 2. 从第一代到第二代/第三代的演化

| 维度 | 第一代「句读」（PR #108） | 第二代/第三代「可改写的教科书」（本实验） |
| --- | --- | --- |
| **核心隐喻** | 界面是一句可以改写的话（表单/导航/设置） | 知识是一个可推敲、可变形、可逆的语言-模型耦合体 |
| **操作对文本的影响** | 替换词钮或修改数值 | **结构性重写**：跨过物理/数学/逻辑边界时，句子自身的语法骨架随之改写 |
| **公式形态** | 静态算式输出 | **可拆解、可换形公式**：点击符号展开意义；在近似式/精确式、一般式/顶点式/交点式间切换 |
| **图文关系** | 疏中附图，单向联动或简单点击 | **双向耦合**：改文驱动图形，直接拖动图形（摆球、抛物线顶点、纬线）反向改写正文 |
| **逻辑与因果** | 隐含在文案中 | **因果溯源（Causal Trace）**：悬停/聚焦结论时，反向点亮上游依赖的前提词钮 |
| **探索过程** | 即时状态，无历史比较 | **可逆推演（Undo/Redo）+ 探索手记（Snapshots）+ 双态并排对比** |

## 3. 四个实验篇章与科学模型边界

1. **物理 · 《单摆的等时性与边界》**（`js/ch-pendulum.js`）
   - **模型**：采用第一类完全椭圆积分的算术-几何平均（AGM）计算任意摆角（`0°–85°`）的精确周期 $T = T_0 / \mathrm{AGM}(1, \cos(\theta_0/2))$。
   - **边界**：当 $\theta_0 \le 5^\circ$ 时，文字陈述等时性定律；超过 $5^\circ$ 与 $30^\circ$ 时，句子重写为偏差提示与非线性警告；当 $g = 0$（失重空间站）时，回复力消失，句子重写为「不再摆动」。
2. **数学 · 《二次函数的形与根》**（`js/ch-quadratic.js`）
   - **模型**：精确计算顶点 $(h, k)$、判别式 $\Delta = b^2 - 4ac$ 与实/复根；支持在「一般式」「顶点式」「交点式」之间切换。
   - **边界**：当 $a = 0$ 时二次项消失，抛物线退化为一次直线，正文自动移除顶点与判别式陈述；当 $\Delta < 0$ 时，交点式就地拒绝分解并给出复根与原因夹注。
3. **地理 · 《晨昏线与昼夜长短》**（`js/ch-daynight.js`）
   - **模型**：球面天文公式 $\cos \omega_0 = -\tan\phi\tan\delta$（黄赤交角 $23.44^\circ$），计算昼长、日出日落地方时与正午太阳高度。
   - **边界**：跨入极昼（$-\tan\phi\tan\delta \le -1$）或极夜（$\ge 1$）时，句子自动重写为极昼/极夜状态描述。
4. **逻辑与语言 · 《条件、推理与句法重构》**（`js/ch-logic.js`）
   - **模型**：基于凸四边形性质集合判定充分条件是否成立，不成立时自动构造几何反例并更新欧拉图；同时提供汉语复句骨架切换（因果、让步转折、充分条件、必要条件、反问），实时展示逻辑真值条件与信息焦点的迁移。

## 4. 运行与自动化验证

- **本地运行**：在仓库根目录或 `experiments/judou-lab/` 下启动任意静态服务器（如 `python3 -m http.server 8000`），访问 `/experiments/judou-lab/index.html`。
- **自动化测试**：运行 `python3 experiments/judou-lab/verify.py`，将自动启动本地服务器、使用 Playwright Chromium 在桌面（1440×900）与手机（390×844）视口下验证全部四个篇章、组件验收台、研究手记及零控制台错误，并将截图保存至 `experiments/judou-lab/shots/`。
