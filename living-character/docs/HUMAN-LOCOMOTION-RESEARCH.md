# 专业级人体运动研究与技术选型报告（Section 02）

## 一、真实人体步态周期与生物力学规律

真实人类行走并非四肢按正弦函数摆动，而是一个受重力、动量守恒与能量回收支配的动力学过程：

1. **步态周期（Gait Cycle）八个关键时相**：
   - **支撑相（Stance Phase，约占 60%–62%，随速度升高而缩短；跑步时 < 50%，出现双足腾空飞翔相）**：
     1. *Initial Contact / Heel Strike（足跟着地，0%–2%）*：踝背屈 ~5°–15°、膝微屈（~5°），身体中心位于两脚之间，重心开始前移。
     2. *Loading Response（承重反应/缓冲期，2%–12%）*：支撑膝立即弯曲至 ~15°–18° 吸收垂直冲击（**关键消除「圆规直腿」感**），骨盆向支撑侧横移并开始向摆动侧微降（Trendelenburg 骨盆倾斜 ~3°–5°），脚掌从脚跟滚动贴平地面（Plantarflexion → Flat）。
     3. *Midstance（支撑中期，12%–31%）*：人体作为**倒立摆（Inverted Pendulum）**越过支撑踝上方，骨盆达到**步态周期最高点**（与跑步的弹簧-质量模式相反，跑步在支撑中期最低！），支撑腿膝关节由缓冲微屈逐渐伸展。
     4. *Terminal Stance（支撑末期，31%–50%）*：重心越过支撑脚前掌，**脚跟抬起（Heel-Off）**，以跖趾关节（MTP / Toe joint）为枢轴滚动，小腿三头肌发力推进。
     5. *Pre-Swing（摆动前期/离地，50%–62%）*：对侧脚着地，本侧脚跖屈蹬离（Toe-Off ~40°–55°），膝快速弯曲启动摆动。
   - **摆动相（Swing Phase，约占 38%–40%）**：
     6. *Initial Swing（摆动初期，62%–75%）*：膝屈曲峰值达 ~60° 保证脚尖离地净空（~3–5 cm，不蹭地也不踢正步）。
     7. *Mid Swing（摆动中期，75%–87%）*：髋屈曲前摆，小腿在惯性下自然展开。
     8. *Terminal Swing（摆动末期，87%–100%）*：小腿减速准备足跟着地，摆动速度平滑收敛，落脚点与下一周期身体质心预测对齐。

2. **躯干、骨盆、手臂与头部的动力学耦合**：
   - **步频与步幅关系**：真实行走遵循 $\text{cadence} \propto \sqrt{v}$（源自物理摆长规律），Froude 数 $\text{Fr} = v^2 / (g \cdot L_{\text{leg}}) \approx 0.5$ 时人体自然从走切入小跑（约 1.8–2.0 m/s）。
   - **骨盆六自由度耦合**：横移（侧向质心转移至支撑脚）+ 垂直起伏（每跨两步两个周期，约 2.5–4.5 cm）+ 水平面旋转（随前摆腿向前扭转 ±5°–7°）+ 冠状面倾斜（摆动侧微降 ±3°–5°）+ 矢状面前倾（加速/跑步前倾）。
   - **胸廓反向扭转（Thoracic Counter-Rotation）**：骨盆向右前转时，胸廓向左前反向旋转，抵消角动量；肘关节屈曲随臂前摆自然加深（摆幅与对侧髋屈曲相位锁定但略滞后）。
   - **前庭—视觉头部稳定（Head Stabilization）**：人类内耳前庭与颈部肌肉主动抵消躯干俯仰与滚转约 70%–85%，使视线保持水平稳定；**转向时总是「视线 → 头部 → 胸椎 → 骨盆 → 脚步」按时间级联发生**，而非全身像炮塔一样整体绕中心旋转。

## 三、HAIZ Round 3 混合运动架构设计

本轮摒弃「单纯播片段导致滑步」与「单纯程序化导致上身机械」的两极缺陷，采用 **「程序化动力学底座 + 重定向动捕上身韵律 + 物理级联与次级弹簧」的四层混合架构**：

1. **Layer 1 — 动力学与地形底座 (`three-procedural-locomotion` v0.11.0 + `foot-ik-terrain.js`)**：
   - 控制真实质量感加减速（`speedEasing` S 曲线）、向心侧倾限制（`maxLateralAcceleration`）、支撑脚世界空间硬锁（Foot Locking）、脚跟—全掌—脚尖滚动（Foot Roll）、离散台阶逐级攀爬及斜坡法线适应。
2. **Layer 2 — 生理转向级联控制器 (`turn-cascade.js`)**：
   - 彻底消灭「炮塔式转身」：静止小角度转向（< 32°）仅驱动视—头—胸；中大角度触发单/双步原地换向步态；高速急停折返触发 `Brake → Plant → Pivot → Drive` 四段动力学过渡。
3. **Layer 3 — 相位锁定的动捕上身层 (`mocap-layer.js`)**：
   - 将 Blender 重定向后的 `UAL1` + `CMU` 真实人类上身动画（`spine / spine1 / chest / shoulders / arms / hands`）以 Footstep 相位锁同步叠加，既保留 100% 零滑步与实时地形自适应，又获得真人肩胛联动、自然肘腕放松与交谈/张望/上下楼梯的呼吸感。
4. **Layer 4 — 二阶弹簧次级运动与风场着色 (`secondary-motion.js` + `painterly-shader.js`)**：
   - 双肩背包、斜挎包、马尾辫、刘海与校服下摆随真实加速度、转向角速度及海口季风动态摆动，并在 `南海晴光` / `入画水粉` 双画境下和谐呈现。
