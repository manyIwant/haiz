# HAIZ · 校园资料、资产来源与溯源诚实性说明

> 本文件遵循 HAIZ 校园世界重构计划的**真实空间依据、诚实溯源标注、公开合法素材与师生隐私/安防保护**四项核心原则。

---

## 一、隐私保护与校园安全边界声明

1. **仅使用公开与仓库既有授权资料**：本次重建全部空间与外观依据均来自 OpenStreetMap / Overture Maps 公开地理数据及 `manyIwant/haiz` 仓库中既有公开校园风景与建筑外观照片。
2. **严格保护师生个人隐私**：未收集、未爬取、未嵌入任何包含可识别个人面部、姓名、学号、联系方式或私人照片的图像；所有三维人物均使用开源 CC0 通用人物网格与虚构叙事角色名。
3. **严禁涉及敏感与安防空间**：仅还原外部公共可见建筑体量、立面、广场、运动场与公共园林；**不包含**门禁闸机细节、监控摄像头位置、配电/机房、保安室内部、宿舍室内平面或任何非公开内部安防信息。
4. **不二次复制未明示许可的实景照片**：本实验分支仅通过路径与依据说明引用仓库已有公开参考图，未将其重新打包复制到新发布的独立公网预览仓库中。

## 三、诚实溯源分级体系（零虚假测绘声明）

本重构世界中的**每一处建筑与地标**都在 `world_spec.json` 与 glTF 节点 `extras`（`haiz_tag` / `haiz_basis`）中携带显式可信度标记，用户可在实时三维校园中**直接点击任意建筑**查阅溯源卡片。

| 可信度标签 | 严格定义 | 本次重构覆盖对象 |
|---|---|---|
| `photo-derived/public-map` | 同时拥有公开地图建筑轮廓与多角度实景照片标定（体量、屋顶形制、立面节奏与主色均有实景依据） | 北门牌坊、一号教学楼、太湖石前庭、百年榄仁树、砚池与艺术教育活动中心、图书馆与天文台、凤栖堂、衍林堂、二号教学楼、科学馆、科技楼、女生宿舍、体育馆、运动场与看台 |
| `photo-derived/estimated` | 拥有实景外观照片依据，但局部尺寸、次要立面或精准相对坐标由相邻地标与航拍推算 | 凤栖亭、衍林亭、校友会馆、南门牌坊、三号/四号教学楼、男生宿舍楼群、第一/第二/第三食堂 |
| `public-map/estimated` | 拥有真实 OSM/Overture 建筑占地多边形，但缺乏近景实拍照片，外立面采用海南中学同类热带校园建筑范式合理推演 | 部分辅助实验楼、南区教学附楼、教工/配套建筑 |
| `public-map/context` | 校园围墙外 133 栋真实府城街区体块，以真实 OSM 轮廓 + 琼山街区柔和色调概括表达，仅作城市天际线背景 | `d06_fucheng_context` 全部 133 栋周边建筑 |
| `artistic/living-world` | 为赋予校园生命感与空间尺度而进行的合理艺术复原与生态模拟 | 6 位校园作息人物、橘猫、彩蝶、雨燕、锦鲤、单车与滑翔伞、部分道路行道树与路灯具体点位 |
| ~~`surveyed`~~ | **严格禁用（0 个节点）** — 本项目未开展工程级激光雷达或全站仪实地测绘，绝不将照片估算或公开地图数据伪装为精确测绘结果 | **0（经 `validate_world.mjs` 自动化门禁强制校验）** |

## 四、已知资料缺口与下一阶段补充采集清单

为避免盲目追求表面“100% 写实”而虚构细节，我们明确记录当前公开资料尚不充分的区域及后续合法补充方案：

1. **高精立面细节缺口**：
   - **校友会馆、衍林亭与北门东侧院墙**：缺少正面平视高清外景照，当前窗洞与檐下彩画为同风格推演；
   - **三栋食堂（一/二/三食堂）与南区教学附楼**：缺少近景外立面与檐口照片，当前按南国通廊与底层柱廊范式表达；
   - **高登西街南门周边与植物园小径**：缺少南门北望视角的清晰照片，南门细节标记为 `photo-derived/estimated`。
2. **历史文化细节与声景缺口**：
   - 校史碑刻、宣传栏与百年校庆纪念雕塑若获校方或校友公开文本授权，可直接写入 `materials.py` 贴图生成器与 `world_spec.json` 故事文案；
   - 真实海口校园环境声景（不含人声隐私的椰风、热带阵雨、蝉鸣、礼堂钟声）可作为下一阶段轻量 Web Audio 资产接入。
3. **补充采集原则**：所有后续补充材料须由师生/校友自愿提供公开户外建筑外观照，拍摄前遮蔽或避开无关人员面部与车牌，严守隐私与安防底线。
