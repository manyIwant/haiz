# HAIZ WORLD · 校园图谱

基于 `manyIwant/haiz` 的 HAIZ ATLAS PR #16，选用修正后的第三套「校园图谱」方向。来源提交：`c6cebfbbd213dd0a2bc6becdd89391e82b1279ed`。

## 打开

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

在本机打开 `http://127.0.0.1:4173/`。

## 体验

- 真实 Three.js 校园，支持“空间”透视、“图谱”正交俯瞰与第一人称漫游；点选建筑、拖动旋转、滚轮或双指缩放。
- 实景对照覆盖 1 张新核实的 2013 年校门 CC0 照片及 7 处项目已有实拍；逐项区分来源、年代、授权及待核实状态，错标照片不展示。
- 一号楼、二号楼、图书馆及凤栖堂仅通过独立材质副本做小幅外观校准，原模型几何、坐标和运行时文件不变。
- 四个主要地点与完整 34 节点搜索；`Cmd/Ctrl + K` 打开搜索。
- 「靠近建筑」在同一校园场景内下降到原引擎的安全落点，支持跳过、取消与减少动态效果。
- 第一人称沿用原来的移动、碰撞与触屏摇杆；`WASD` / 方向键行走，拖动环顾，`Esc` 暂停或继续。
- 图书馆进入现有 STILLROOM；一号楼进入现有概念教室。空间页上方可以返回校园，并恢复选中的建筑。
- Porcelain、Obsidian、Ocean 三主题；设置里可以调整画质和动态效果。

## 空间依据

`public/haiz/` 是原仓库的本地副本。建筑位置来自原 `campus.json` 的 `rect`，经原 `world.js` 转换；未按生成图重排建筑。原校园数据、世界几何、移动逻辑、运行时与两个目的页保留原始字节，测试使用固定哈希与 34 节点坐标快照检查。

新入口 `world/atlas-engine.html` 仅派生原页面并加载伴随控制器，切换观察相机和界面。原始校园节点、碰撞体与建筑模型不变。北门、一号楼、二号楼、科学馆的轴线以及图书馆、凤栖堂、衍林堂、砚池和操场的相对位置见 [空间核对](docs/spatial-layout.md)。

旧手图投影与当前三维镜头的 Z 方向相反。原型沿用真实三维投影，不把旧图当作移楼依据，也不显示未经复核的真北。原 KML 与转换脚本缺失，模型仍不代表测绘级实景复刻。

## 性能策略与边界

- 俯瞰仅在交互或画面改变时提交 GPU 绘制；轻量模式的俯瞰绘制限制在约 30 帧/秒。
- 手机粗指针设备从原引擎的轻量模式起步，保留画质选择。分辨率、阴影和反射由原引擎的质量档位控制。
- 标签页隐藏时暂停。减少动态效果跳过自动飞行，并关闭界面动画。
- 进入独立学习空间时移除校园 iframe，避免两个校园/教室 WebGL 场景同时运行；返回时重建校园并恢复所选建筑。
- 资源均来自本地副本，资源按页面实际请求加载；不会一次下载副本内全部视频和文档。
- 已做桌面浏览器、窄屏布局、实际三维落点与键盘移动验证。手机真机的 GPU 性能、温度、续航、Safari/iOS 及真实多点触控仍需设备验证。
- STILLROOM 和概念教室是原有独立场景，通过明确入口联动，校园模型本身没有变成这些房间的测绘内部空间。
