# HAIZ 离线便携版

直接双击 `HAIZ-Classroom.html`，用较新的 Edge 或 Chrome 打开。无需服务器、Node、Python、ClassIsland 插件、管理员权限或首次联网。全部脚本、样式、字体与两张静态空间图嵌在一个文件内，默认进入上课留白状态。

这是网页便携工具，不是原生 Windows exe，不会置顶、透明覆盖授课软件、注册全局快捷键、添加开机启动或修改系统配置。学校策略限制打开本地脚本时，请由设备管理员决定是否允许，不要绕过策略。没有在真实希沃 Windows 硬件上验证。

## 一次演示

1. 点“教师发布台”，选择示例班级，输入提醒，预览后确认发布。
2. 回到教室屏，手动选“课间”。通知出现；选“上课”则收起。
3. “一键隐藏”退出网页全屏并隐藏内容。Windows 用 Alt+Tab 切回授课软件；HAIZ 不会自动抢回焦点。
4. 私人学习：顶部“我的自习室”→ 开始一件小事 → 写下一步 → 进入；离开前更新思路。
5. 公共内容通过演示 JSON 包导入导出；接收端必须逐条审核。私人记录使用独立备份入口，不进入公共包。

## 保存与更新

浏览器通常允许 file:// 下的 localStorage，但具体隔离与持久化取决于版本、学校策略和文件路径。页面启动会检测写入限制，失败时提示导出备份。移动或改名文件、换浏览器、清理浏览数据可能导致无法读取原记录，操作前务必导出；私人备份可以恢复，公共包需要重新审核。不要把未备份的浏览器数据当成长期档案。

同一路径、同一浏览器配置的多窗口是否互相收到 storage 事件，也取决于浏览器的 file:// 行为；不承诺跨设备同步。通过 https 网站版运行时可使用标准同源跨标签同步和 Service Worker 离线缓存。

纯本机演示的角色选择不是身份认证。不要把此版本当作正式远程通知系统；不能从学生私人电脑远程推送至教室。本轮不包含生产服务器或 ClassIsland 插件产物。

为了离线和低功耗，便携版使用静态场景，三维窗台及第一轮完整网站在源码包的 dist/ 中保留。版权、审计和集成设计见 ../docs/。重新生成便携文件：`node scripts/build-portable.mjs`（无需安装依赖）。

验证范围：当前 Linux 受管 Chromium 阻止 file://（ERR_BLOCKED_BY_ADMINISTRATOR），没有绕过此策略。已验证单文件经 HTTP 加载自身后断网运行，不请求额外脚本、字体或图片；Windows 双击、本地存储持久性与希沃兼容性仍待授权环境实测。
