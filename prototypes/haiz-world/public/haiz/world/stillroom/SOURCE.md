# STILLROOM 参考版来源与变更

基础界面、JS和建筑SVG来自用户在本轮提供的 STILLROOM_沉浸式自习室_v1.zip。原包保留在开发附件目录，未改变原文件；本目录为HAIZ集成副本，不将用户素材额外宣称为MIT授权。未下载或分发Unsplash图片、Google字体、Apple字体。

适配：移除所有外部图片/字体请求；只使用包内原创建筑SVG；进入此页面才加载场景；试用模式只用sessionStorage，离开浏览器会话前需保留需要的文字；原本机服务器下仍按独立本地空间保存。离开标签页/重载时暂停计时，避免把无人值守时间算成专注；存储失败保留输入并提示复制；SW仅清理自己的缓存，修复原版会清理同来源全部缓存的问题。新增返回HAIZ入口。

它是2.5D艺术场景，不是校园建筑实景或可行走的Three.js房间。原有第一人称校园、windowsill及其许可均保留。未完成真实手机功耗、帧率、音频和安装测试。教师私人资料不进入此页面。
