# 三人小范围试用

当前建议先用本地浏览器Demo，不需要买开发者会员。三位自愿测试者：①学生首页→社团搜索→作品草稿→重开；②自习→暂停恢复→断网，沿用既有Study；③教师手机视口草稿→桌面接力→确认→公共屏→撤回。需要开发者在同一测试服务器演示；目前未提供公网账号。

反馈：版本、设备系统（可选）、任务、具体步骤、是否完成、预期/实际、是否需要帮助。截图先自行检查再选择分享，不收集密码、成绩、手机号或真实学生数据。不自动录屏上传。
