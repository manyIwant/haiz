## 新内容与连贯的创作过程

`darkroom.html` 是一座无需 WebGL 的交互工作台，从默认电影入口、杂志导航、杂志推荐、课间电台与全站探索搜索都能进入。

1. **显影**：四处项目既有实拍——凤栖堂、榄仁树、砚池与图书馆。鼠标或触摸在 Canvas 蒙版中留下光迹，图片始终保持完整比例；滑杆、一键看全图和重置提供非手势替代。笔触最多 1600 点，只留在本页内存中。缩放页面会按归一化轨迹重画，不把相纸清空。
2. **笔触译成音乐**：左右坐标量化为八拍，上下坐标量化为四个声部；每一拍取该空间区段的平均纵坐标，得到一组可复现的音符。不是随机按钮，也不是录音识别。只在用户点击转换后更改编排，转换不会自动播放。
3. **四声部八拍编曲**：檐下钟音、叶间低音、水面轻响与纸页节奏均由 Web Audio 原创合成。支持预设、留白、单声部试听、格子开关、电脑拖画、手机短触摸、键盘空格、60–132 BPM、0–70% 音量。短触摸直接处理 pointerup，避免横向滚动后的兼容性 click 缺失；滑动取消不会误写音符。
4. **作品接力**：白名单地点、4 个 8-bit 声部、速度、80 字以内留言和纸色编码为版本化 fragment。另一浏览器打开后可改编，但不实时改动原作，不存在后台房间、公开留言、虚构点赞或在线人数。链接携带文字，拿到链接的人可读到留言；本地清除无法撤回已分享链接。
5. **可带走的输出**：1080×1440 PNG 保留完整照片及现有来源说明，不移除照片水印。WAV 使用 OfflineAudioContext 渲染一轮八拍及尾音，44.1 kHz、单声道、16-bit PCM；空白作品仍可导出安静音轨。未支持的浏览器保留编排和链接功能。

原创声音不是校园现场采样，不冒充学校广播。照片来自用户版本既有资源，其年代及转载授权仍未独立确认；导出和页面均说明版权归原作者与发布机构。没有用生成图片冒充实拍。

## 状态、安全与性能

- `assets/js/darkroom-core.js` 为独立可测试格式层：严格 URL 校验、限制长度、有限数字、不可变编辑、1600 点轨迹上限与稳定作品编号；编号不是全局唯一身份标识。
- `assets/js/darkroom.js` 只使用原生 Canvas、Pointer Events、SVG、Web Audio；无新增生产依赖、遥测、远程字体或运行时 CDN。
- `localStorage` 仅使用 `haiz.darkroom.score.v1`。访问页面不会自动重新写入已清除的记录；下次实际编辑才保存。存储不可用时可以继续创作和导出。
- 接到的作品在实际改编后会同步更新当前地址的 fragment；章节跳转不覆盖作品 fragment，刷新不会无声回退为改编前的原作。不会增加逐拍浏览历史或触发远程请求。
- 留言用 textContent / Canvas 文本绘制，不执行 URL 中的 HTML。作品链接有格式和体积上限，不加载任意远程图片或音频。
- 音频需要用户启动；播放编曲会关闭共享环境声，避免叠加。切后台、离开页面和点击停止都会取消调度并停止已创建音源。停止后无编曲定时器；笔触光圈最多 5 个，700 ms 结束即移除。
- 尊重减少动态效果偏好；关闭装饰光圈，SVG 直接显示，无强制平滑滚动。核心显影、编曲、分享、导出不依赖装饰动画。
- 关于本站的“清除本机记录”现包含暗房作品，仍保留其他应用的存储键。

## 三维外观的进一步细化

- 一号楼：依据已有正面照片，细化中央双侧石材构件、较小的内退窗、窗楣、金属中梃、顶部挑檐的三级收边、支托与侧部阶梯冠部；保持既有占地、教室与出入口。观察镜头优先寻找近距离正面安全位置，不再只从楼体远端看中央细节。
- 凤栖堂：细化柱头弧形金线与圆饰，补充柱础附近的有限接触阴影。接触阴影是程序近似，不是实时 AO 或扫描烘焙。
- 曲面屋顶补上向下的内衬表面，防止人在门廊下方仰视时穿透瓦坡、只看见红色脊线。上下表面分别校验法线，不把材质双面显示当作完整的结构复原。
- 图书馆：为曲面金属圆顶增加独立的拉丝法线和粗糙度图；不以颜色纹理代替圆顶立缝几何。
- 墙砖：将投影尺度从 1.6 降到 0.8 模型单位，细化勾缝、降低凹凸，避免远景像大型砖砌；这是视觉尺度调整，不是测得真实瓷砖尺寸。

既有 HDR、CC0 扫描地面、原创釉面和署名盆栽继续使用；本轮没有新增重型后期或屏幕空间滤镜。**整体仍不是照片级扫描复刻**：缺少标定机位、多视角现场照片、当前尺寸和完整植被资料，不能由立面细化或测试结果证明“极复刻”。

## 验证与范围

运行 `npm run build`、`npm test`、`npm run test:darkroom`、`npm run test:browser`、`npm run test:atelier`。报告分别位于 tests 下；截图和实际下载结果在忽略的 tests/artifacts 下生成。

暗房包含 1024 组声部编码往返、真实 Chromium 指针擦除、笔触转音乐、键盘编辑、独立移动浏览器接力、原始触摸事件、PNG 解码、WAV 头与有效样本、后台停止、作用域内清除、损坏链接、禁用存储、无音频及减少动态效果回退。三维继续验证所有开放教室、门洞、碰撞、导览、真实 glTF 加载与浏览器无错误。

手机测试为 Chromium 触摸模拟，不代表已经在实体 iOS/Android 真机上验收。三维测试使用软件 WebGL，不以初始化 FPS 值宣称硬件性能。GitHub 主分支推送与线上 Pages 部署是两个不同状态，推送后仍需以实际站点发布结果为准。
