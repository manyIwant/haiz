# 探索导演台与釉面细化

本轮在环境恢复后继续开发，接续默认电影首页、建筑观察手册与校园摄影模式。日期按北京时间记录；代码仍是可直接静态托管的网站，不增加服务器、账号或生产依赖。

## 从浏览，到自己编排

`director.html` 使用既有 `campus.json` 的轮廓及同一个坐标变换绘制 SVG 校园图，不使用想象的新校区平面。10 个地点可选择 1–6 站，以键盘或按钮调整顺序；提供树荫、建筑与课间三组灵感，以及晨光、雨后、薄暮气候。路线和气候仅保存到当前浏览器，可复制包含白名单地点 ID 的入口。

地图虚线只表示顺序。显示的米数是模型地点之间的直线跨度之和，不是规划步行距离、实测尺寸或步行时间。进入三维校园后，第一站沿用既有安全落点入口，后续使用现有路径规划器连续步行，每步检查模型碰撞；手动行走或环顾可接管。路径无法规划时提示并交还控制，不把瞬移伪装成行走。这不是实地参观导航。

`journey-core.js` 让页面和校园共用去重、排序、气候白名单及机位校验；浏览器入口不执行 URL 中的脚本或任意名称。

## 把构图保存下来

摄影模式按 P 打开时释放鼠标锁定并停止自动路线，保留拖动环顾和行走。可命名并保存最多 8 个本机机位，记录模型位置、偏航、俯仰、镜头和气候，不记录图片或地理定位，也不上传。导演台提供恢复和移除入口。

分享链接中的数值严格检查有限性、边界、镜头与俯仰范围。加载时会重新检查碰撞；不安全位置调整到附近安全点，无法恢复则保留正常入口。分享数值保留位置两位小数、角度三位小数，因此不是无限精度存档。本地收藏保留完整数值。存储不可用会明确提示，明信片下载与复制入口仍可使用。

## 原创釉面颜色层

- 文件：`assets/walk/textures/jade-glaze-generated.webp`
- 1024×1024 WebP，375,956 字节；SHA-256 见 `assets/walk/credits.json`。
- 来源：本轮图像生成工具制作的原创绿色陶瓷釉面细节，不是校园照片、实景扫描或新增的网络建筑证据。
- 生成提示要点：方形、均匀漫射照明、正交平面绿色陶瓷釉面；细小矿物色差与细裂纹；仅颜色层；没有瓦片形状、建筑、文字、方向光、阴影、镜面高光或明显沟槽。
- 生成 PNG 只做尺寸与格式转换后作为颜色图打包。纹理按 sRGB 读取，镜像重复减轻接缝；瓦沟、搭接、法线、高度与粗糙度继续由确定性程序图提供。
- 只替换绿瓦的颜色层，红瓦仍使用独立程序颜色和原调色。材质实验室与校园共用；加载失败时保留程序材质。增加的网络请求仅为同源本地素材。
- 此颜色细节不证明凤栖堂实际釉料的矿物组成、年代或准确颜色。

环境恢复后重新请求学校官网、360Cities 一号楼全景和海南省政府既有资料入口，仍收到运行平台代理的 CONNECT 403；对官网申请放宽执行权限重试也相同。因此没有声称获得新实拍，建筑外观依据仍是上传版本已有照片。既有研究入口和限制保留在 `data/architecture.json` 与前轮观察文档中。

## 验证与可访问性

执行 `npm run build`、`npm test`、`npm run test:browser`。浏览器测试覆盖桌面及 390px 手机视口、路线增删重排和上限、气候持久化、机位名作为纯文字输出、机位移除、保存后重新进入三维校园恢复构图、自选路线启动，以及 1024px 釉面与程序法线、物理材质绑定。

Node 运行测试另外完整行走四站建筑路线，逐步检查没有碰撞，保留原三站路线、16 间教室往返及失败加载回退检查。测试报告位于 `tests/*-results.json` 和 `tests/walk/*-results.json`。

键盘焦点在地图与列表重绘后保留；提供列表替代小地图点选、明确按钮名称、状态提示、减少动态效果支持、手机较大的操作按钮。全站清除本机数据同时包含路线、机位与探索足迹。云端浏览器使用 SwiftShader 软件 WebGL，手机为视口模拟，不能据此承诺真实设备帧率、触摸性能或测绘精度。

本轮保留 `descent.html` 为电影源，构建同步为 `index.html`；原杂志首页为 `journal.html`。功能在 `feat/campus-materials-20261017` 分支交付，不自动合并主分支或改变 Pages 发布设置。
