# 数据、权限与同步边界

## 私人与公共分离

| 数据 | 存储 / 生命周期 | 可见范围 |
| --- | --- | --- |
| 第一轮便笺、作品、计时 | `haiz.world.demo.v1`，保持原结构 | 当前浏览器演示 |
| Study 思路卡 | `haiz.study.private.v2`；id、title、understood、tried、stuck、next、place、updatedAt | 本机私密，未向 Backend 发送 |
| 思考书架 | 同私人键；理解/改变/问题/探索、之前/现在、修改时间 | 本机私密，可导出/恢复/编辑/删除 |
| 四处空间便笺 | 同私人键，按 place 保存 | 本机私密 |
| 公共演示公告 | `haiz.classroom.demo.v2`；纯静态版为本机内容，本地服务连接时保存最后授权快照 | 班级/全校演示范围 |
| 本地服务公告、审计与模拟适配器 | `.haiz-demo/public-state.json`，不在静态发布目录，不进 Git/ZIP | 本地凭据授权范围 |
| 服务凭据 | `.haiz-demo/local-demo-keys.json`，随机生成；浏览器仅 sessionStorage | 本机测试者，不是学校密码 |

公告字段：唯一 `id`、递增 `version`、`kind`、标题/正文、班级范围、发布角色与本地 actor、发布时间/更新时间、开始/到期时间、优先级、紧急原因、审核状态、发布/撤回状态、允许展示模式、`demo:true`。服务快照还有全局 `revision`、服务器时间、只读 Bridge 状态和接收时间。

公共导出使用字段白名单，不包含私人数据、服务凭据、个人成绩、学生名单或学习时长。文件包无签名，只用于离线本机实验；接收端产生新的本机待审副本以避免直接发布来源不明内容。真正的服务同步保留消息原 ID 和版本，不用文件副本模拟实时同步。

## 两种权限语义必须区分

**静态/便携模式**：教师/学生/管理员的 UI 切换是状态机演示，localStorage 可被使用者修改，不能保障真实身份或限制设备所有者。普通学生 UI 没有发布入口，领域函数拒绝学生写入，但这不是安全认证。

**localhost 服务模式**：客户端角色选择禁用，服务端通过随机凭据判定范围。teacher-a / teacher-b 只能向自己班级发布、改自己内容；display/student 只读；待审需 admin 通过；紧急内容要求 admin 和原因。浏览器篡改角色或 scope 不能改变服务端授权。旧版本修改拒绝为 409。服务未提供任意命令、远程屏幕、私有文件、私人学习记录 API。

教师可直接确认自己授权范围的一般内容，也可主动提交管理员审核；待审内容从 display/student 的服务端快照中排除。活动、资源与通知共用审查与撤回规则。无任何真实学校账号或机构授权声称。

## 断网与时间

SSE 只推完整授权公共快照，不弹出系统窗口；ID / version 更新同一记录。临时断连每 3 秒重试，快照 revision 回退时拒收。断网显示最后接收时间，服务模式进入只读，禁止将离线操作冒充已发布；本轮不实现离线写入队列。到期由客户端时间筛选，离线不会无限展示；时钟跳变超过 60 秒时收起内容、停止自动进入课间，需人工确认。设备恢复可见时重新连接取最新快照。教师隐藏不会被下一条状态覆盖。

Service Worker 排除 `/api/`，不会缓存含凭据的网络响应。网页壳和最后公共数据用于离线显示。服务重启随机凭据轮换，需重新登录；仅网络中断且服务未重启时无需重新输入。文件单机模式无需服务，但其记录持久性受浏览器 file:// 策略影响，提供备份和恢复。

## 正式部署尚欠缺

学校设备授权与身份目录、持久安全会话、TLS、签名内容包、远程撤回可靠性、受保护审计、版本化 ClassIsland 实际联调，以及 Windows 真机焦点/遮挡和低功耗长时间运行。没有这些条件，不把此 localhost 实验放到学校公网或内网使用。
