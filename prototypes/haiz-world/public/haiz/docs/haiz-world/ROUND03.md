# 本轮增量：完整校园、思维书桌、晚修作业

日期：2026-10-22。所有现场设备状态均未验证；未访问学校网络。

## 产品决定

用户明确：ClassIsland 的当天课程表中，最后两节自习就是晚修。HAIZ 不维护另一张固定晚修时间表。公开作业是给不带手机的学生看的班级清单；教师在办公室写一次，经授权同步到课堂和移动入口。没有注意力监控、成绩、名单、完成率排名或监听。

## 可运行闭环

1. `node scripts/classroom-server.mjs`，浏览器配置 A 使用 teacher-a 身份进入 `#homework`，配置 B 用 display-a，管理员用 admin。凭据由服务启动随机生成，仅写本机忽略目录。
2. 管理员载入明确标记的模拟课表。教室客户端在作业页启用课表联动，再打开 `#classroom`。当前没有真实 ClassIsland 连接。
3. 教师选学科、日期，填写要求、准备材料与交付说明，预览发布；可修改、送审、撤回。同一 ID 递增版本，旧版本拒绝覆盖。
4. 当天最后两节自习到点显示今天本班、审核通过、未撤回的作业；节间与结束收起。任一有效课表缺失、冲突或过期则不自动展示。自动切换仅发生在 HAIZ 页面，不会抢系统焦点或打开别的软件。
5. 手动隐藏优先，一键纯净课堂暂停自动作业展示。离线保留当天公开缓存；已撤回内容在恢复连接后移除，不声称断网可以即时获知撤回。非当天内容不会无限期显示。
6. `#assignments` 是学生公共清单，移动布局复用同一模块。教师日期筛选可查未来作业。浏览器本机模式只是角色模拟；启动服务才有服务端身份和班级防护。

## 校园与建筑

- `#walk` 恢复完整原始引擎：34 地点、16 间首层想象教室；WASD、拖动环顾、俯瞰、全校搜索、分类、跳转和手机摇杆。开始按钮进入第一人称，暂停停止渲染。
- `#atlas` 为无需 WebGL 的完整地图；照片依据直接附在地点详情。`#garden` 保留三处体素艺术小景。
- 用户指出基本所有建筑都有偏差，因此所有节点均标记待核对。已有四处对应照片可直接打开：一号楼、二号楼、凤栖堂、科学馆。没有把未核实的示意尺寸说成实测。
- 本轮修正体素庭院中凤栖堂的明显误构：移除叠加的第二重独立屋顶与虚构侧廊，改浅白墙、红柱金色细带及深色阶梯；砚池移出正前方，作为独立艺术小景。位置仍是艺术排布。全校模型没有完成逐栋实测重建，详见 BUILDING_REVIEW.md。
- 全量模型在 Linux 软件渲染器上明显慢；默认均衡，低画质降低分辨率，初始暂停等待点击。不能把本次控制正确性测试当作中低端 Windows 帧率保证。

## 思维书桌

全屏专注书桌、5/15/25/45 分钟自选计时、暂停/恢复、低负荷模式和私密线索。离开页面、休眠和重开不假装持续专注；结束时保存理解与下一步到原有思维续航卡。计时仅个人自愿工具，不代表真实注意力。
