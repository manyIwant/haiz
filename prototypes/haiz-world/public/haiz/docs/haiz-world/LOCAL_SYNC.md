# 本地授权同步实验

本原型运行在普通开发电脑的 loopback 上，不进入学校网络。Node.js 20+（测试使用本环境实际 Node 版本，见测试报告），无 npm 生产依赖。Windows 可运行根目录 `start-local-demo.cmd`；脚本不安装软件，不申请提权，不注册自启动，不创建防火墙规则。没有 Node 时用 `portable/HAIZ-Classroom.html` 做单机演示。

## 开始

```sh
node scripts/classroom-server.mjs
```

打开输出的 `http://127.0.0.1:8787/#teach`。服务生成 `.haiz-demo/local-demo-keys.json`，只存在本地且被 Git 忽略；不要上传、发群或放进交付 ZIP。每次服务启动重新生成凭据，旧凭据失效；公告数据保留在 `.haiz-demo/public-state.json`。

在页面“连接本地演示服务”输入对应的随机凭据。它不是学校账号密码，不向外部发送。凭据仅保存在当前标签页 sessionStorage，断开后删除。不同窗口使用以下身份：

| 本地凭据名 | 服务端角色与范围 |
| --- | --- |
| teacher-a / teacher-b | 分别属于高一 / 高二示例班；只能新增本班内容，修改、撤回自己发布的内容 |
| display-a / display-b | 只读对应班和全校已审公共内容，不能发布、审核或修改 |
| student-a | 只读 A 班与全校公共内容，不存在私人记录 API |
| admin | 授权管理员演示，可以审核、发紧急演示、驱动模拟适配器 |

## 六步验证闭环

1. 窗口一用 teacher-a 登录发布台；另一个浏览器配置 / 无痕窗口用 display-a 登录 `#classroom`，手动切课间。
2. 教师输入提醒 → 预览 → “提交管理员审核”。公共屏不应出现。
3. 窗口三用 admin 登录发布台，点待审内容“审核”，核对正文与时段后通过。
4. display-a 通过实际 HTTP SSE 连接自动收到新快照；display-b 收不到 A 班消息。无静态图片或 localStorage 跨配置假同步。
5. 教师修改同一条消息，其 ID 保留、版本递增。旧版本修改返回 409。撤回后所有已连接授权屏读取的新快照移除该条；不会反复弹窗。
6. Ctrl+C 关闭服务。已缓存网页和未过期公共内容保留，状态标注最近接收时间与“只读缓存”；到期内容仍被浏览器按时段过滤。重新运行服务后凭据会轮换，需要重新连接；网络临时中断但服务未重启时 SSE 每 3 秒重试并恢复最新快照。

## 课程读取与纯净模式

默认显示明确标注的手动只读课表示例。连接本地服务后读取模拟适配器 DTO，来源始终为 `simulator / SIM-1`，不是任何 ClassIsland 版本。管理员可以模拟上课、课间、放学、来源未启动和课表冲突。每个教室窗口默认仍由老师手动切换；可勾选“跟随模拟课程状态”，切换原因可查。手动隐藏具有最高优先级，后续快照不得取消隐藏。

教师准备事项只能针对只读来源的下一节科目保存，并需勾选确认。来源失效、存在冲突或科目不匹配时，增强提示暂停。没有课表编辑、ClassIsland 内部 API、进程注入、文件改写或系统控制入口。正式选择插件还是 IPC 伴随进程，要等确定目标版本并做编译与真机技术验证；详见 CLASSISLAND_INTEGRATION.md。

## 协议与隔离

- `GET /api/snapshot` / `GET /api/events`：携带 Bearer 本地凭据；按服务端身份过滤。SSE 推快照，消息 ID + version 和全局 revision 用于重连和更新。
- `POST /api/notices`：服务端检查角色、范围、所有权、紧急原因；可送审。已有条目必须携带匹配 version。
- `POST /api/notice-action`：审核或撤回；仅管理员可以通过服务端待审内容。撤回受所有权限制。
- `POST /api/course-note`：教师确认的附加信息，不改课表。
- `POST /api/adapter`：仅管理员驱动模拟器。没有任意命令、屏幕控制、文件访问或私人学习接口。

服务仅绑定 127.0.0.1，验证 Host 和 Origin，无跨域授权，写请求要求 JSON，内容大小上限 32 KiB。凭据和数据在 dist 外，静态路径不能越界。API 不进入 Service Worker 缓存；离线屏消费最后的已认证公共快照并显示时间标记。日志仅是本机演示记录，可被设备所有者修改，不声称防篡改。public-state.json 原子替换写入。学校生产部署仍需真正的身份系统、服务鉴权、授权设备、TLS 与受保护审计。

网站版的静态 Sites 预览没有部署这个本地服务；它使用浏览器内演示联动。连接按钮会明确要求打开本地服务地址，不跨源探测校园内网或 localhost。
