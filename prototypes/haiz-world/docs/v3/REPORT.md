直接读取当前 `HAIZ-BLENDER-V3/HAIZ-Campus-V3.blend`，确认是 R3，包含中央与侧翼屋顶、白色屋脊线及 1923 入口。目录中原 GLB 早于这些修改，本次从当前 `.blend` 重新导出。

- 一号楼、榄仁树、砚池、景石、根区台地、前场使用 R3 区域资产。

- 全校植被使用 V3 榕树、榄仁、阔叶与棕榈；642 个树干/树冠实例对应约 321 个树位，管理为 34 个空间分块。

## M5 性能实测

Apple M5 / ANGLE Metal，均衡画质，页面可见。机位 `[14.195,3.1,-96]` 看向 `[14.195,10,-53.59865]`，62° 镜头，1440×960 页面/1459×1070 绘图缓冲。静止场景手动连续绘制，旧版 90 帧、V3 120 帧。

| 指标 | 原校园 | 当前 V3 |
|---|---:|---:|
| rAF 样本 FPS | 60.11 | 60.45 |
| 帧间隔 P95 | 17.6 ms | 17.4 ms |
| CPU 提交 P95 | 3.4 ms | 3.2 ms |
| Draw calls | 625 | 724 |
| 每帧三角形 | 1,059,434 | 1,623,334 |
| 几何资源 | 819 | 653 |
| 纹理资源 | 136 | 148 |

小幅时间差不证明提速。V3 绘制和三角面开销更高；CPU 提交不是 GPU 时间，也不是持续漫游或手机 FPS。场景引用纹理 RGBA/mipmap 粗估 273 MiB、几何属性/索引约 234 MiB，包括隐藏回退对象，可能重复计算共享存储，且不含驱动/HDR精度/全部渲染目标，不是显存总量。[完整测量与限制](performance.json)。

三档 DPR 上限 1.65/1.2/0.85，阴影 2048/1024/关闭，植被距离 280/190/110，过滤 8/4/2。60/45/30 是运行时绘制预算，不是保证 FPS。完整/移动植被在启动时选择，运行中切换调整密度和距离，不重新下载另一份冠层模型。

## 限制与真实参考缺口

- 原 KML、控制点、真北和高度基准缺失；坐标一致只证明内部一致，并非测绘数字孪生。
- 一号楼 116×27×19 m 旧体量、层高、背面窗墙、入口、屋顶坡度仍待带尺度照片/测量；楼梯与 201 为体验性推演。
- 凤栖堂/衍林堂 V3 主体缺失；其他 V3 教学楼、宿舍、食堂等仍有通用体量，尚未全面深化。需要正侧背立面、入口近照和屋顶参考。
- 植被来自共享形态和继承树位，没有现场普查/扫描，仍有程序重复。地面和水岸接地需继续校正。
- 资源总量较大，隐藏回退仍占场景资源；未做网络流式分区、KTX2/Meshopt 或长期内存压力测试。
- 未验证真实 iPhone/Android、Safari/Firefox、温度/续航、弱网、完整 WCAG/Lighthouse/CWV；手机证据是 M5 上的触屏模拟。
- 原靠近建筑镜头保留，没有新增完整多站电影导演模式。运动场细节及缺失历史主体沿用原方案。

## V4 优先顺序

1. 区域延迟加载、共享纹理、清理隐藏回退资源，建立真实手机与弱网预算。
2. 现场尺寸/控制点校准一号楼与主轴，完善真实楼梯/背面/室内，再扩展二三号楼。
3. 补凤栖堂与衍林堂可靠主体，深化图书馆、食堂宿舍及艺术中心。
4. 用现场照片改善树冠、根盘、铺装和水岸，保留空间克制。
5. 真机持续漫游与 Safari 验证后，确定压缩、LOD 和高画质光照预算。

这些是排序建议，没有在本轮冒称完成。
